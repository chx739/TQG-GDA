## 参考包已经实现的范式

| 部分 | 附件中的行为 |
|---|---|
| 源数据角色 | 按类划分 `ref / fit / cal`；参照库参与源预训练 |
| 源分类 | 使用同一个基于距离的源参照分类器进行预训练与后续预测 |
| 编码器 | GIN/GINE，BatchNorm，各层 sum pooling 拼接与投影 |
| 适配表示 | 源预训练后冻结编码器及图坐标 |
| 适配对象 | 优化共享几何度量，结合可信目标参照和逐类源任务风险约束 |
| 更新验收 | 候选子问题、非线性重评估、接受或回溯、停止 |
| 预测 | 完整源参照库结合最终共享几何 |

这些是参考实现的现状，不是已经确定的新 TQG 数学定义。如何引入 TQG、保留哪些机制、更新哪些变量及如何构造目标函数，均留待下一步讨论。

## 与历史 TQG 的关系

历史 TQG 保存在 `history/tqg-v2-20261106`，固定提交为 [`eb39fd7c5433420bd51f14e6330ba5067d164456`](https://github.com/chx739/TQG-GDA/tree/eb39fd7c5433420bd51f14e6330ba5067d164456)。其算法、冻结协议、日志、模型及评价记录保持原样。

历史版本引用的 SEGA 骨干配置与本次附件不同。历史 TQG 的独立 `query` 角色不能直接等同于附件参与预训练的 `ref`；两者的初始化、分类器及适配变量也不同。历史实验分数不能直接转作本参考范式的结果。
