# 独立复核记录

首轮由两个上下文独立的审查会话分别沿原设计和命令行追踪实现。修正后重新启动独立会话，使用构造图检查数值反例、数据权限和冻结参数。以下保留能复现的发现及其回归依据。

| 发现 | 修复和验收依据 |
|---|---|
| 神经网络 float32 评分在 η=0 的混合精度计算中可能产生微小修正 | 源、目标候选概率均在 float64 中归一化，测试逐元素比较源概率及全局／分量条件零适配。[模型测试](../tests/test_model.py) |
| 求解器达到迭代上限、未正则化且无有限解时仍可能发布结果 | 适配模式发布前检查各求解器状态。无比较、无校准信息分别按设计回退为零。测试包含结构和先验失败。[估计测试](../tests/test_adaptation.py) |
| 全局伪逆容差掩盖独立的弱比较方向 | 按连通分量在正交对比基中求解。谱值 0.5 和 1e-20 的双分量例恢复约 4.27e19 的敏感度。分量内部无法可靠解析的响应显式记录为 unresolved。[估计测试](../tests/test_adaptation.py) |
| 满 A 池的稠密轨迹占用过多内存 | 第一遍压缩为所选组的比较质量，第二遍使用相同的图 ID 和排列逐图重建。合成独立核验记录到两遍各 12 条对应轨迹，参数全部冻结，源 checkpoint 摘要相同。 |
| 无索引 TU 加载将 H 的损坏邻接带入源训练 | 显式分离一次性 TU 建索引与四个角色的逐图读取。破坏 H 的字节后仍能训练和读取 A，读 H 时报告摘要错误。离散／连续节点列需声明外生来源。[数据测试](../tests/test_data_metrics.py) |
| 混用其他适配池、重复评分 ID 和浮点／布尔类别可产生失真的评分 | 预测核对 A 身份及源文件摘要，评分严格核对 ID、原始整数类别及重复 JSON 键。目标和源标签文件均可在无权限阶段移走。[流程测试](../tests/test_pipeline.py) |
| 极端概率被舍入为 1 后，AUROC 和等量正例排序出现假平局 | 归档自然 log 后验，使用其余类别的 logsumexp 计算 one-vs-rest log-odds，NLL 从自然 log 后验计算。在二类与多类饱和样例中测试排名。[指标测试](../tests/test_data_metrics.py) |
| 两个可见状态时，舍入误差让三分类前缀矩表现为满秩，产生巨大先验偏置 | 显式利用状态概率和为 1 的约束、正质量状态个数和对比矩阵的数值秩。两个状态和三类的例子恢复零偏置，同时保留能分辨的极弱满秩构造。 |
| 优势词元两类概率均舍入为 1 时，响应可能缺少负向补偿；二分类矩根恰在端点时，求解库返回不可靠迭代数 | 逐步用分量内零和约束恢复主导词元响应，解析敏感度例得到 4e-40。端点已为根时直接记录 0 次迭代。[估计测试](../tests/test_adaptation.py) |
| 三类矩中常见状态和稀有状态各支持一个独立方向，普通 SVD 会丢失后者；二分类正则根的两个解析界可能舍入到同一点 | 行尺度下能辨认满秩、原尺度无法可靠求解时，从非主导行重建概率约束，用多精度求小型 Gram 矩。三状态构造恢复 ω≈3e-40 和 ν≈(50,100,−150)，分类决策与高精度参照一致。二类括区向外舍入，根已达浮点分辨率时记录相应状态。 |

这些检查使用可计算真值的例子。真实 smoke 的运行范围和源验证结果见 [S1 验收](../experiments/s1_流程验收_20261126/report.md)。
