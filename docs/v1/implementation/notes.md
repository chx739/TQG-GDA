# 实现说明与复用边界

## 从 SEGA 复用什么

- GIN/GINE + mean/sum readout 的骨干结构。
- TU/PyG 原生缓存与 graph ID 的读取约定。
- 原始 `idx/*.npy` / `node_*.npy` 文件与 PROTEINS 源 train/validation 清单。
- 配置、日志、source validation 选模、轮次边界恢复的工作方式。

TQG 包不依赖 SEGA 安装目录。不引入其局部度量、测地距离、OT、关系记忆或空间回缩步骤。
源框架审查中发现的缺类召回率 NaN 问题，在本包使用 `None` 表示不可定义值。

## 忠实实现的关键点

- 类别维中心化，不在图样本维减均值。
- fit/query 在 warmup 之前固定并分离；validation 完全独立。
- 模型参数快照、扰动、方向都不修改真实参数或 optimizer。
- 只探测 encoder 联合参数；不对线性 head 单独探测。
- 使用目标 JVP 的输出 RMS 规范化；随机/源方向消融也保留同样规范化。
- 每个有效方向最多产生两列响应；非有限方向或响应会在两域共同丢弃，不无限采样。
- 每列两域共享缩放，分别对源域和目标域的均值各赋一半权重。
- Ridge 目标按图数平均、类别分量求和，使用线性方程求解，不显式求逆。
- 目标反馈是 logit 校正，不经过 softmax 变成伪标签，不做概率裁剪。
- 平方损失为 `0.5 * squared_error.sum(class).mean(graph)`，不是按全部元素平均。
- 每轮只在快照起点更新一步，随后反馈被丢弃。
- 返回的所有查询量均停止梯度，最终只通过当前普通 GNN 输出反传。

## 暂未加入的研究扩展

相似源样本检索、自监督可信度、反馈门控、局部系数和元学习均未混入主实现。
它们应先作为独立消融验证，避免基础 TQG 与额外机制混淆。

## 明确的范围

- 当前数据适配器服务已有 TU/PyG 分类缓存；不把 OGB 索引文件误当成完整 OGB loader。
- 不声称估计反馈无偏，不保证目标风险下降。
- 未使用真实图缓存证明效果；开发配置不是调优后的论文设置。
- CPU 的恢复一致性已由工程测试检查；CUDA 需在实际驱动和 PyTorch/PyG 组合上单独验证。
- 默认严格确定性；如果某个 CUDA 算子不支持，需明确记录配置变更，不能静默声称逐位复现。
