# 全量查询实验结果解读

## 白话解读

1. **全部用满51张query，没有形成跨方向稳定收益。** odd+even在0→1相对仅源fit训练提高0.59个百分点（3胜2平0负），但0→2/0→3为−0.12/−0.65个百分点。仅odd在0→1提高0.35个百分点，其余两个方向仍略低。
2. **用满250张更接近仅源训练，但未带来额外分类优势。** 两种响应在0→1和0→2均与fit基线逐种子同分；0→3仍略低。不能把“比某些小query设置少退化”直接说成迁移有效。
3. **even没有稳定的增量价值。** n51时，加入even在0→1/0→2均值略好，在0→3更差；n250时没有均值收益。此处比较同K，响应列数不同，不能单独识别纯曲率信息的作用。
4. **同分不表示没执行反馈。** 全部TQG训练步都有有效探测方向；n250平均纠错幅度普遍小于n51。另做了30对只读参数比较，n250模型均与各自fit基线参数不同，详见model_difference_audit.json。
5. **0→1的小幅改善对选点规则不稳健。** 固定200步的n51 odd+even为57.08，但源验证选点后为56.14，对应fit基线为56.41；不能从两套选点规则里择优汇报。

这些结果支持“扩大query能减轻部分退化，但单独扩大到51或250尚未解决可迁移监督的读取问题”。它们没有证明所有响应迁移方法无效，也不能把n250的表现只解释为数据量作用，因为它同时加入了预训练见过的199张图。

完整三方向表格、配对差值、源验证选点和实验设置见[执行报告](run_report.md)。
