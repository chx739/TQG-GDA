日期：2026-10-24。目标：为后续代码修改和实验提供可执行依据。状态：**方案已设计，改进效果未验证；本次不启动训练。**

这是原版失败后的新版本研究计划，不覆盖原设计、原实验方案或已有结果。目标仍是 ICML 2027，但本文件不是论文已具备投稿条件的声明。

## 0. 五分钟先读：我们准备解决什么

原版 TQG 的流程是：

> 目标图找敏感方向 → 同方向测源/目标响应 → 源标签拟合一个组合权重 → 预测目标纠错 → BP 更新。

当前最有证据的断点是：**源端权重拟合不稳定；源经验未必适用于目标；输出纠错经 BP 后未必变成有利的参数动作。** 未发现能解释失败的明显核心实现错误。

本版按三个层次推进，避免一次加入很多模块：

1. **稳定估计。** 增加每次源查询标签数，减少响应自由度，明确正则化规则。
2. **局部借经验。** 目标图主要向“同样探测下反应相似”的源图借监督，比较普通 embedding 是否同样有效。
3. **检查执行。** 约束预测残差范围，比较输出纠错、SGD 和真实 Adam 一步；只有执行确实有问题，才考虑修改更新器。

推荐阅读顺序：本节 → §2 数据职责 → §4 方法 → §5 实验顺序 → §6 判定标准。实现时再读 §7–9。数学基础较弱时，先看各节的“白话”。

**第一轮最小工作包：D0 工程验收 → D1 固定快照样本量扫描 → D2 局部匹配与执行诊断。** 先做这三项，再决定是否开展 A/B 两组训练。不要直接启动所有组合。

### 1.2 四个可被否定的假设

- **H1：估计方差。** 同一模型、同一响应字典下，增加拟合系数所用的源标签数，降低另一批源图上的残差误差。
- **H2：局部迁移，主假设。** 用响应相似度分配源权重，比均匀权重、embedding 权重及打乱归属的相同权重，更有效地读取可迁移监督，并改善目标分类。
- **H3：非线性增益。** 有限 odd 响应比线性 JVP 提供额外收益；even 是否有额外价值另行判断，不预设成立。
- **H4：执行一致性。** 输出纠错与真实参数步的差异解释部分失败；必要时更新器改造应改善真实步效果，而不只是改善直接 logits 指标。

H1 成立不能推出 H2 成立；H2 成立也不能推出“目标方向必然优于随机”。标准加权、岭回归、投影和交叉验证本身不作为新颖性声明。

### 2.2 固定快照的源外层审计

## 4. 改进方法：按原文步骤定位

### 4.1 保留原输出与残差定义

z(G)=f_θ̄(G)−mean_classes f_θ̄(G)，p(G)=softmax(z(G))，r_i=onehot(y_i)−p_i。

全部反馈计算基于同一快照。类中心化仍只沿类别轴进行，不沿图轴处理。源 fit CE 使用当前模型；query 残差、方向、尺度、权重、系数、投影参考均停止梯度。

### 4.2 §3.5–3.7：先采用较简单的响应

保持目标 VJP 方向及目标 JVP RMS 归一化。主候选 K=4、ρ=.05，采用 odd-only：

\[
F_{ik}=\frac{z_{\bar\theta+\rho v_k}(G_i)-z_{\bar\theta-\rho v_k}(G_i)}{2\rho},\quad
s_k=\sqrt{\tfrac12\operatorname{mean}_S\|F_{ik}\|_2^2+\tfrac12\operatorname{mean}_T\|F_{jk}\|_2^2+10^{-16}},\quad
\Phi_{ik}=F_{ik}/s_k.
\]

源目标同列使用同一 s_k。对照包含 linear（F=Jv）、原 odd+even；不能把 even 暂时去掉写成“已证明它无用”。

**白话：先用较少、较简单的问题测响应，避免靠一堆不稳定特征解释 16 张图。**

### 4.3 新增：用响应签名分配源权重

主版本只用 Φ 作签名，不拼当前预测，防止匹配效果其实仅来自按预测类别分组。

\[
D_{ij}=\|\Phi_{S,i}-\Phi_{T,j}\|_F^2/(CM),\quad
s_D=\operatorname{median}\{D^{SS}_{ik}:i<k,\ D^{SS}_{ik}>10^{-12}\}.
\]

先排除源源距离矩阵对角线。正距离集合为空或 s_D≤1e−12，记录 `uninformative_signature`，无门控版本退化为均匀权重；门控版本该批不提供反馈。非有限值是错误，不当作普通拒绝掩盖。

\[
\widetilde w_{ij}=\operatorname{softmax}_{i}[-D_{ij}/(s_D\tau)],\qquad
w_{ij}=(1-\gamma)/n_S+\gamma\widetilde w_{ij},\quad \gamma=.75,\ \tau=1.
\]

所有 w 都非负且每目标列和为 1。均匀混合防止完全只依赖一张源图，但不是可靠性保证。γ、τ 为预先规定的工程默认值，本版不看目标结果调节。

embedding 对照分别使用冻结 θ₀ 与当前 θ̄ 的 pooling 表示，先除以 max(L2 范数,1e−8)，距离为均方差，使用同样的源源正距离中位数、γ、τ。记录两种对照，避免把“响应会随训练改变”与“embedding 永远冻结”的差异误当响应优势。第一版不训练额外 embedding 网络。

**白话：同样旋钮转一下，反应相近的源图贡献更大；其余源图仍保留少量权重。**

### 4.4 §3.8：从全局系数改为局部加权系数

\[
M_j=\sum_iw_{ij}\Phi_{S,i}^{\top}\Phi_{S,i},\quad
c_j=\sum_iw_{ij}\Phi_{S,i}^{\top}r_i,\quad
a_j=\operatorname{solve}(M_j+\lambda I,c_j),\quad
d_j=\Phi_{T,j}a_j.
\]

因为 Σ_iw_ij=1，**这里不能再额外除以 n_S**。γ=0 必须精确退化到同一字典上的原全局岭回归。采用直接线性求解，不显式求逆，不加未登记的截断或额外归一化。

正则有两个层级，分别保留：

- 桥接消融固定 λ=.01，便于只比较 n 和响应类型。
- 稳定版本每步仅在当前源 bank 内做固定 4 折 CV，候选 λ∈{.01,.1,1}。同一 Φ/尺度，3 折拟合、1 折算图均值残差 MSE，4 折汇总；分数相差≤1e−8 时选较大的 λ。最后在整个 bank 重拟合。

CV 使用**全局均匀回归**选择单个 λ，所有目标局部回归共享它。本版不为每个目标或每种匹配方式额外扩大搜索。固定一个总体源 CV 规则便于控制变量，但它不保证各局部目标的最优正则。每步 CV 折由独立 seed/step/graph-ID 规则决定，和探测随机数隔离。

具体分折：用独立 CV RNG 将 bank ID 排列后等分 4 折；每个拟合折 F 的均匀岭回归都按 **|F|** 归一化：a=[Σ_F ΦᵀΦ/|F|+λI]⁻¹[Σ_F Φᵀr/|F|]。不能继续用完整 bank 的 n_S 作分母，否则不同折的有效正则强度会改变。

### 4.5 可选门控：把“匹配”与“拒绝更新”分开检验

主假设使用**无门控局部版本**，目的是检验匹配本身；门控作为单独消融，不把它与匹配效果混在一起。

定义 b_i=min_{k≠i}D^SS_ik/s_D，t_cov 为 b_i 的 95% 分位数（线性插值）。对目标 j：

\[
\mathrm{ESS}_j=1/\sum_iw_{ij}^2,\quad
m_j=\mathbb{1}\{\min_iD_{ij}/s_D\le t_{cov}\}\,\mathbb{1}\{\mathrm{ESS}_j\ge n_S/4\}.
\]

无门控时 m_j=1。门控是经验支持检查，**不是 95% 目标可靠性保证**。ESS 只衡量权重集中度，不代表相互独立的信息量。

门控对照需有四格：均匀/局部 × 不门控/响应门控。均匀＋门控版本也从同一响应局部权重算 m，再用均匀权重回归。固定快照比较时共用同一 m；完整训练时各自轨迹会分离，须说明这一点。

若全部拒绝，反馈为零，仍执行源 CE；这会退化为**源 CE 继续训练**，不是自动退化为冻结源模型。高拒绝率不能当作迁移成功。

### 4.6 §3.9–3.10：合法残差投影与反馈损失

\[
q_j=\Pi_{\Delta}(p_j+d_j),\quad d_j^{proj}=q_j-p_j,\quad
L_{fb}=\frac1{2n_T}\sum_jm_j\|z_\theta(G_j)-\operatorname{sg}(z_j+d_j^{proj})\|_2^2,
\]
\[
L=L_{fit}+\beta L_{fb},\qquad \beta=.1.
\]

投影用标准概率单纯形欧氏投影，不是逐坐标 clamp 后随意归一化。按分量降序排序 v=p+d；取最大的 k 使 v_(k)−(Σ_{l≤k}v_(l)−1)/k>0；令阈值为该前缀表达式，再 q_c=max(v_c−阈值,0)。

真实残差 r=onehot(y)−p 属于 Δ−p，因而投影保证 ||d_proj−r||²≤||d−r||²。这只保证残差平方误差不增加，**不保证目标 CE、准确率或 Adam 步改善**。

门控后仍除原 n_T，不除接受图数；否则仅剩几张图时可能被重新放大。q、d_proj、m 全部 detach。

在每次重建、只做一步更新的设置下，以上平方反馈与以 q 为停止梯度软标签的 CE 在当前点梯度相同。因此“把 MSE 换成软 CE”不列为独立改进。

### 4.7 所有简化对照的精确定义

| 对照 | 定义及目的 |
|---|---|
| 打乱匹配 | 对每个目标 j，打乱同一组 w_ij 在源索引上的归属；保留权重集合、ESS、投影。固定快照有门控时保留原 m。检验是否找对源图 |
| 局部平均残差 | d_j=Σ_iw_ij r_i，再做同样投影/反馈。检验响应回归是否比直接借残差有价值 |
| 局部标签迁移 | q_j=Σ_iw_ij onehot(y_i)，目标 soft CE 权重 .1。它与局部平均残差不同 |
| 加权源 query CE | w̄_i=(1/n_T)Σ_jm_jw_ij；L=L_fit+.1Σ_iw̄_i CE(y_i,p_θ(G_i))，无目标反馈；所有 w/m detach。检验是否只是多用了源标签 |
| 随机探测 | 随机 encoder 参数方向，经相同目标 JVP RMS 归一化；其余流程相同。检验目标生成方向的价值 |
| 均值/零残差 | 固定快照常量控制，不产生探测优势；零预测用于解释残差指标 |

| odd 响应列 M=K | 2、4、8，同一最大字典前缀 |
| 固定 ridge | .01、.1、1 |
| 方向来源 | target、random |

每块 54 组回归，5 种子×2 任务×20 块=200 块，合计 10,800 组回归；**不是 10,800 次模型训练**。缓存最大字典和尺度，只重做小矩阵求解。额外记录每个 n/M 的 bank 内 CV 选择结果，并用外层 audit 评价，不能用外层 audit 选 λ。

主指标：源 audit 残差 MSE；补充：目标 heldout MSE、反馈与真实目标梯度余弦、响应谱、有效自由度、少数类图数。

再加一个源标签分层诊断：n=16/32、M=4、λ=.01，少数类期望配额分别 4/8；若 bank 不足，取该类全部可用图、剩余由多数类补足到 n，保留不足标记，禁止重复采样冒充新图。配额控制中的 n16/32 仍构造嵌套子集。它改变采样目标，只用来判断类别覆盖影响，不混入主结果。

结论边界：n32 优于 n8 只能支持“小查询批次导致估计误差”，不能证明大数据能消除域差异，也不把残差 MSE 当目标性能的必要条件。

### D2：匹配是否有用，纠错是否执行正确？

仍用固定 warmup，n=32、K=4、odd、源内 CV，复用 D1 的 5 种子×2 任务×20 个采样块，比较 §4.7 全部对照及均匀/局部×门控四格。所有规则先写入配置，再生成目标开发评价。历史 final 状态仅作补充，每种子/任务预定 3 块，共 30 块，不与 warmup 主统计混合。

必须输出三个层次：

1. **可表达性：** 目标 oracle 在 32 张图上拟合全局均匀岭回归，在独立 32 张图上评价；只在这 32 张拟合图内做同网格 4 折 CV。与源全局回归比较时保持字典及容量相同。它是有标签诊断，不是局部方法的理论上界；全局 oracle 不好，不能单独否定更大函数类的局部预测。oracle 不训练、不计入 UDA 方法成绩。
2. **迁移：** 同字典下比较源回归与 oracle 在相同 heldout 图上的预测差及各自残差误差；系数差只作补充，因为相关特征上不同系数可能产生相同输出。另比较真实源标签与三个固定种子排列源标签。排列后重新执行源 CV，以检验整个标签处理链。
3. **执行：** 先区分 query 图上的 d_Q 与 heldout 图上的 d_H。两者由同一预测规则、同一字典和公共尺度产生，但维度不同，不能直接把 16 张图的 d_Q 加到 32 张 heldout 图。直接输出对照计算 z_H+0.1d_H；参数步由 query 上的 d_Q 构造，再在 H 上评价。因此该比较同时包含跨图泛化差异。另报 query 自身上相同 d_Q 的直接输出/参数步对照，专门隔离执行几何。SGD 做等范数试算；Adam 比较复制状态的 source-only 与 source+feedback 一步，随后丢弃副本，所有目标标签只作离线评价。

梯度余弦在反馈用的 query 16 图与真实目标 heldout 32 图之间计算，全模型和 encoder-only 分别报告。零反馈梯度的 cosine 记为 null 并报告激活率，不把它伪装成正信号；另报以零效应计入全部块的平均 CE 改善，防止只看被接收样本。

warmup 主诊断先用 warmup 参数新建 **lr=.0003、空动量的适配 Adam**，再克隆两份比较；不能继承 lr=.003 的预训练 Adam 状态。原适配 `last.pt` 若含完整 optimizer，可以作为补充执行诊断并保留历史状态；仅有模型参数的 selected checkpoint 不得用新建 Adam 冒充历史一步。

**阶段决策：** 不因为源 audit MSE 未超过零就自动否定目标收益。允许开展 B 的最低探索信号为：至少一个任务、至少一种机制指标（cosine 或实际 Adam 相对 source-only 的 CE 改善）满足局部法平均值>0、相对排列权重的配对均值差>0、≥4/5 种子差值>0。cosine 每种子须至少有 10/20 个有效非零梯度块，否则只用包含零效应的全块 Adam 指标判定。都不满足时暂不开展整个 B 组，记录 H2 缺少信号。只在一个任务出现信号时属于“异质性探索”，B 仍保留两个任务，不能称广泛有效。这个宽松推进门槛不同于 §6 的成功标准。

## 6. 如何判断成功、失败和下一步

### 6.1 指标与统计

- 主分类指标：balanced accuracy，越大越好；同时完整报告 accuracy、CE、Brier、15 个等宽置信区间的 top-label ECE、每类 recall、预测类别比例。
- 机制指标：源/目标残差 MSE、零纠错基准下的 MSE gain、梯度 cosine、实际 Adam 的目标 CE 改善。
- 支持诊断：ESS、最大权重、距均匀分布 L1 距离、覆盖通过率、非零反馈率、源 bank 类别数、纠错/源残差范数比、梯度范数比、方向间相关性。
- 先按模型种子平均重复块；报告 5 种子 mean±样本 SD、配对差均值、配对胜负和全部种子值。两个任务共享源模型，不能合成 10 个独立种子。5 个种子的置信区间仅作不确定性描述，不声称 4/5 胜出等于统计显著。

### 6.2 提前规定的判据

| 判断 | 本版判据 | 没达到时 |
|---|---|---|
| H1 小查询影响 | 在 M4/λ.01/target 固定条件下，n32 相比 n8 的源 audit MSE 均值降低≥20%，每任务≥4/5 种子改善 | 不把数据少作为已证实主因；仍报告完整曲线 |
| H2 分类主假设 | T6 在两个任务各自比 T5、T9、T10 平均 BA 至少高 1 个百分点，且每项比较≥4/5 种子胜出 | 拒绝本版“响应局部匹配优于均匀和 embedding”的广泛主张 |
| 实用性底线 | T6 两任务均不低于冻结源模型和 B_full 的平均 BA；不能仅胜过失败原版 | 未证明实用收益 |
| 机制排他性 | T6 比 T11 梯度 cosine 至少高 .05，真实标签比排列标签至少高 .05；各任务平均为正且≥4/5 种子方向一致 | 不主张找到可迁移的标签关系 |
| 简单解释 | T6 在两任务比 T12/T13/T16 各至少高 .5 个 BA 百分点 | 相应复杂步骤的独立价值未建立，考虑简化 |
| 目标探测/有限非线性 | T6 相对 T14/T15 分别至少 +.5 BA 百分点，且配对机制指标方向一致 | 删除相应贡献，不换名保留 |
| 门控 | 同时报告四格差异和全体目标效果；拒绝率>80% 标记退化 | 不把近乎关闭反馈当迁移成功 |

这些是本轮推进标准，不是理论必然效果；一项不成立就报告该项不成立，不改变阈值适配结果。投影的数学不增误差性质只在数值验收中检查，不要求它必然带来 +1pp 分类收益。

工程硬停止：数据角色混用、目标 final 标签评价、非有限值、意外参数修改、未记录版本或超过资源上限。保存失败记录，修复后新提交重跑受影响的完整配对集合，不只重跑差种子。

科学停止不是删文件：完成当前预定阶段所有有效方法/种子后统一判断。若纯预测和真实参数效果都没有正信号，优先重新考虑响应表示或迁移假设；若直接输出好、真实步差，再进入 §8 执行器分支。

## 8. 有条件的下一版分支，不混入本版主线

### 8.1 执行器分支

若同一 d 在 logits 上好、在实际参数步上差，再考虑：

- **受限参数步：** linear Φ=JU 时，直接 δθ=ηUa，检查实际输出是否更接近拟合 d。
- **阻尼输出核校正：** K_T=J_TJ_Tᵀ，先解 b=(K_T+μI)⁻¹d，再沿 J_Tᵀb 做小 SGD 步。

两者都会改变原流程，需要新版本明确源 CE 如何合成、SGD/Adam 如何处理、μ/η 的源侧选择和额外成本。不能用局部 SGD 公式替完整 Adam 作保证。本版只设计诊断，不默认实施这些更新器。

### 8.2 类别与表示分支

若观察到源多数类偏置，单独比较源 query 分层采样、源 CE 类权重；不要把目标真实类别比例带入训练。先验估计需明确假设，不能默认严格 label shift。

若响应匹配只和预测类别有关，再比较 prediction-only、response+prediction。若固定/当前 embedding 都足够好，先接受更简单的解释，不立即训练更复杂的 embedding。

自监督额外任务（类似图像旋转预测的启发）放后续分支：先定义对图有意义、标签保持的任务，再验证其分数能否预测迁移可靠性。图没有天然统一的旋转分类任务，不直接照搬图像操作。
