| §3.1–3.3 输入与前缀 | 外生节点特征和预算 (n,m) 从第 1 步可见。每个排列分至多四块，末边独立成块。组 k 由源训练的粗端点类型对、前缀路径关系和离散边类型决定。词元 j 是前缀度桶 0/1/2/≥3 的无序端点对，共十种。[结构规则](../cela/structure.py) |
| §3.4–3.5 源训练 | 两层前缀 GIN 在有多种边标记时使用 GINE 消息。共享候选评分 u 带可训练、中心化的词元偏置。组评分类别维中心化。仅以外生特征和预算计算条件类别头，加上各类别有序边选择的 log-likelihood 后得到整图后验。训练优化图级 CE 加源联合 NLL，联合项权重为 λg/(1+源训练图平均边数)。源验证以固定排列集成后的自然 CE 选 checkpoint。[模型](../cela/model.py) · [训练入口](../cela/pipeline.py) |
| §3.6–3.9 目标结构 | A 池每张图固定采样若干排列。只在本步实际选中的组内建立可选词元的比较，保留孤点。在每个连通分量的和为零子空间内拟合 η。各图等权、排列取均值、步骤求和，再按全局平均边数缩放并加 ridge。冻结源模型。预测时保持各类别赋给各分量的源质量，分量内部才施加 tilt。[求解器](../cela/adaptation.py) |
| §3.10–3.11 图级判别与可选校准 | 结构拟合完成后，用固定 η 计算每一步之前的前缀 logits 和组×分量的类别概率。二类解单调矩方程，多类用 Helmert 对比基拟合。无矩信息时 ν=0 并记录状态。无有限解或未收敛时停止生成适配结果。 |
| §3.12–3.13 机制核验 | 构造测试覆盖条件类别消除、信息矩阵核空间、跨分量 gauge 不变性、判别传递积分关系和文档两图排序反转。无标签 A 诊断含图级比较支持、信息谱、条件 NLL、各类对的 log-odds 变化，可启用图级 bootstrap。弱信息敏感度按分量求解，超出数值分辨率时记录受影响的图和排列数。[机制测试](../tests/test_adaptation.py) |
| §3.14–3.16 推断与缓存 | 块内特征固定，每选一对节点就从所有类型的候选中删除该对。反向 logaddexp 缓存恢复各步的精确质量。A 池第一遍保留所选组的十维比较质量，第二遍按同一排列逐图重算前缀，收集低维先验矩和类别响应。新图主输出为各排列后验的算术平均，同时保存似然加权敏感性对照和排列间标准差。[推断入口](../cela/pipeline.py) |

## 复现口径

默认 hidden=64，块数上限 4，源训练每 epoch 重采样 1 次排列，适配 4 次、推断和源验证 8 次。Adam 学习率 0.001，batch 16，最多 100 个 epoch。λg=1，结构与先验 ridge=0.01，目标优化最多 100 步，容差 1e-6。smoke 只缩短源训练并启用 4 次图级 bootstrap。完整候选按图枚举，单块候选数量随节点数平方增长。当前 CPU 实现适合小中图。

| 输出模式 | η | ν | 候选归一化 |
|---|---|---|---|
| `zero` | 0 | 0 | 源模型 |
| `prior_only` | 0 | 用 η=0 的前缀矩拟合 | 源模型 |
| `structural_only` | 组内比较拟合 | 0 | 分量内 |
| `prior_calibrated` | 同一结构估计 | 用该 η 的前缀矩拟合 | 分量内 |
| `v2_global` | 与 structural_only 同一个 η | 0 | 全局 |

所有模式共享源 checkpoint 和 H 排列。`v2_global` 隔离文档指定的全局归一化差别。自然决策取最大后验，BA 决策从自然 log 后验减去由 A 条件类别头估计的 log 类别比例。评分同时提供 Accuracy、BA、Macro-F1、AUROC、自然 NLL，并在二类时比较等预测正例数下的净纠正。缺类时 BA 和宏 AUROC 标为 null，保留每类支持数。H 标签只可在独立 score 阶段传入。
