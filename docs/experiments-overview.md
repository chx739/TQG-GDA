# 实验阅读路线

实验的唯一状态索引在 [experiments/README.md](../experiments/README.md)，本页不复制数值结果。

1. [合成实验](../experiments/synthetic/README.md)：从解析几何、控制实验读到 P0，区分 score 估计误差与目标函数的权衡。
2. [Mutagenicity](../experiments/mutagenicity/README.md)：R1/R1b 检查表示和边界支持；R2 检查训练预算与适配；R3 检查约束；R4 固定配置覆盖全部方向。
3. 每轮先看 `README.md` 的证据入口，再看报告；计划配置和实际配置分开保存。

合成方向一致率、真实图 Accuracy 和工程测试通过率属于不同证据，不作替代。历史开发评价不能改称独立最终测试。
