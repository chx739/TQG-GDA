# TQG v2 §3.8：四项核心条件的验证方案与已有证据

日期：2026-11-03。状态：**实验设计，新增实验尚未执行**。这份文档供下一轮诊断使用，不修改此前冻结方案、门槛或结果。

## 1．先用一句话理解要验证什么

TQG希望：**目标图提出梯度问题，源图凭真实标签提供答案。** 这要求：源目标的答题规律相容；签名记住答题所需信息；核读出器能用有限数据学到规律；源经验覆盖目标真正要问的部分。

已有实验说明“在友好条件下能够读出正确方向”，但尚未说明这四个条件在真实Mutagenicity任务上成立。下一步先诊断，不直接增加完整适配轮数。

### 四个条件及验证边界

| 条件 | 数学表述（标签省略类别对比坐标） | 白话问题 | 有限实验能给出的证据 |
|---|---|---|---|
| 跨域条件稳定性 | η_S,t(R)≈η_T,t(R) | 同样的签名，在两域是否对应相容的标签概率？ | 比较同签名输入、同容量、同监督量的源训练／目标训练探针；真实数据只能给局部、有限样本证据 |
| 签名任务充分性 | E_D[Y\|G]≈η_t(R_t(G)) | h和A有没有丢掉任务信息？ | 同域预测、已知规律的签名碰撞、扩充签名对照；探针失败不等于已证明信息丢失 |
| 函数复杂度可控 | μ_t=η_t−p_t可由H_t^q以适度复杂度近似 | 当前核是不是学得动，而不是只在训练点拟合？ | 独立留出、正则／样本量曲线、已知η的Oracle与噪声分解 |
| 源监督支持充分 | 源查询能约束目标梯度查询需要的函数分量 | 目标问题有没有相关源经验可回答？ | 函数／查询覆盖诊断及受控删减、补充源bank；输入近邻只是代理 |

这里R_t(G)=(h_t(G), A_t(G))，A_t(G)=J_t(G)V_t，μ_t是标签概率减模型概率。数学对应[原文§3.8及前后定义](../../TQG_Graph_Level_GDA_Design_v2.md)。H-only只把核的输入改为h，仍使用目标V和梯度查询。

四项是相互关联的充分性要求，不能只凭某一次低余弦唯一定位失败原因。更弱的、只针对当前梯度查询的条件也可能够用；不要求重建所有图的全部标签信息。

## 4．统一设置与标签边界

### 数据、模型、快照

- 真实诊断沿用Mutagenicity 4337张图、SEGA按边数／规模构建的0→1、0→2、0→3。这些不是官方自然域划分。
- 源域0训练975=fit779+query196，另有源validation109；fit已参与骨干预训练，不能混入“骨干从未见过的query”正对照。
- 每个目标域development542，既有输入ID划分A271／B271。继续不读final标签。A/B已被历史实验观察，所有新增结果是开发诊断，不能叫新盲测。
- 五模型种子3405—3409，GINE两层、隐藏32、mean pooling。主分析只用初始fit-best快照，避免与训练阶段变化混淆。0/50/200源监督快照作为登记的第二阶段敏感性分析，不并入主表。
- 主几何使用每任务、每模型初始快照的旧第0个目标A16块构造V；该V固定后，源query、目标A/B及各种签名版本都用同一个V计算A(G)。不能给每张图各建V后直接比较坐标。
- H与HA都报告；H核的原默认带宽、HA两个距离的原默认带宽从全196源query输入取得并冻结，不能使用B标签选择。探针的训练折标准化仅用该折训练输入。保留特征尺度与数值秩。
- 主阶段15份任务×模型几何。若做块敏感性，复用第1—7块分别重算签名／探针，不把块当独立模型种子。

### 目标标签何时能用

A1/A3中目标A标签可训练一个**诊断用目标探针**。这是为了问“若有同域监督，这个签名能否预测”，不是TQG训练，也不是合法UDA性能。这个探针不得生成后续适配信号，不保存为UDA候选模型。

目标B标签只在锁定候选、预测和输入支持分组后评价。所有超参数仅通过各自训练集内部交叉验证选择。B不得选核、选签名、选阈值或选训练轮数。诊断目标标签读取记录到独立账本。

### 统计与报告

- 先平均同一模型内的折／块／抽样顺序，再报告五模型种子的均值±样本标准差及逐种子差值。五模型共享图数据，不能把它当五套独立数据抽样。
- 图级配对bootstrap给定这些图／模型的描述性区间；同一图跨模型时使用相同重采样ID。区间不代表对所有新域的保证。比较门槛是路线筛选规则，不宣称统计显著性。
- 所有失败、未收敛、零梯度、数值下溢、类别缺失均保留；余弦不可定义不填成0。分开报告：几何支持、数值可比覆盖、反馈范数，三者不是同一指标。
- 本文数值门槛是新增实验的预设建议，执行时先冻结配置和SHA。若修改，必须在看新结果前登记新版本。旧实验不按新门槛重新宣布成功。

<a id="a0-freeze"></a>
## A0．冻结与回放：先保证对照真的可比

**目的：** 防止把缓存、坐标、数据泄漏或正则缩放差异误认为科学现象。

1. 记录代码、文档、checkpoint、图ID、输入签名和标签权限SHA；确认fit/query/validation、A/B/final角色。
2. 重放15个主几何的旧H-JOINT、HA-JOINT，λ_W=0.01、FP64，比较W、反馈及旧指标。相对／绝对误差容限均1e−8；近零量只按绝对误差。
3. 验证所有签名用同一θ、V；dropout关闭、BN统计固定；构造W不读标签、残差读取发生在W封存后；无额外除以query数。
4. 在合成小例子验证图块排列、W列块和残差顺序一致；真标签／乱标签只改指定标签部分。
5. 检查新增诊断探针与原TQG更新路径隔离；不覆盖旧checkpoint、缓存和计划。

**输出：** `audit.json`、`provenance.json`、`label_access.jsonl`、配置SHA。任一关键项失败先修复，不进入统计解释。

<a id="a1-triangle"></a>
## A1．三角对照：源内能学吗，迁过去还对吗？

**优先级最高。** 白话：先让源经验答源题，再答目标题；另请一个只学过同量目标题的“诊断老师”答同一批目标题。

### 具体分组

源query196按输入ID固定四折，每次147训练、49审计。目标A271按输入ID、每个外层折的固定盐选147张训练；不按标签挑选。源／目标训练图数相同，类别计数公开，不强行改成相同比例。每个训练集内部固定三折选择超参数。

| 名称 | 训练标签 | 同域或跨域评价 | 作用 |
|---|---|---|---|
| S→S | 源query训练147 | 源独立49 | 同域签名／读出是否可学 |
| S→T | 同一个源探针 | 目标B271 | 源规律能否迁移 |
| T→T，诊断Oracle | 目标A训练147 | 同一目标B271 | 同域监督、相同样本量下能达到什么水平 |
| PRIOR / MODEL | 训练集类比例 / 原p(G) | 同上各评价池 | 排除只读类别比例，及原模型已经解释的收益 |
| SHUFFLE | 每训练折三次固定标签置乱 | 同上 | 评价签名与逐图标签的对应是否有增量；置乱后按同样内部流程选超参数 |

每个模型、任务、折分别运行H和HA；四折对同一B的预测先各自算分再折内平均，不能将其当四倍独立B数据。

### 固定探针族

1. **原核残差KRR：** 训练目标为Qᵀ(Y−p)，λ_W∈{0.001,0.01,0.1,1}，带宽固定原方案。利用p恢复标签概率；二分类裁到[1e−6,1−1e−6]后计算NLL，另报未裁残差MSE、越界比例。它是函数预测探针，不等同于原JOINT梯度读出W。
2. **线性逻辑回归：** L2∈{0.01,0.1,1,10}；训练折标准化，最多500次优化迭代，收敛标志公开。
3. **小MLP：** 一层隐藏32、ReLU、weight decay∈{0.001,0.01,0.1}，Adam lr0.001、固定200步、无dropout；模型初始化由模型种子和折ID确定；不在B早停。

内部选择以训练集三折平均NLL最低为准；并列选更强正则。每个族独立报告，不在B挑一个“最优探针”。KRR目标、概率恢复与指标在执行前补齐单测。

### 指标与预设路线门槛

主指标NLL，次指标Brier、BA、相对原p的改善；标签图数、训练／验证差距、概率越界率、每折类数必须报告。NLL是每图自然对数损失，**0.02不是2个准确率百分点**。

定义同一B上的迁移缺口：

`Gap = NLL(S→T) − NLL(T→T)`。

- **同域可学筛选：** S→S或T→T较对应PRIOR、三次SHUFFLE均值的NLL均降低≥0.02，至少4/5模型种子方向一致。原p对照另报，不因预训练模型已很强就直接否定签名。
- **迁移缺口候选：** T→T可学，Gap≥0.02且≥4/5种子为正。再做A2支持分层；此时只能称“源训练读出存在迁移缺口”。
- **局部相容候选：** 两种训练读出都可学，且共同支持子集上Gap的配对90%描述性区间落入[−0.02,+0.02]。样本不足／区间过宽记为证据不足，不能用“不显著”宣布相等。
- 至少2/3任务同向才升级为跨任务路线建议；各探针族分别报告。只有某一个族满足时，结论限定该族。

### 如何解释

| 观察 | 优先考虑 | 不能直接说 |
|---|---|---|
| S→S也差 | 有限监督、探针能力、核和签名问题 | 全是域偏移导致 |
| S→S好、S→T差、T→T好 | 条件关系／支持／源覆盖下的函数拟合差异 | 已严格证明η_S≠η_T |
| S→T和T→T都差 | 签名信息不足或探针／样本不足 | 已严格证明签名不充分 |
| S→T接近T→T且都好 | 当前支持区域存在可迁移规律的正证据 | 完整目标空间和训练全过程都满足§3.8 |

**输出：** `probe_predictions.csv`、`probe_metrics.csv`、`inner_cv.csv`、逐种子三角图、校准图。已有相关但不等价的工作：[D4源内留出](../../experiments/tqg_d3_d4_20261031/结果解读.md)。

<a id="a2-support"></a>
## A2．支持分层与定向源bank：覆盖到了，还是覆盖了也答错？

### A2-a：先做不改算法的支持诊断

1. 所有分组只看输入。H／HA分别使用原带宽归一化后的距离；记录每个B图到源训练bank的最近距离、最大K_ST、核有效邻居数`ESS=(Σk)^2/Σk²`。分母近零标缺失，不伪造ESS。
2. 以源训练bank的留一最近邻距离90%分位数为阈值，划分B为“较近／较远”。这叫输入支持代理，不能等同数学支持。
3. 在两组中分别算A1的S→T、T→T及Gap，公开图数／类比例／NLL基线。评价同一B子集上的两种读出，减少任务难度混淆。
4. 原梯度读出记录tr(E)/r、λ_max(E)、||W||_F、||H_ST||、||反馈||。E只表示核函数类下的查询代理误差，不是真实标签误差或置信区间。
5. 比较代理支持与实际梯度误差时，使用已经冻结的A块经验梯度作诊断；另报V对B梯度的投影覆盖。不能把B梯度不在A的V内全归因于源支持。

**筛选：** 若高支持子集上的Gap比低支持子集至少小0.02，且4/5种子同向、每组至少30张B图，支持“覆盖相关瓶颈”候选；不足30不合并不同任务凑数。此为相关证据，不是因果结论。

### A2-b：按目标问题选择源bank（有候选后再做）

这是此前“找与目标相似的源响应再读取”的具体版本。

- 从未参与骨干训练的同一个query196池中，比较n64、n128两档：均匀bank、H近邻bank、HA近邻bank，以及**全196软匹配**。
- 近邻bank按当前A16目标输入与每源图的最大核值排序，图ID打破并列；不使用B输入选择bank。软匹配先只用原核W，额外图权重／截断必须单独登记，不偷偷新增门控。
- 带宽用共同196输入固定；每个n都报告λ固定0.01与λ=0.01·n/196两种约定。先分别在n64／128内比较，不把n不同的收益当匹配贡献。
- 均匀bank用五个输入无关固定排列，先模型内平均。标签乱序／等幅随机／BASE保留对照跟随新bank重新构造，不能复用旧196对照。

**进入A6的门槛：** 至少2/3任务方向余弦较同n均匀提高≥0.05、相对误差降低≥10%、≥4/5模型种子同向、数值可比覆盖≥80%；同时不因删除难例降低覆盖来制造成功。

弱支持时“停止反馈”另做风险—覆盖曲线：阈值仅由源留出或合成训练集确定，比较等覆盖随机拒绝，报告拒绝率和保留样本风险。不能仅因反馈变小称可靠。

已有基础：[D8 S4](../../experiments/tqg_d8_residual_20261031/结果解读.md)。**新局部bank、支持分层、可靠拒绝尚未完成。**

<a id="a3-sufficiency"></a>
## A3．签名是否丢信息：先区分表示问题和读出器问题

**问题：** 若η(G)无法通过R表达，增加W求解精度也不能恢复丢失的信息。

1. 在A1相同数据、同折、同容量探针下，比较H与HA；不因HA维度大额外给更大隐藏层。
2. 登记两个增强签名：`H + log(1+节点数) + log(1+边数)`；`H + 上述规模 + 平均度 + 度标准差 + 三角形密度`。图统计均不读标签，尺度只用训练折拟合。
3. 再比较“增强H”和“增强H+A”，分别只改变统计补充或A加入一个因素。对每一签名运行与A1一致的线性／MLP／KRR，明确KRR使用相应特征的核而非偷偷沿用旧H距离。增强H的各维仅用训练折均值／标准差缩放，零方差维置0；其RBF带宽平方取训练折两两平方距离中位数、下限1e−12。增强H+A采用增强H核乘原A核。此新核与原H核的差异单列报告。
4. 在源内、目标内分别评价，避免把跨域改善直接解读成信息增加。记录参数数目；增广增加输入参数，因此另附用等维固定随机噪声增广的对照，不把容量差全算信息贡献。
5. 若所有固定签名都弱，可单独训练目标诊断GNN作为更强图输入参照：只用同147目标训练图与同内部交叉验证，骨干不得将B标签用于选择。此项不是充分性证明，也不作为公平固定特征主对照；预算登记后才执行。

**候选门槛：** 增强签名相对原签名，同域NLL降低≥0.02、较等维随机增广仍降低≥0.02、至少4/5种子同向且至少2/3任务满足。若只换MLP就改善，优先称“原核读出受限”；若同探针补签名才改善，支持“原签名不足”候选，仍不证明E[Y|G]真值。

真实图通常只有单次标签，不能通过“邻居标签不一样”判定签名不充分——标签本来可以随机。真正有η真值的充分性检查放在A5。

已有证据：[D4 HA未稳定胜H](../../experiments/tqg_d3_d4_20261031/结果解读.md)，**不是已完成上述充分性检验**。

<a id="a4-complexity"></a>
## A4．核复杂度、近似误差和噪声：分别测，不把“拟合差”混成一种原因

### A4-a：真实数据的学习曲线

- 固定A1主几何，H／HA分别做源内四折及T→T。每个外层147训练图内部按输入ID嵌套取n32／64／128／147，评价池保持不变。类缺失保留并报告。
- 原带宽乘数{0.5,1,2}，λ∈{0.001,0.01,0.1,1}；只用训练内部三折选择，公开全部曲线。n变化同时公开固定λ和λ=λ_base·n/147约定（λ_base取上述网格），不能事后挑一个作为主曲线。
- 记录训练／独立留出残差MSE与NLL、有效维度`tr[K(K+λI)^{-1}]`、核谱、KRR系数的RKHS范数、原查询W范数。**||W||不等于μ的RKHS范数**，不可混写。
- 训练很好、留出差且读出范数大：有限样本／噪声放大候选。所有复杂度都训练差：核、签名或优化候选。更强探针留出好而KRR差：核选择候选。

### A4-b：已知η的合成数据，固定输入重复标签

复用D8 S1、S2和线性生成器，但新增独立源bank规模n64／196／512／1024，输入与θ／V固定，20个独立标签抽样。五生成器种子对应五模型种子。每个n的W只求一次，再换标签，避免把W改变当标签方差。

对每个固定源输入池计算：

- `g_emp`：真实抽样Y读出的反馈；
- `g_oracle`：把源Y换成已知η_S后的反馈；
- `g_T`：已知目标η_T形成的当前A条件梯度。

报告：`noise=g_emp−g_oracle`、`mismatch=g_oracle−g_T`，以及平方总误差中的交叉项`2〈noise,mismatch〉`。mismatch同时含域关系、签名、近似和有限输入覆盖，不能单称“域偏移”。

**候选门槛：** n196→1024后Oracle相对误差下降≥20%，或固定输入重复标签的误差方差下降≥20%，各要求≥4/5种子同向；分别支持覆盖／近似受样本改善或标签方差受改善，不能直接外推真实数据。若Oracle仍错方向，优先修读取／迁移关系而非只去噪。

已有相关：[D3正则](../../experiments/tqg_d3_d4_20261031/结果解读.md)、[D7-H数量](../../experiments/tqg_label_query_20261102/结果解读.md)、[D8 Oracle分解](../../experiments/tqg_d8_residual_20261031/结果解读.md)。新独立bank>196、固定输入重复标签与上述留出曲线未执行。

<a id="a5-controlled"></a>
## A5．已知规律的单因素对照：确认诊断能分清四种问题

旧D8的S2会同时改变多个条件。新增一个**签名／读出层合成单元实验**用于隔离变量，不冒充图网络端到端验证。

共同设定：原始输入G在此表示可观测变量`(x,z)`，x、z独立均匀分布于[−1,1]；主签名R=x，p固定0.5；一维梯度查询权重a(x)=x。五数据种子、源n196、独立目标1024；条件概率真值可直接算。标签噪声用Bernoulli(η)生成；每种输入重复20套标签。统一RBF核、带宽从源输入确定，原正则及A4网格都公开。

| 组 | 只改变什么 | 具体设定 | 预期可识别现象 |
|---|---|---|---|
| C0友好 | 基准 | 两域η=σ(2x)，支持相同 | Oracle查询可恢复；A1同域／跨域接近 |
| C1条件失稳 | 目标η变，输入及签名不变 | 源σ(2x)，目标1−σ(2x) | W完全不变，但真目标查询变化；仅无标签诊断不能识别 |
| C2签名丢信息 | 两域共同规则依赖被丢变量 | 两域η=σ(4z)，R仍x；恢复组用R=(x,z) | 条件稳定仍成立η_S(R)=η_T(R)=0.5，但完整输入η(G)无法由x表达；逐图条件概率误差可精确测 |
| C3高复杂度 | 只增加规律频率 | 两域η=0.5+0.4sin(kπx)，k=1／4／16 | 真η充分且跨域相同，有限样本与固定核复杂度出现困难；增n／调带宽曲线反映可学性 |
| C4缺支持 | 只移除源输入区域 | 两域η=σ(2x)，源x∈[−1,0]，目标x∈[−1,1] | 全目标包含源未约束区域；分别评价重叠与外推部分 |

**重要修正：** 对称分布下一维平均梯度可能抵消，即使C2丢信息也可能恰好答对a(x)=x。因此C2必须额外评价逐图η的Brier／MSE及点查询；另加a(G)=z的查询与R=(x,z)恢复组，明确该权重不再由旧R可测，这是签名不充分的反例，不能称符合旧核假设的查询。其余组也报告点查询，避免平均抵消掩盖失败。

C4不能用一次RBF外推恰好成功证明覆盖不需要。补一个“两种标签函数在源区完全相同、目标未覆盖区不同”的成对世界，展示源监督无法区分；改变η仅用于这一不可识别性演示，不混成C4单因素主比较。

**验收：** C0预先以Oracle查询相对误差≤0.1、≥4/5种子满足为读出单元正对照；近零真查询改报绝对误差≤0.01。C1/C2/C4主要核查预定恒等式／不可识别性（容限1e−8）和已知η误差，不强迫所有随机标签实例都退化；C3报告频率曲线，不预设单调或保证哪一k必失败。这个单元实验不能替代真实图A1—A4。

## A6．诊断找到候选后，重新证明“反馈有用”

若A1—A5支持某个具体改法，如扩大签名、局部bank或换核，仅修改这一项，另行冻结执行协议。先验收下列矩阵，不直接跑长训练。

- 比较源SGD、原H、原HA、新候选、BASE、保留BASE的标签置乱与等幅随机、完整反馈等幅null、目标梯度Oracle。
- 主β=0.1、SGD η=0.0003、fit16、A16、全B271；三任务五种子，从同一原θ开始独立单步。先初始快照，再源监督50／200快照复查。
- 方向：余弦>0、对两类null优势均≥0.05、至少4/5种子同向、数值可比覆盖≥80%。另报相对L2误差和投影外误差。
- 单步：对源SGD额外相对CE收益≥1e−4，并优于BASE及两类完整等幅null，各≥4/5种子同向；不得靠强改步长掩盖方向问题。
- 至少2/3任务同时过方向、单步门槛，且后期快照不普遍反向，才考虑登记完整适配和独立数据集复验。

以上是新候选筛选门槛，不回改旧H的D2结论。目标标签训练的诊断探针不能直接作为合法UDA候选。最终测试标签仍不用于选择候选。

## 6．执行规模、输出与停止规则

### 分阶段预算

本轮只设计，未申请或消耗新训练预算。预计CPU可完成核心冻结特征诊断，耗时必须通过无B标签pilot实测，不把估计当已运行结果。

- **第一批：A0+A1+A2-a。** A1基础配置数：15任务×模型几何×4外层折×2签名×2训练域×3探针族=720个探针选择单元；每单元含固定内部三折／超参数网格。三个SHUFFLE另加2160单元，共2880单元，不把内部拟合次数漏掉。四折网格选择每单元含3×网格大小次拟合及一次全训练集重拟合，合计34560次探针拟合；同输入／同标签的等价单元可缓存并保留逻辑记录。先5%单元pilot，按实际拟合数和时间外推，乘1.3调试余量；建议上限8 CPU核时、峰值内存8GiB。
