## 怎样读这些结果

- **训练预算结论已更新。** 旧400步静态结果不能作为“网络学不到”的依据。8192样本、batch128时400步只有6.25次遍历，6400步为100次。P0没有启动学习score闭环，也没有证明真实图所需预算。
- **估计问题与目标权衡问题并存。** 修正score方向错误不会自动消除源CE恢复力；反过来，当前源约束下收益小也不证明score永远无用。
- **经验score不是总体真值。** 它是有限样本高斯平滑密度的精确梯度；学习模型可能因平滑偏置比经验梯度更接近总体梯度。真实图数据无法直接获得总体score真值。
- **oracle是诊断工具。** 解析源后验在真实数据中通常不可得；固定斜率阈值分析不是完整TSBA收益上界。纯密度移动也不是原TSBA方法。
- **方向准确率不是分类准确率。** 99.980%对应固定双侧查询上的法向符号一致率，不能写成Mutagenicity分类准确率。

最新工程检查59项通过。工程通过、模拟机制成立、真实任务有效是三个不同层级。五种子结果保留逐项、配对差和失败情况，不将锚点或轮次数当成独立重复。
