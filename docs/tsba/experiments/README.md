## 当前能支持的结论

| 问题 | 当前证据 | 尚不能推出 |
|---|---|---|
| score 能否学到有用方向？ | 二维、8192样本、原带宽下，6400步双侧方向准确率99.980%，静态检查5/5通过 | 十六维、真实图表示或闭环适配也有效 |
| 之前失败是否只是训练不足？ | 该二维设置的400步明显不足；原DSM选模仍可能选中较差模型 | 所有性能下降都由训练步数导致 |
| 正确score能否带来足够收益？ | 当前源约束下，简化oracle平衡收益仅约+0.0108个百分点 | 完整非线性分类头的收益上界 |
| 降低边界密度是否改善分类？ | 特定相容模拟分布支持；反例说明不存在无条件保证 | 真实图数据满足低密度分隔条件 |
| TSBA在Mutagenicity上是否有效？ | 尚无当前TSBA真实图实验结果 | 旧TQG结果、模拟结果、工程测试可代替验证 |

方法需要分别满足：表示可读、类别对应有依据、局部密度方向有任务价值、score估计可靠、参数响应能执行有益位移。源CE维持语义，也可能抵消目标请求；应研究收益与源代价的权衡，不能简单认为源约束应该删除。
