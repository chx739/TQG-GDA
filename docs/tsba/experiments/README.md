## 当前能支持的结论

| 问题 | 当前证据 | 尚不能推出 |
|---|---|---|
| score 能否学到有用方向？ | 模拟二维6400步双侧方向准确率99.980%；真实16维900→7200步在四个任务/带宽面板降低平均请求RMSE约9.2%–26.8% | 模拟训练预算结论可直接迁移到真实图，或符号一致等于分类收益 |
| 之前失败是否只是训练不足？ | 二维400步、真实图900步均存在训练不足；R2继续训练改善score，但没有恢复主指标收益 | 所有性能下降都由训练步数导致 |
| 正确score能否带来足够收益？ | 当前源约束下，简化oracle平衡收益仅约+0.0108个百分点 | 完整非线性分类头的收益上界 |
| 降低边界密度是否改善分类？ | 特定相容模拟分布支持；反例说明不存在无条件保证 | 真实图数据满足低密度分隔条件 |
| TSBA在Mutagenicity上是否有效？ | R3 的 NLL 配对收益依任务而变。R4 中 A2 相对源头的 Accuracy 在 6 个方向改善、1 个持平、5 个退化，12 方向等权平均低于两个零请求对照。 | 密度请求的增量能跨任务稳定复现 |
| 扩尺度能否验证低密度类别分隔？ | 加倍半径有22条记录通过双侧独立图支持，加倍带宽改善ESS；全部六面板仍无双侧B支持达标点 | 条件通过率为0%，或低密度分隔不存在；正确结论是当前条件比例NA |

方法需要分别满足：表示可读、类别对应有依据、局部密度方向有任务价值、score估计可靠、参数响应能执行有益位移。源CE维持语义，也可能抵消目标请求；应研究收益与源代价的权衡，不能简单认为源约束应该删除。

## 文件组织与存档

`synthetic/`和`real-data/`是分类阅读入口。历史日期目录、报告、执行前JSON协议及归档索引保留原路径，避免破坏已发布链接和证据来源。历史结论按各轮实验的评价范围阅读。

各已执行报告链接到日志、CSV、checkpoint清单和本地不可覆盖压缩档。GitHub保存代码、报告与必要标量证据，大体积模型/输入张量保存在报告注明的本地档案。原始方法设计正文保留为历史设计，不用其“尚未实现”状态判断当前进展。

R1b 与 R2 复用约 72%/10%/18% 的源角色和目标 A/B 划分。R3 使用 868/216 源训练和验证划分重新训练，封存后计分整个目标域。R4 采用各源域独立划分和完整目标域评价，主终点是第 30 次尝试的 Accuracy，同时报告 NLL、BA 和 Macro-F1。
