## 分阶段验证链

| 顺序 | 内容 | 能支持的结论 |
|---|---|---|
| R0 | raw图重建、角色隔离、独立label broker及工程验收 | 输入和执行可信，不证明方法有效 |
| R1-A | 5个源GNN；等标注预算源/目标探针及规模、置乱、先验对照 | 表示可读性和实际起点的观察到的改善空间 |
| R1-B | 参考边界的双侧真实样本、类别组成与KDE相对密度 | 类别相关的低密度结构是否有局部证据 |
| R1-C | 源法向扫描、密度下降方向、参考交点/共识 | 初始源边界附近的局部方向是否相容 |
| R1b | warm参考、六尺度、静态score、单步正常/反向/零/同矩阵源对照 | 已完成；NLL与BA分离，score增量弱，源项主导 |
| R2 | 完整30轮、score预算×边界权重、几何源/正常/反向对照 | 已完成；学习score与KDE的平均NLL均未超过起点，源对照自身也恶化 |
| R3 | 两项干预、M11 参数敏感性、固定输出缩放对照 | 全目标域开发评价完成，配对密度收益依任务而变 |
| 后续独立确认 | 另行登记的方法修改与独立评价 | 待登记 |

R1 至 R2 固定0→1/0→3、种子3405–3409。源角色由每个cfg.seed分层随机生成，保持先10%验证、再对剩余80%训练/20%诊断（预期779/109/196）；每个目标域A271/B271；这些运行的final标签未解析。R3 沿用任务与种子，按 SEGA 角色规则合并 ref 和 fit，使用 cal 验证，并在封存后为两个完整目标域计分。原始图输入允许全部目标池。原始数据图类别与节点/边输入标签分开处理。

R1只做静态诊断；R1b另行登记并执行score训练与一次分类头更新。R2按用户新协议运行完整30次尝试，使用128图批次和动态边界；没有更改GNN、pooling或生产算法。直接KDE仍是有限样本密度估计，不是总体oracle；目标监督头仍是参考而非正确边界。低支持量不能当作低密度类别分隔的反证。

## 与历史计划的区别

旧E3只检查可读性/覆盖，新R1增加双侧类别相关密度结构和源局部方向诊断。匹配探针147张改为**118优化+29内部验证的总预算**，最大800更新；B只在S2后评价，不能选头/停止点/尺度。源初始和LR参考以解析距离核验投影，明确数值失败与边界超半径。

新的分阶段开发协议先诊断再决定R2，替代[旧§5–7](../validation-plan.md#5-真实图数据与标签协议)先全部封存E4再开诊断标签的顺序。A/B有历史观察，不称盲测；根据结果修改方法后，独立确认另定协议。旧TQG真实数据结果只作背景，不能归入当前TSBA证据。

## R1 至 R2 的数据划分历史

SEGA只用于核对域索引：四域大小1084/1084/1084/1085，历史索引与参考包逐字节一致，两两互斥并覆盖4337图。源779/109/196和目标A/B/final是独立实验角色，均在对应域内互斥且完整覆盖。v2曾误将域索引核对扩展为SEGA的I_ref/I_fit/I_cal角色；SEGA算法角色改动已撤回。v4按用户要求独立做源分层，允许受限数据分配器在R0读取源标签；这不是调用SEGA角色函数，也不把诊断标签交给源训练器。A/B仅是固定哈希伪随机分组，非类别分层。

## v4：源划分随cfg.seed变化

按用户要求，源域采用独立的两级类别分层随机划分，seed与模型cfg.seed一致，保留约72%训练/10%验证/18%诊断。每seed保存独立角色清单；同seed跨任务/对照复用。旧seed431源成员只作为历史来源，目标A/B不变。R0仅受限数据分配器可以读源标签做分层，源训练器不能获得诊断标签。196张诊断数据只服务本轮研究，不是TSBA算法必需；本修订不引入任何SEGA算法角色。
