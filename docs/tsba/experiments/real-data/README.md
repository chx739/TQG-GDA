# 真实图验证：Mutagenicity 分阶段开发计划

更新：2026-11-10。**状态：设计阶段，未启动真实图训练或TSBA适配，没有效果结果。** 本页整理当前建议，不代表已经冻结所有执行参数。执行前需要补齐数据导出器、独立评价接口、探针预算及资源上限，并保存不可覆写协议。

## 1. 第一阶段：源模型、表示与边界起点

目标是确认存在值得修正且可被当前分类模块修正的边界。此阶段训练真实GNN，冻结后做诊断；不训练score、不运行分类适配。它尚不直接检验低密度移动是否改善分类。

| 项目 | 固定范围 |
|---|---|
| 数据/域 | Mutagenicity 4337图；SEGA按图规模构造域，非官方自然域 |
| 方向与种子 | 0→1、0→3；3405–3409 |
| 源训练/验证/诊断 | 779/109/196张；诊断池不并入源模型训练 |
| 目标域1 | A271、B271、final542 |
| 目标域3 | A271、B271、final543 |
| 标签权限 | A用于隔离监督探针，B用于开发评价；final标签不读取 |
| 输入权限 | 如使用全部目标输入，明确为传导式设置；标签不得进入训练payload |

角色ID及划分文件哈希已只读核对；执行前仍须复核原始图缓存、特征和图ID映射。节点14维、边3维为历史元数据；当前主GIN不使用边属性。五个源模型必须使用当前TSBA重新训练，旧TQG checkpoint不能替代。

### 1.1 源模型基线

沿用GIN三层、hidden64、输出16维、源训练100 epochs，源验证最低CE选模。相同种子跨目标域复用源模型；冻结参数、BN统计、dropout和由源训练表示确定的坐标。

保存训练曲线、全部checkpoint选择信息、源诊断池及目标B逐图概率。报告BA、NLL、每类召回、混淆矩阵、预测比例。不能用源训练准确率代替泛化表现。

### 1.2 冻结表示可读性

复用旧E3的匹配监督设计：源诊断196张做四折，每折147训练/49源内审计；目标A按预先固定ID哈希取147训练，在同一B评价。使用LR和hidden32 MLP，源/目标匹配初始化、标签数量与训练预算；加入同预算标签置乱和训练类别先验对照。

原E3登记200次full-batch更新；执行前需明确优化充分性检查及固定预算终点，不能看到B结果后加训练或挑最优快照。所有探针在完整16维表示上工作，二维可视化不能代替分类证据。四折先在种子内平均，不当成20个独立种子。

目标探针较强支持表示中有可读信息，源/目标匹配探针差异支持分类规则存在迁移缺口；都不是UDA方法、性能上界或密度假设证明。探针都差时先查训练与容量，不能直接断言表示无信息。

### 1.3 无标签边界与规模检查

固定初始分类头，在目标输入上使用原带宽和投影半径，保存有效/唯一锚点数、覆盖率、投影距离/半径、根残差、法向幅度及所有失败原因，不因覆盖少临时放大半径。

域按图规模构造，而编码器使用sum pooling：记录表示范数与节点/边数关系，增加仅图规模特征的匹配监督诊断基线。相关性本身不证明失败；不据此自动修改pooling。虚拟边界点没有真实图标签，不给它们人为标注“正确类别”。

## 2. 分阶段决策

| 第一阶段观察 | 后续行动 |
|---|---|
| 目标探针优于先验/置乱及匹配源探针，且有有效边界 | 进入静态score与单步请求诊断 |
| 探针均差 | 先排查特征、编码器、优化和容量 |
| 表示可读但边界覆盖不足 | 先定位投影/半径/边界位置，不直接扩预算 |
| 源模型已很好 | 报告剩余错误与改善空间 |
| 表示主要体现规模且类别可读性弱 | 先研究表示问题 |

第二阶段才直接检验“低密度方向是否有任务价值”：固定共同边界查询，比较学习score、经验KDE及重采样稳定性，再做正向、反向、置乱、零请求和纯源更新的单步控制。先封存候选与概率，再用B评价BA/NLL，并记录源代价、实际边界位移、接受率。具体预算和控制配置另行冻结。

真实图没有总体score oracle；KDE与网络一致不证明方向正确，稳定也不等于准确。P0的6400步不是16维真实图的充分预算保证。源约束可能限制有效位移，须区别“方向无用”和“有用方向没执行出来”。完整闭环及PL/熵最小化对照放在后续阶段，不预先声称有效。

## 3. 开发标签与旧协议的关系

本页将旧E3拆为先导实验，再据结果决定后续工作。**这调整了旧计划§5要求E3/E4全部封存后才查看A/B的执行顺序。** 后续执行须登记为新的分阶段开发协议，不将基于A/B的方案修改说成没有开发选择。

A/B已有旧TQG观察历史，不能称新盲测；final标签本阶段始终禁用。旧TQG真实数据研究只支持背景与划分来源，不属于当前TSBA结果。新阶段保存数据角色、标签访问记录、配置/commit、模型/表示、逐图概率、日志、失败与哈希；结果完成后再新增日期报告，不提前将计划标为完成。
