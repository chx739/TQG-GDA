# 全量源查询实验：三个迁移方向完整结果

实验按用户要求比较全部query n51／全部源训练图n250 × odd／odd+even，配四个基线。单位为balanced accuracy百分比，均值±五个模型种子标准差；固定200步为主要结果。

| 方法 | 0→1 | 0→2 | 0→3 |
|---|---:|---:|---:|
| fit-only 源模型不动 | 56.28 ± 0.94 | 64.47 ± 1.35 | 60.06 ± 1.00 |
| 继续源 fit 训练 | 56.49 ± 0.46 | 64.28 ± 0.34 | 61.05 ± 1.65 |
| 全源标签训练 | 56.49 ± 1.06 | 63.44 ± 1.72 | 59.51 ± 1.71 |
| 简单置信度伪标签 | 56.49 ± 0.46 | 64.28 ± 0.34 | 61.15 ± 1.96 |
| 全部 qry n51，odd+even | 57.08 ± 0.66 | 64.16 ± 1.10 | 60.40 ± 0.69 |
| 全部 qry n51，odd | 56.84 ± 0.48 | 63.94 ± 0.62 | 60.78 ± 0.77 |
| 全部源训练图 n250，odd+even | 56.49 ± 0.46 | 64.28 ± 0.34 | 60.86 ± 1.67 |
| 全部源训练图 n250，odd | 56.49 ± 0.46 | 64.28 ± 0.34 | 60.96 ± 1.53 |

## 白话解读

1. **全部用满51张query，没有形成跨方向稳定收益。** odd+even在0→1相对仅源fit训练提高0.59个百分点（3胜2平0负），但0→2/0→3为−0.12/−0.65个百分点。仅odd在0→1提高0.35个百分点，其余两个方向仍略低。
2. **用满250张更接近仅源训练，但未带来额外分类优势。** 两种响应在0→1和0→2均与fit基线逐种子同分；0→3仍略低。不能把“比某些小query设置少退化”直接说成迁移有效。
3. **even没有稳定的增量价值。** n51时，加入even在0→1/0→2均值略好，在0→3更差；n250时没有均值收益。此处比较同K，响应列数不同，不能单独识别纯曲率信息的作用。
4. **同分不表示没执行反馈。** 全部TQG训练步都有有效探测方向；n250平均纠错幅度普遍小于n51。另做了30对只读参数比较，n250模型均与各自fit基线参数不同，详见model_difference_audit.json。
5. **0→1的小幅改善对选点规则不稳健。** 固定200步的n51 odd+even为57.08，但源验证选点后为56.14，对应fit基线为56.41；不能从两套选点规则里择优汇报。

这些结果支持“扩大query能减轻部分退化，但单独扩大到51或250尚未解决可迁移监督的读取问题”。它们没有证明所有响应迁移方法无效，也不能把n250的表现只解释为数据量作用，因为它同时加入了预训练见过的199张图。

## 实验设置

所有TQG组采用相同199-fit源预训练起点（700步训练预算内按源验证CE选点）、相同源fit分类主损失、目标图产生方向、K4、rho=.05、固定ridge=.01、反馈权重.1、Adam lr=.0003、float64，适配200步。每步用完整51或250张源图拟合响应组合权重；不加投影、局部匹配或CV选正则。odd+even为8列、odd为4列（方向全部有效时），比较同方向数而非同响应列数。

n250包含已参与预训练的199张fit图，n51为初始未参加预训练的query图。因此n250/n51差异包含样本数、样本角色和残差分布变化，不能只归因于扩大样本量。28张源验证图从不并入回归。全源CE基线使用自己的250源图预训练起点。

0→2/0→3的fit CE、全源CE复用已核验v1作业，先重放其前10步模型与Adam状态并逐位核对。伪标签在本轮配对调度下新跑。0→1所有训练方法均按当前调度新跑，源模型仍只用源0训练，目标开发/最终ID沿用最早固定划分。新适配85个、复用适配20个、冻结参考15个，无新增源预训练。

两个独立进程各用一个CPU线程；未开始作业的恢复文件临时写NVMe并在结束后按SHA256逐文件核验归档。未改数值代码，未根据目标成绩调整方法。存在存储差异，耗时不用于算法速度比较。

## 结论范围

每组仅五个模型种子，目标开发集此前已被观察。均值±标准差不是置信区间，也不代表统计显著。目标final标签未用于训练、选模或评价；原始缓存包含标签，训练视图不暴露目标y。

两进程累计墙钟（含I/O）约53.4分钟；本次整体经过约35.1分钟；GPU0小时。

完整逐种子指标见[results.csv](results.csv)；全部基线配对差及纠错幅度见[results_summary.json](results_summary.json)。
