## 1．我建议先解决什么

**先让源监督读得准、迁得动，再证明梯度查询值得做。** 当前最有证据支持的两条改进是：从目标附近选源经验，以及改善核读出。先在 Mutagenicity 上进行，PROTEINS 用于后续复验和有限监督诊断。

本轮目标应是回答“哪一步有问题、哪个最小改动有效、是否值得继续”，而不是要求代理一直尝试到出现正结果。ICML 2027 是长期研究目标，本轮结果不能直接换算成接收概率。

| [D8](../../results/tqg_d8_residual_20261031/结果解读.md)：友好条件可以恢复方向，替换为真实源条件概率后明显改善；失配情况下仍可能失败 | 将有限标签噪声和跨域关系问题分开 | 真实数据只缺更多标签 |

两数据集分别使用各自的源 fit 预训练模型。本轮条件诊断没有重新预训练骨干，也没有连续 TQG 适配。诊断探针训练不能计作完整模型训练。

## 3．改进顺序

| 顺序 | 改动或对照 | 白话问题 | 通过后做什么 |
|---|---|---|---|
| 0 | 核对简单残差 KRR 与 MEAN 的等价性；补源标签教师基线 | 复杂查询是不是只完成了普通回归已能完成的工作？ | 明确贡献归属和公平对照 |
| 1a | A2-b：H/HA 近邻 bank 对同 n 均匀 bank；全 196 保留 | 目标问的问题，交给更相关的源图，答案会不会更好？ | 候选进入 A6 |
| 1b | A4-a：带宽、正则、样本量曲线 | 同样的源经验，是不是目前读得太不稳定？ | 冻结源端选择规则，再进入 A6 |
| 2 | A6：方向、标签归因、独立一步更新 | 答案是否真能让目标模型往正确方向动？ | 两个任务以上通过后，才进入连续训练 |
| 3 | 支持不足时收缩/停止反馈，作为单独增量 | 有用的反馈能否少犯大错？ | 与等覆盖随机拒绝比较，再决定保留 |
| 4 | 连续适配及 PROTEINS 复验 | 独立一步的帮助能否积累，能否跨数据集复现？ | 形成适用范围和论文贡献判断 |

1a 与 1b 都有依据，可以复用同一冻结模型与缓存进行。先分别改变一个因素；只有独立结果支持时，才增加唯一一个“局部 bank＋读出改进”组合，避免把调参空间无限扩大。

暂不优先增加 GNN 深度、训练一个新相似度网络、加长适配、放大反馈系数或同时叠加多个模块。现有探针已经说明 Mutagenicity 的固定特征有可利用的信息，但尚未说明当前方式能把它转成可靠更新。

## 4．必须加上的简单对照

### 4.1 残差 KRR 再求梯度，与 MEAN 的关系

按照 v2 记号，令块核为 K、源残差为 r_S，目标响应平均矩阵为 B_T。在**同一核、相同正则、相同源/目标图、同一个 V、没有额外裁剪且停止读出梯度**时：

```text
alpha = (K + lambda I)^(-1) r_S
mu_hat_T = K_TS alpha
d = B_T^T mu_hat_T
  = H_ST^T (K + lambda I)^(-1) r_S
  = W_MEAN r_S
g = -V d
```

这来自[方法公式](../../method/design.md)和[D3 已有等价关系](../../../research_plans/tqg_v2_20261031/D3_calibration.md)。它是代数关系，不是本轮新实验发现。

因此，不能把“先预测残差、再形成目标梯度”的同核版本包装成独立的新算法。JOINT 的额外作用、目标响应签名的作用、局部源选择的作用，需要各自证明。ISO 与 MEAN 还须按 D3 的正则映射比较，不能只比较超参数名字相同的数值。

### 4.2 源标签教师

冻结同一个骨干，用 query 标签训练简单 LR 教师。给目标图预测软标签，再形成目标 CE 反馈。教师只看源标签，不使用目标 A/B 标签训练或选参数；这与历史 T→T 诊断探针不同。同数量主比较使用相同源 bank；全196教师另列。主教师用H，检验HA的查询机制增量时另配同HA输入教师，避免把信息量差异当成查询优势。

用同一 V 投影的教师反馈作公平主对照，完整梯度作附加参照。报告教师的直接预测，以及教师反馈加入源监督后的独立一步效果。正则用源内部交叉验证选择；乱标签教师必须重新训练并走同一选择流程。

若简单教师已经解释收益，适当结论是“普通监督读出/教师迁移有效，TQG 特有机制的增量尚未证明”。若新 TQG 超过教师，还要检查是否来自更多标签、更有利的正则、反馈幅度或更大的参数子空间。

## 5．两项主要优化如何做

### A2-b：目标选择源 bank

沿用[原 A2-b](../assumptions_20261103/README.md#a2-support)：query196 内 n64/128，同数量比较均匀、H 近邻与 HA 近邻；保留全 196。带宽用共同 196 输入固定，近邻只根据目标 A16 输入选，不根据 B 输入或标签选。

五个随机排列先在同一模型内汇总；它们不是五个新模型种子。固定 lambda0.01 与 lambda0.01×n/196 两种约定都报告。初轮保留原 JOINT 读取，以隔离 bank 的作用；若后续换 MEAN，作为单独版本重新登记。全196原核已经提供一种软匹配，不能不经消融就再加入新权重层。

风险是：删除不相关样本也会删除监督量；近邻可能仅共享规模等无关因素。因此必须有同数量随机 bank、类别构成记录、支持与覆盖记录，以及重新构造的标签置乱/等幅对照。不能只挑看起来改善的目标图。

### A4-a：读出复杂度

沿用[原 A4-a](../assumptions_20261103/README.md#a4-complexity)的四外折、三内折、n32/64/128/147、带宽乘数和 lambda 网格；明确带宽乘数作用于 s 还是 s²，执行前写进配置。源内选择只能用源训练折；T→T 只作诊断。

重点记录训练/留出残差 MSE、NLL、Brier、原概率越界率、核谱、有效维度、RKHS 系数范数及 W 范数。KRR 恢复概率越界和裁剪可能放大 NLL；只靠裁剪使 NLL 好看，不算方向质量改善。

保留简单 LR 教师。若原核可学性不佳但 LR 可学，再考虑“读取标签概率”与“读取残差”的模型失配；本轮先不增加新的大型网络。

A4 的预测指标用于定位问题，不是梯度方法的最终成败定义。即便全函数预测收益有限，某个预先登记的查询读出仍可能改善目标梯度；反之预测变好也可能无法改善梯度。因此最多保留每条路线一个候选进入 A6 的完整矩阵，选择理由提前写清。

## 6．何时继续，何时停止

沿用 A6：至少 2/3 任务同时满足方向和独立一步门槛，各要求至少 4/5 模型种子同向，并在源监督 50/200 快照复查。方向与幅度分开；真实逐图标签必须胜过保留 BASE 的标签对照。采用目标经验标签梯度作诊断时，不将它称作已知条件期望梯度。

相对 CE 收益 1e-4 是无量纲比例，相当于 **0.01% 相对 CE**，不是 0.01 个准确率百分点。原 A6 的归一化分母需在执行前从旧实现核对并明确，不能在不同对照间悄悄换口径。

如果只在局部有效，报告覆盖率与全体目标风险；可靠拒绝需和等覆盖随机拒绝比较。不能把只评价简单样本后的分数提升当作整体方法进步。

如果两条最小改动和简单教师都未提供可靠逐图标签增量，完成失败归因并停止本轮搜索。下一步可以是更稳定的签名、更多独立监督或更明确的迁移假设；不能靠不断更换种子、任务和阈值挽救结论。

如果通过 A6，先只把通过的单一候选带入连续适配，保留四个原始基线、旧 H/HA、MEAN、教师与标签归因对照。完整训练优先复用预训练起点，后续 200 步；所有曲线和最后一步一起报告，不能按目标 B 选最优轮次。

PROTEINS 使用自己的五个预训练模型复验冻结候选。若要增加 query 或解释小样本，另登记划分/预算并必要时重训骨干；不能把旧骨干已见的199张 fit 图直接混进原独立query51，仍声称监督读取独立。

## 7．理论上的优化目标应更准确

我们真正需要的是目标 Jacobian 加权后的误差小。只在源、目标共同支持、两域条件函数都有定义的区域，可以把查询误差写成：

```text
T_T[mu_hat_S - mu_T]
= T_T[mu_hat_S - mu_S] + T_T[mu_S - mu_T]
  读取/估计误差                  迁移失配
```

共同支持之外需单列不可约束的部分，不能任意延拓源条件函数后声称已经估计到真规律。完整图任务充分性的误差也不能被这两项自动消除。

第一项可尝试用更好的核、正则、更多独立标签改进；第二项不会因为求解器收敛而自动消失。目标梯度查询可能只需要比“所有图的标签概率都完全相同”更弱的条件，但加权后的正负误差也可能偶然抵消，必须用多个目标块/快照验证。

后续值得研究的是“只读取有源证据约束的目标查询分量，并说明适用边界”。它目前是研究建议，尚不是已验证方法；输入距离和 E(W) 都不自动是可靠误差证书。

理论背景可参考 [Support and Invertibility in Domain-Invariant Representations](https://proceedings.mlr.press/v89/johansson19a.html)：讨论表示丢信息及源支持覆盖；以及 [Impossibility Theorems for Domain Adaptation](https://proceedings.mlr.press/v9/david10a.html)：说明仅凭源标签和无标签目标输入，重加权不具有无条件的成功保证。这些结论支持谨慎限定迁移条件，不证明当前近邻方案一定有效。
