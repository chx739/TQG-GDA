# Mutagenicity：TQG v2 完整实验验证

**结论：当前默认配置下，v2 尚未获得跨任务稳定收益。** 相对匹配 SGD 的源 fit 基线，0→1 为 +0.264 个百分点，0→2 为 −0.077 个百分点，0→3 为 −0.0015 个百分点（基本持平）。0→1 的平均提升主要来自种子3405；普通KRR和打乱query标签对照并未稳定落后。

Mutagenicity 共4337张图，四个域沿用SEGA提供的边数规模索引，不是数据集官方域划分。fit/query按照类别分别取约80%并向下取整，合计779 fit和196 query；query标签通过反馈参与训练，不是验证标签。

源模型沿用 SEGA 通用配置：2层 GINE、hidden32、mean readout、14维节点标签、3维边标签；源预训练100 epoch，fit/all-source 分别2500/3100次更新。复用原有10个源模型，没有重复预训练。

源域1084张：975训练＝779 fit＋196独立 query，另109源验证。主版本每步使用全部196张 query、16张目标图，完整有效目标梯度空间；适配200 step，无动量SGD、lr0.0003、反馈权重0.1、FP64。核尺度由源query确定，lambda_W=0.01；校准最多200次内部迭代，绝对/相对gap容差1e-8/1e-6。

四个TQG相关设置共享fit预训练起点和源fit主损失；全源监督基线另用975张图预训练和继续训练。伪标签阈值0.9。目标输入采用transductive设置；开发集各542张，final标签始终未评价。

## 预设问题的回答

- 相对继续源fit训练，满足“平均差为正且至少3/5种子获胜”的任务数：1/3；预设门槛为至少2个任务，未达到。
- 相对普通KRR，主版本平均分更高的任务数：2/3；达到预设的至少2个任务门槛，但仍需结合增幅和种子波动。
- 四个查询设置共12000步，数值回退0步；零秩回退0步。完整收敛率、秩和执行等式误差见training_diagnostics.json。

## 结果怎样理解

1. **主假设未通过。** 只有0→1满足平均提升且至少3/5种子获胜，未达到预设的至少两个任务。该方向五种子的配对变化为+1.284、+0.154、−0.128、+0.145、−0.137个百分点，除种子3405外，其余四个的平均变化仅约+0.009个百分点。按源验证选点后，0→1的主版本与源fit基线只差约+0.01个百分点。
2. **联合校准的额外价值尚未得到有力支持。** 相对KRR，三个方向分别为+0.029、+0.065、−0.023个百分点。虽然两个方向均值为正，幅度很小，不能据此主张复杂校准稳定有效。当前也没有匹配不同目标下的有效正则强度：固定Ω=I/r时，联合问题相当于KRR使用lambda_W/2，因此后续应增加KRR lambda=0.005或固定Ω的对照。
3. **正确query标签没有体现稳定优势。** 打乱的只是196张query标签，预训练和源fit主损失仍使用真实标签。打乱对照在0→1反而更高，0→3也略高；这使我们无法把小增益明确归因于正确源监督迁移。打乱同时改变残差幅度，不能由此证明真实标签完全没有用。
4. **响应相似性没有稳定增量。** 加入响应核相对仅表示核在0→1/2略好，0→3反而低约0.40个百分点。核的改变也改变反馈幅度，尚未做反馈范数匹配，不能只凭分数判断响应方向是否更可迁移。
5. **反馈确实执行，但这不证明估计方向正确。** 主版本加权反馈与源梯度的范数比中位数约0.21/0.21/0.22；全部60个查询方法模型均与配对源SGD参数不同，差异范数范围0.00281–0.05456。不是辅助梯度完全没有参与更新的情况。
6. **损失与分类指标要分开看。** 0→3普通CE均值从源fit的0.97412降到v2的0.96482，但balanced accuracy基本不变；0→1的BA小涨而CE略变差。当前没有离线比较估计梯度与目标标签所对应的批次梯度的方向，不能声称已经准确恢复了目标分类梯度。
