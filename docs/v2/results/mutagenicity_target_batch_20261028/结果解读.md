# 目标batch对照：结果解读

**结论：增大目标batch让反馈幅度波动更小、目标图覆盖更充分，但未带来跨任务稳定的分类收益，计算开销明显增加。当前证据不足以支持仅靠增大目标batch解决TQG的效果问题。**

本轮只改变目标batch16/32/64；源fit每步16、query全部196，复用同一组源预训练模型，适配200步，SGD lr0.0003、反馈权重0.1、FP64。0→1/2/3各五种子。batch16和源SGD为已核对配置、数据、模型哈希及数值代码的历史复用；32/64为30次新适配。

B_frozen表示源模型不动，B_fit表示继续源fit监督，B16/B32/B64表示TQG的目标batch大小。

**主指标：固定200步的balanced accuracy（%），均值±五个模型种子的样本标准差。**

| 方法 | 0→1 | 0→2 | 0→3 |
|---|---:|---:|---:|
| B_frozen | 76.72 ± 1.38 | 67.34 ± 2.56 | 61.67 ± 3.36 |
| B_fit | 76.76 ± 1.50 | 67.37 ± 2.76 | 61.82 ± 3.48 |
| B16 | 77.02 ± 1.28 | 67.29 ± 2.94 | 61.81 ± 3.61 |
| B32 | 77.13 ± 1.40 | 67.26 ± 2.94 | 61.89 ± 3.63 |
| B64 | 77.08 ± 1.42 | 67.23 ± 2.89 | 61.96 ± 3.61 |

## 增大batch是否更好？

- B32相对batch16，在0→1/2/3分别为+0.113／-0.032／+0.080个百分点。1/3任务同时满足平均差为正、至少3/5种子获胜，未达到本轮预设支持条件。
- B64相对batch16，在0→1/2/3分别为+0.058／-0.065／+0.143个百分点。1/3任务同时满足平均差为正、至少3/5种子获胜，未达到本轮预设支持条件。

这只是五种子、固定划分、固定超参数下的探索性证据，不等于统计显著性或跨数据集有效性。不得按每个任务挑最好的batch组成一个新方法结果。源验证选点是次要结果，见run_report.md。
