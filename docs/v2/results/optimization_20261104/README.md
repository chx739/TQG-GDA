# 局部源经验与核读取优化：本轮结论

2026-11-04。研究目标：让真实逐图源标签产生可靠的目标梯度反馈，并检查TQG相对于简单源标签教师的额外价值。

**本轮有限候选未通过。** LOCAL与KERNEL均0/3任务通过冻结A6综合门槛。依协议，不运行组合、连续200步适配、支持门控或新增PROTEINS复验。此结论不是“所有TQG不可能有效”，也不是“源标签完全不能迁移”。

## 对原因的判断

1. **当前求解与执行路径并未显示审计不一致。** 读出重算、控制系数、标签边界、教师选参、记录指标以及普通模型FULL/BASE参数步重放通过；这不是“全部代码不存在任何错误”的证明。
2. **源内预测目标与目标反馈目标不一致。** 核选参优化源留出NLL，无法保证目标梯度误差小；源端更好的选择在目标上仍可能更差。KERNEL大多数块选择强正则，不证明目标端也最优。
3. **近邻不能保证标签规律相容。** 删除远图还减少监督约束，局部bank可能保留相似外观而不是相同任务规律。
4. **真实标签不是稳定增量来源的证据仍不足。** KERNEL在0→2/3的FULL弱于BASE；LOCAL0→3有平均增量但种子、幅度控制与快照不一致。BASE包含源类比例、模型预测和可能受源端选择影响的W，不是“无源标签”的算法。
5. **本轮不能唯一定位到数据少。** 条件失配、有限源标签、签名信息和模型状态依赖仍混合存在。PROTEINS既有小样本结果不能作为单因素证明。

## 下一轮建议（本轮未启动）

优先重审迁移假设：什么源条件在目标上应保持，哪些目标查询分量有源监督约束？先定义可被证伪的条件，再设计稳定签名或支持诊断。若研究标签数量，应新增独立监督并登记新的数据预算；不要把已用于骨干训练的fit图混入旧query后继续声称独立读取。

若研究新的读出目标，应明确源预测误差与目标Jacobian加权查询误差的区别，并保持普通LR/MEAN基线。无目标标签时不能直接优化未知的真实目标查询误差。任何新的相似度网络、标签读取方式或约束都应作为下一轮有限候选重新登记，不能在本轮结果后无界搜索。

应保留的主张：友好条件下机制可工作；源特征含可读标签信息；本轮部分简单源教师存在预测迁移；局部/核改动的适用边界已有实证。

应撤回或不提出的主张：已实现跨任务稳定源标签梯度迁移；响应距离或JOINT有稳定机制收益；近邻就是可靠性；源预测改善等于适配有效；TQG优于普通教师；已有ICML级完整正面贡献。

论文级证据仍缺：更明确的可迁移条件、跨任务稳定的真实标签增量、与简单教师的机制优势、冻结候选的连续适配以及新的独立评价协议。当前开发A/B历史已观察，不能称未见测试。
