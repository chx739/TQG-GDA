# TQG 失败原因与改进方案

2026-10-24。针对原设计稿、冻结实现及已经完成的 PROTEINS 0→2 / 0→3 开发实验。

**判断：当前证据更支持“源残差拟合不稳定、迁移关系缺少保证、反馈执行可能改变纠错方向”，而不是一个明显的公式抄错或代码符号错误。** 原版 TQG 的有效性没有通过本轮验证；这不等于所有基于响应的迁移方法都不可行。下一步应定位和修改机制，而不是只增加训练轮数或算力。

本次复核 44,800 条既有诊断、12,000 个训练步和 130 条分类评价；另做 17 项独立数值核查、60 个真实检查点采样块的只读机制检查，以及合成数学反例。没有启动新的真实数据训练，没有使用最终保留集标签进行评价或调参，冻结代码和原方案未修改。以下归因属于事后分析，不能替代控制变量实验。

## 1. 实验究竟在哪里失败

| 方法 | 0→2 | 0→3 |
|---|---:|---:|
| 冻结源模型，不适配 | **64.47** | **60.06** |
| 同一源模型，仅继续源 fit CE | 62.36 | 58.01 |
| 随机方向 TQG | 61.25 | 51.85 |

主要比较固定 200 个适配步；最后一行是补充的选点规则。原版 TQG 比相同初始化、相同源 fit 数据的 CE 对照低 **0.89 / 5.49 个百分点**，所以问题不只是全源 CE 多用了源标签。它比随机方向只高 0.22 / 0.67 个百分点，两任务均仅 2/5 种子胜出，没有支持稳定的目标方向优势。源验证集选点可以缓解退化，仍不如冻结参考。

**最直接的断点甚至发生在跨域之前：权重在当前拟合源图上有效，换一批源图就差了。** 源预训练状态、每次 16 张 query 图时：

| 任务 | 拟合用源图 | 另一批源图 | 另一批目标图 |
|---|---:|---:|---:|
| 0→2 的残差 MSE 改善 | +0.079 | −0.215 | −0.297 |
| 0→3 的残差 MSE 改善 | +0.075 | −0.148 | −0.454 |

正值表示比“预测纠错量为零”好，负值表示更差。岭回归允许 a=0，所以它本来就能降低拟合样本的目标；**当批拟合下降不是学到可迁移规律的证据**。把 query 从 16 增至 32 能明显减轻负收益，但尚未稳定解决问题。源残差 MSE 差也不严格推出目标参数步一定差，还要检查实际梯度。

## 2. 先校正一个关键心智模型

原版实际执行的是：

> 目标图产生探测方向 → 同方向测源/目标响应 → 用源标签拟合响应组合权重 → 在目标图预测输出纠错 → 经反向传播、源 CE 和 Adam 更新参数。

**组合权重 a 是“响应特征的组合权重”，不是最终参数变化比例。** 原版并不直接做 θ←θ+Va。

用最少的公式表示：

\[
r_S=\operatorname{onehot}(y_S)-p_S,\qquad
a=\arg\min_a\frac1{n_S}\sum_i\|\Phi_{S,i}a-r_{S,i}\|^2+\lambda\|a\|^2,
\]
\[
d_T=\Phi_Ta,\qquad
L_{fb}=\frac1{2n_T}\|z_\theta-\operatorname{sg}(\bar z+d_T)\|^2.
\]

这里 Φ 是各个探测方向产生的响应；d 是预测纠错量；sg 表示把参考值当常数。每步重算一次参考，再以“源 CE + 0.1 × 反馈损失”更新一次。

因此，不能用“源标签选出了正确的参数方向，所以目标照着走就对了”解释原方法；它并没有获得这种保证。

## 3. 数学上有三处需要额外依据的跨越

### 3.1 目标敏感，不等于与标签有关——对应 §3.5

目标方向的未归一化形式是 u=J_Tᵀξ/√n_T，J 表示输出对编码器参数的变化率。它倾向选出“容易让目标输出变化”的方向。

白话例子：图变大能让模型置信度大幅变化，但图大小未必是正确分类依据。探测可以找到这个方向，却没有标签告诉它该不该利用这个方向。按响应大小归一化只调整长度，不会赋予分类意义。

本轮目标方向在多数诊断中落后随机方向，源标签打乱后也没有稳定变差。因此“目标选择带来了额外的可迁移监督”目前没有证据支持。但不能反过来说乱标签更有用，排列保留了类别比例和总体偏置。

### 3.2 源响应和标签的关系，不保证在目标域一样——对应 §3.8→3.9

假设源图与目标图遇到某个探测都产生同样的“第一类分数上升”响应：源图真实属于第一类，这个响应有利；目标图真实属于第二类，它就有害。**相同响应不包含“应该往哪边修”的答案。**

数学上，源回归依赖两项：M_S=E[ΦᵀΦ] 和 c_S=E[Φᵀr]。目标输入让我们看到 M_T，却不能直接给出含真实标签的 c_T。共享尺度、匹配 embedding 或匹配响应，都不能自动保证 c_S≈c_T。

这是一类域适应的根本限制：输入表示接近、源分类误差低，仍不足以保证目标准确率。相关理论背景见 [Zhao 等，ICML 2019](https://proceedings.mlr.press/v97/zhao19a.html)。这篇论文不直接证明 TQG 失败，但说明必须明确额外迁移条件。

本轮有两项强风险：

- 源训练 class0 比例 **83.6%**，目标 3 开发集只有 **24.5%**。TQG 后目标 3 预测 class0 的比例从 68.9% 上升到 85.6%，class1 召回从 36.0% 降到 15.6%。模型变得更偏向源多数类。
- 源图节点数 38–620，目标 2 为 13–29，目标 3 为 4–23，原始图规模没有重叠。响应空间或 embedding 空间是否仍有可迁移的重叠，需要另外测量。

类别比例不同不能单独证明条件标签规则改变，也不能认定严格的 label shift 假设成立；上述是风险证据，不是对唯一原因的证明。

### 3.3 输出纠错看起来对，BP 后参数动作仍可能错——对应 §3.9→3.11

在当前快照处：

\[
\nabla_\theta L_{fb}=-J_T^\top d_T/n_T.
\]

符号正确。但只考虑反馈、做一个很小的普通 SGD 步时：

\[
\Delta\theta=\eta J_T^\top d_T/n_T,\qquad
\Delta z_T\approx\eta J_TJ_T^\top d_T/n_T.
\]

**真正输出变化是经过 J_TJ_Tᵀ 变换的 d，不是直接把 d 加上去。** 不同图共用模型参数，一张图的纠错会影响其他图；敏感度大的分量会被放大。若评价另一批图，还会涉及两批图之间的 Jacobian 映射。源主损失和 Adam 会进一步改变最终动作。

一个已独立核验的反例：两张图中，一张应该往负方向修，另一张应该往正方向修；拟合给出两张都往正方向的小纠错。直接修改输出时，第二张收益超过第一张损失，总 CE 下降；但第一张对参数敏感 10 倍，BP 再前传放大成 100 倍，总 CE 反而上升。即使源和目标完全相同、模型线性，也会发生。

该反例的残差 MSE 改善 +0.17993；直接小输出步使 CE 从 0.91629073 降至 0.91627309，反馈参数步却升至 0.91643199。它证明这一风险存在，不证明它已经是 PROTEINS 的最大成因。

真实日志也有同类现象：0→3 预训练状态的随机方向，直接输出纠错平均降低 CE 0.00527，对应等参数范数小步却平均增加 CE 0.00023。当前尚未逐步恢复真实 Adam 状态作因果分解，不能把 Adam 本身定为罪魁祸首。

### 3.4 一阶版更像源梯度的重新加工，不会凭空增加标签信息

只保留很小半径的一阶响应，令 U 包含归一化探测方向，H_D=E[J_DᵀJ_D]，g_S 为源 CE 梯度，可推得反馈梯度近似为：

\[
\widehat g_T\approx H_TU(U^\top H_SU+\lambda I)^{-1}U^\top g_S.
\]

也就是把源梯度投影到少量方向，再按目标的敏感程度重新加工。这个操作可能有用，但“用了目标计算”本身不能证明获得了新的标签信息。

一个值得检查的后果是：如果源模型已经足够好，E[r_S|G] 接近零，剩余单图残差可能主要是难以预测的标签波动；若总体源梯度恰为零，上式的一阶反馈也为零。小批次依然能拟合出非零系数，但这些系数可能主要来自抽样波动。这是条件性的数学风险，当前还没有单独证实它解释了多少真实实验退化。

因此有限非线性分支需要证明：它不只是产生了非零的新特征，而且读取出了超出一阶源梯度、能够迁移到目标的监督信息。一般性的随机特征残差拟合已有相关研究，如 [RFRBoost，ICML 2025](https://proceedings.mlr.press/v267/zozoulenko25a.html)；TQG 的贡献需要落在迁移机制和验证上。

## 4. 是否存在实现错误：逐项结论

| 环节 | 本次核查结论 | 仍有的方法风险 |
|---|---|---|
| 探测方向 | 目标 VJP、类别中心化、编码器参数范围正确 | 敏感方向可能与标签无关 |
| 方向尺度 | JVP 归一化符合设计；实测输出扰动约 0.043–0.055，接近设定 0.05 | 本次没看到探测爆炸，不代表任何模型都安全 |
| odd/even 响应 | 分母 2ρ、ρ² 和共享基准正确 | even 的标签相关性、半径稳定性未被建立 |
| 共同标准化 | 源目标使用同一列尺度，没有分开缩放 | 统一单位不等于迁移成立，且影响正则化 |
| 组合权重 | 残差符号、除以图数、岭回归求解正确 | 小样本统计外推不稳定 |
| 反馈损失 | detach、负梯度方向、0.1 权重正确；head/encoder 都有梯度 | 实际参数动作不等于直接输出纠错 |
| 批次与评价 | 对照配对、独立抽样和现有开发诊断路径未见明显错误 | 目标开发集已用于分析，后续针对它调试属于探索 |

独立核查采用三分类、源/目标不等批量、显式 Jacobian、增广最小二乘、有限差分和 PyG GIN 路径，避免只重复实现本身。**17 项全部通过**，反馈梯度有限差分误差约 4.16×10⁻¹²；冻结代码没有改动。

还有三项值得注意，但不能称为已确认的代码 bug：

1. **16 张源图拟合 8 列响应。** 二分类中心化后，每图只有一个独立类别对比，不是 32 个独立监督。源 query 池仅 51 张、少数类 9 张，每批期望约 2.8 张少数类。响应又高度相关，源矩阵 stable rank 均值只有 1.30–1.49；这说明能量集中，不能等同于代数秩只有 1–2。
2. **弱 even 分支获得了相近的拟合机会。** 它对实际有限输出扰动的幅度通常只有 odd 的约 2%，却各自按 RMS 归一化。可能保留了微弱有用信号，也可能放大不稳定信息；目前需要消融才能区分。
3. **反馈不总是“小辅助项”。** 训练历史里的纠错 RMS 最大约 3.5，而真实 onehot−p 的每图范数至多 √2。60 个只读检查块中，乘 0.1 后的反馈梯度中位数约为源梯度的 20%–32%，个别达到 4.08 倍。它可能强烈改变更新，但源梯度与反馈梯度相反也不自动说明反馈错。

默认共享 RMS、8 列、λ=.01 下，正则 Gram 条件数有上界 1601，且使用 float64。**不要把统计泛化差直接说成“矩阵奇异导致浮点计算爆炸”。**

## 5. 最值得尝试的改造：目标局部的源监督读取

你的“目标找响应/参数作用类似的源图”想法，最适合具体化为：

> 在同一模型、同一组探测下，比较每张图的响应签名；目标图主要向响应相似的源图借标签经验，分别拟合纠错，可靠性不足时不反馈。

它把原版“整批目标共用一个全局 a”改成“每个目标簇使用局部 a”。参数本身是全图共享的；可比较的是每张图的响应或参数梯度，而不是每张图拥有一套独立参数。

### 建议流程

1. **固定当前快照和同一组方向。** 首版先用 linear/odd，减少尚未验证的 even 影响。
2. **构造响应签名。** 如 u(G)=[冻结 embedding，当前概率 p，vec(Φ(G))，原始响应幅度]。分别检查这些信息是否有增益，不能一开始全部拼上后就宣称响应有用。
3. **为目标图/簇分配源软权重。** w_ij∝exp[−D(u_i^S,u_j^T)/τ]，并使 Σ_i w_ij=1。粗筛可先用低成本 embedding；精排再用同方向响应。
4. **拟合局部系数。**

\[
a_j=\arg\min_a\sum_iw_{ij}\|\Phi_{S,i}a-r_{S,i}\|^2
+\lambda\|a-a_{\rm global}\|^2,\qquad d_j=\Phi_{T,j}a_j.
\]

这里向全局系数收缩是可选项；全局系数也不稳定时应比较向零收缩。小数据下先按目标簇拟合，比每图单独拟合更容易稳定。

5. **检查是否真的有可借用的源经验。** 记录距离、响应覆盖、有效样本量 ESS=1/Σ_iw_ij²；没有近邻或 ESS 太低就令 d_j=0。阈值从预先约定的源侧留出或受控数据确定，不用目标真标签选择。
6. **约束纠错幅度，再检查真正参数动作。** 不能只报告直接加 d 后的输出表现。

白话例子：两组源图都在某个方向上响应，但一组当前已经偏向第一类，另一组偏向第二类。原版把两组经验混在一起学一个 a；局部版本按响应、当前预测及表示分组，允许对不同目标图给出不同纠错。**如果局部相似之后标签关系仍不同，这个改法仍会失败。**

有四个必须保留的限制：

- 当前源图与目标图在原始规模上无交集；最近邻只表示“最接近”，不保证“足够接近”。方法可能合理地拒绝很多目标图，不应把低更新率藏起来。
- 不要从每批 16 张里硬选 4 张，再拟合 8 个系数。优先在更大的合法 query 池上软加权，避免进一步丢少数类。
- 签名必须使用相同方向和尺度。每步随机字典会变，不能直接比较不同字典的 a，也不能不重算就长期复用过时的响应缓存。
- query 标签已经通过反馈进入训练；用它选超参时要安排不同折的职责，不能始终称为独立验证集。

**最关键对照**：相同样本数量的随机选择、embedding 权重、响应权重、混合权重；再比较“加权源 CE”和更简单的“局部平均残差 d_j=Σ_iw_ijr_i”。只有复杂响应回归稳定超过这些对照，才支持 TQG 额外步骤有价值。

源图选择本身已有相关工作，例如 [GRADATE](https://arxiv.org/html/2505.17293v2) 研究图域适应中的源图选择。因此不要把“找相似源图”单独当成新颖性；可研究的问题是：**动态响应能否比普通结构/embedding 相似度更准确地判断哪些源监督可迁移。**

### 一个有明确数学保证的小改动

令 Δ 为合法概率向量集合（各分量非负、和为 1），采用欧氏投影：

\[
q=\Pi_\Delta(p+d),\qquad d_{\rm proj}=q-p.
\]

真实 r=onehot(y)−p 一定在 Δ−p 内，因此对任何可能的真实类别，都有：

\[
\|d_{\rm proj}-r\|^2\leq\|d-r\|^2.
\]

白话：既然在估计分类残差，就先把估计拉回“某个合法类别概率能产生的范围”。不用知道标签，也不会增加该残差的平方误差。这是标准凸投影性质，不能直接作为新定理。仍用 z+d_proj 作参考，而不是把 logits 当概率裁剪。

**它不能保证 CE 或参数更新更好。** 此外，若 q 停止梯度，soft CE(q,p_θ) 在快照处的梯度与该平方反馈完全相同；每轮重算参考、只走一步时，单纯“把 MSE 改成 CE”并不是本质修复。方法更准确的定位是构造受源监督支持的软目标，而不是仅凭没有 argmax 就声称与伪标签无关。

更大的执行改造可选：仅线性响应 Φ=JU 时直接 δθ=ηUa，或先求 β=(J_TJ_Tᵀ+μI)⁻¹d，再沿 J_Tᵀβ 做小 SGD 步。前者省掉再次几何变换；后者使局部输出变化接近 K(K+μI)⁻¹d。这些都不是原版 TQG，也不能直接套用到有动量的 Adam 后宣称保证成立。

## 7. 下一轮应怎样验证，而不是盲目扩大训练

建议按顺序做四段判别，每段失败都有明确去向：

1. **响应特征能否表达任务信息？** 固定快照，用已允许的目标开发标签作明确标记的 oracle 残差拟合，严格分拟合/留出目标图。若连 oracle 都不能泛化，先改特征或样本量；oracle 不能算无监督成绩。
2. **信息在哪一步丢失？** 同一字典比较源拟合、源留出、源系数到目标、目标 oracle 系数，定位源估计方差与迁移差距。源留出差只是诊断信号，并非目标一定无收益的定理。
3. **输出信号能否落实为动作？** 相同 d 比较直接 logits、等长 SGD、复制真实 Adam 状态后的 source-only/source+feedback。只试算并丢弃副本；目标标签不参与实际训练门控。
4. **有针对性的短训练消融。** 每次只加一项：更稳定的全局回归、残差投影、局部响应匹配、执行器校正；保留冻结源、源 CE、随机方向、均值残差和相同预算对照。不要一次叠加全部改动导致无法归因。

另加一个受控正对照很有价值：同标签机制、可控支持重叠的合成图任务，再逐渐加入图规模差异、类别比例变化与标签关系变化。随机划分同一数据集可以查工程链路，但不能冒充真正跨域成功。

0→2 / 0→3 开发集现已参与失败分析，围绕它做后续改法属于探索。确认新假设时应预先冻结方案，并使用新的任务或未用过的评价数据；不能把反复看开发结果后的最优设置当成无偏确认。现有最终保留集继续保持原角色。

## 8. 当前能说多有把握

| 判断 | 证据强度 |
|---|---|
| 原版在本轮两任务、五种子设置中未通过验证 | 高：完整训练和既定对照支持 |
| 已检查核心公式没有明显实现错误 | 高：逐项代码对照和独立数值核查；不等于排除所有潜在 bug |
| 当前源系数拟合存在明显的批外泛化问题 | 高：独立源块诊断直接显示 |
| 类别偏置、弱响应尺度与反馈放大参与了失败 | 中：观察到现象，但各自因果贡献尚未分离 |
