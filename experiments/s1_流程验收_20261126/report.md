# S1 验收结果

2026-11-26 在 CPU 上完成。Python 3.12.4、PyTorch 2.5.1、NumPy 1.26.4、SciPy 1.15.2、mpmath 1.3.0，单线程。最终 44 项测试全部通过，wheel 构建成功。三组任务均通过正式命令行完成源训练、A 适配、H 预测和跨进程重载。五种模式的主后验及似然加权后验均已归一化，每组重载预测文件逐字节一致，源 checkpoint 的 SHA-256 保持一致。

A 条件 NLL 对图取平均、对排列取平均、对该图的边步骤求和，使用拟合 A 本身。H 结构修正比较同一张图在 `structural_only` 与 `zero` 下的自然类别 log-odds。每个任务均为源训练 8、验证 4、A 4、H 4，训练 2 个 epoch。[配置与复现](README.md)

**合成结果。** 零适配和仅结构适配的 Accuracy 都为 3/4，AUROC 都为 0.50，自然 NLL 分别为 0.6804 和 0.6802。预先声明的 `prior_calibrated` 为 2/4、NLL 0.7978，`prior_only` 为 2/4、NLL 81.4467。四张图足以检查评分路径，判别收益还需独立、大样本比较。

**真实图。** 两个 A 池都将十个词元连成单一分量，验证了这种情况下 `structural_only` 与 `v2_global` 在同一 H 上给出相同预测。断开分量的机制由构造测试单独覆盖。两组真实 H 都保持标签封闭，无法从这轮报告真实目标 Accuracy。

**先验校准暴露的问题。** 真实 A 上的二分类矩方程都数值收敛，但估出的中心化类别偏置绝对值很大，Mutagenicity 约为 1446，PROTEINS 约为 1765。加入校准后，两组 H 的四张图分别全部预测为原始类别表的第 0、1 个索引。这直接说明小池上的收敛解可以主导结构证据。校准的统计稳定性、源端类别概率能力和真实迁移收益均待独立验证。
