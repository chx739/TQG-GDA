# D4：响应相似度是否携带可迁移监督

[返回实验列表](README.md#experiment-list) · [统一协议](method.md) · 后续：[D5](D5_local_support.md)

**优先级P1；待实现、待执行；新增训练0。**

白话：当前已经在比较表示h和响应A；下一步不是再加一个相似度，而是检查这种相似度是否真的有助于判断怎样纠错。

## 1. 假设与两组实验

H4：h+A相对仅h在真实目标梯度上有增量，且这个增量在等反馈范数后保留。预期余弦优势≥0.03，而不仅是范数变小。

第一组做源内模拟迁移，验证估计器在较友好的情况下能否回答监督查询；第二组复用D1目标诊断。如果源内好、跨域坏，更支持迁移假设／覆盖出了问题；两边都坏则优先查读取和核。

## 2. 五个核臂

| 臂 | 核 |
|---|---|
| H | exp(−distance_h/(2s_h²)) |
| A | exp(−distance_A/(2s_A²)) |
| HA | 原版两个距离相加后的exp |
| CONST | 所有源源、源目标、目标目标核均为1，PSD常数核 |
| HA-PERM | 在算核前把源图的(h,A)按同一输入无关排列重分配给源ID；残差仍保持原ID |

尺度沿用同块源bank输入的中位数，不在每个臂另调温度。HA-PERM必须同时置换源源核的行列及源目标核的行；只乱K_ST会破坏完整Gram一致性，不是有效负对照。

五臂使用相同目标V、读取器joint lambda0.01、停止梯度规则。D3若支持简化读取，可另冻结一个统一MEAN版本重做所有核，但不能只给HA使用joint、给H使用MEAN后声称是签名差异。

## 3. 源内模拟组

使用默认source-only快照，不使用已被query反馈适配过的模型作主分析。

- 将196张query按SHA256(D4|source_id)排序划成98/98；两个方向交换bank与audit，构成2折。快照使用统一协议指定的源侧组。
- 每折bank98供读取权重和残差；audit98先按ID排列，每块使用独立generator无放回抽16张作模拟目标，余82张作单步审计B。每折4块，种子为64000000＋(model_seed−3405)×10000＋snapshot_step×10＋fold×1000＋block_id；fold取0/1，block_id取0—3。
- 源尺度只由bank98输入确定。audit的标签只用于Oracle／评价，不能用于求W、选核或调λ。
- 5种子×3快照×2折×4块＝120组；同一源域无需对三个真实迁移任务重复计成独立证据。
- 核主指标是模拟目标的梯度余弦／误差。近邻标签一致率、残差差异只作辅助，不把逐图残差预测强加为TQG的必要任务。

此处同域源外层审计也不构成严格统计独立保证，特别是原source角色按标签分层划分。报告称“未用于该快照query反馈的源图”，不称已证明的iid无偏估计。

## 4. 真实目标组

复用D1全部360块，比较五核的原始梯度指标。一步B池效果仅使用前4块，与D2相同η0.0003。

等范数比较把各非零反馈缩放至同块H臂范数，保持源梯度、β和η不变；H为零的块保留原始结果、等范数比较记NA。不按目标标签选择缩放系数。

需要报告：距离分布、尺度floor率、K_SS有效秩、K_ST最大／均值与分位数、核近似常数程度、源近邻标签一致率相对类比例基线、实际梯度质量。距离集中不等于中位数数值不稳定，两者分别检查。

## 5. 决策与改进方向

真实目标组至少2/3任务HA对H的平均c_A优势≥0.03、至少3/5种子为正，且等范数B池一步改善为正，才支持“响应提供额外监督信息”。源内成功不能替代跨域成功。

- H≈HA或H更好：优先简化签名，不把多算JVP当贡献。
- A好、H使结果变差：检查表示相似度是否把不相关源图拉近；再登记A-only候选。
- HA仅在少部分有支持的块好：进入D5。
- 所有核源内都失败：先处理校准、任务函数族、噪声或实现；暂不学新的embedding。
- 不实施“统一缩放A再重算同规则带宽”作为改进，因为一般与原核等价；改变相对方向权重或每图归一化则是新几何，必须另设对照。
