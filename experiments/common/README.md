# 通用实验工具

这里仅保存不绑定实验轮次、数据域或实验方法的工具。没有 R2、R3 等轮次目录，也不放训练、适配流程或命令行入口。

| 模块 | 职责 |
|---|---|
| `io.py` | 文件哈希、JSON/张量保存、文件清单及执行环境记录 |
| `archives.py` | 打包并校验原始产物 |
| `paths.py` | 定位仓库根目录 |
| `runtime.py` | 执行计时、资源记录、阶段文件封存 |
| `statistics.py` | 二分类指标、置信区间、绘图误差条和结果序列化 |
| `metrics.py` | 在相同查询上计算 score 与分类指标 |
| `geometry.py` | 通用边界几何测量 |

新增工具需满足：不读取某轮固定协议、不硬编码轮次或任务参数、不导入任何具体实验的 `src`。只因为被两个实验调用，不代表应该移到这里；带有实验假设的实现保留在原实验中，调用方在 README 明确依赖。
