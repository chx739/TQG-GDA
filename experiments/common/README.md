# 实验共用代码

这里保存跨轮复用的实验工具，不复制核心 TSBA 算法。

| 位置 | 内容 |
|---|---|
| `paths.py` | 从公共位置确定仓库根目录，避免各入口依赖目录深度 |
| `synthetic/` | 合成分布、解析诊断、对照实现、汇总和归档工具 |
| `real_data/` | 真实图输入、源训练、探针、密度、评价与执行记录 |
| `real_data/next_round/` | 从 R1b 沿用的冻结模型与经验 score 工具 |
| `real_data/r2/` | R2–R4 共用的状态、训练、适配及评价实现 |
| `real_data/r3/` | R3–R4 共用的约束、轨迹、训练与评价实现 |

子目录保留最初引入这些实现的阶段名，便于区分不同历史协议；这里的代码确实被多轮复用，专用入口仍在相应实验目录。部分 `run_*.py`、`summarize*.py` 保存沿用的函数，其命令行入口已移到各轮目录，不直接作为共用模块运行。

- 正常使用算法需要的模块放 `tsba/`。
- 仅用于实验、但被多轮使用的模块放这里。
- 只服务于一轮的运行、诊断和分析放该轮目录。

修改共用实现可能影响多个实验，应测试相关调用方。原始报告、配置、日志不因重构重算或覆写。
