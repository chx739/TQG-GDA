# D1：固定快照上，源监督是否给出了正确梯度

[返回实验列表](README.md#experiment-list) · [统一协议](method.md) · 后续：[D2](D2_one_step.md)、[D3](D3_calibration.md)、[D4](D4_signature.md)

**优先级P0；待实现、待执行；新增真实数据训练数0。**

白话：先不连续训练，拿同一个模型问一次——真实源标签给出的建议，是否比乱标签、同样大小的随机建议更接近目标任务需要的方向？

## 1. 可被否定的假设

真实query标签的TQG反馈，与A批次经验CE梯度正向对齐，并在跨模型种子汇总后优于打乱标签和等范数随机方向。预期余弦优势至少0.05；若达不到，不把小幅BA变化归为监督迁移。

D1不是证明条件期望梯度恢复。A标签梯度含有限样本标签噪声；D8用已知条件概率补这一点。

## 2. 固定设计与规模

- 3个任务×5个模型种子×3快照(t=0、源SGD50、源SGD200)×8块＝360个主块。
- 各块源fit16、源query196、目标A16，全B池271；具体ID规则见统一协议。
- 主版本joint／h+A／lambda_W0.01；β在纯梯度夹角中不起作用，记录未加权g_hat。
- 同一块先计算一次V、所有响应、尺度、核、W；后续不同标签只换r_S，不能换θ、V、核或W。
- 默认不增加32/64/196目标batch，不进行新训练。

## 3. 对照臂

| 臂 | 定义 | 作用 |
|---|---|---|
| TRUE | −VW[堆叠Q_Cᵀ(Y−p)] | 当前主版本的P维损失梯度估计 |
| PERM-1/2/3 | −VW[堆叠Q_Cᵀ(ΠY−p)]；Π只置乱Y，不置乱整个残差 | 去除标签与图的对应，保留标签总数／比例 |
| RAND-1/2/3 | V u，u为r维标准高斯，缩放到||TRUE||₂ | 检查是否只是额外扰动；随机方向限制在同一V空间 |
| ZERO | 零反馈 | 零点参考，夹角为NA |
| ORACLE-A | g_A | 实现与上限参考，不是UDA方法 |
| SOURCE | 同块g_S | 观察源任务本身与目标的关系 |

PERM随机数用generator(block_seed+9101/9102/9103)，RAND用+9201/9202/9203。不得用目标标签选置乱或随机方向；空rank或TRUE为零时RAND置零并标注不能作非零等范数比较。

主梯度误差使用各臂原始幅度；另外记录PERM等范数版本给D2，不能用Oracle最优缩放后的误差替换原误差。PERM为零时不强制放大，标记norm_match_unavailable。

## 4. 每块记录与指标

必须保存：snapshot/source/data SHA、A/B/fit/query ID、rank、奇异值摘要、W范数、校准gap、源残差范数、各臂梯度范数、c_A/e_A/a_A、c_B、g_B的空间内外能量。

主要：TRUE对PERM均值、RAND均值的配对余弦优势。次要：相对误差、正向率、范数比、与g_S的夹角、校准代理误差与实际误差是否相关。

按t=0/50/200分别画图，再等权汇总，防止总体均值掩盖源训练越久监督越差。零梯度、回退、未收敛与NA必须保留。

## 5. 预设继续门槛

一个任务同时满足：

1. 五种子聚合后TRUE平均c_A>0；
2. TRUE对PERM均值和RAND均值的平均余弦优势分别≥0.05；
3. 两个比较各至少3/5模型种子的配对差为正；
4. 可作TRUE与两类null成对非零比较的覆盖率≥80%；不足时判证据不充分，不挑有效块宣布成功。

至少2/3任务满足，才称“方向诊断得到支持”。这不是显著性结论。相对误差必须一起披露，不能因角度好就称幅度准确。

若失败：仍完成D2作为定位；允许D3/4/8寻找原因，但暂停完整训练扩展。任何修订后的新候选需独立版本和原门槛重新检查。
