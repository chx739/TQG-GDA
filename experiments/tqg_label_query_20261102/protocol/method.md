## 4. A/B开发池、抽样与标签权限

对每个域的原542个development全局ID，按SHA256字符串排序：
tqg-v2-diag-20261031|domain=d|id=i

前271个组成A池，后271个组成B池。不使用标签分层或按效果挑图；写出A.npy/B.npy与哈希、与原dev/final的集合核对结果。

每个任务、模型种子、快照、block_id构造如下种子：

block_seed = 61000000 + domain*100000 + (model_seed-3405)*10000 + snapshot_step*10 + block_id。

block_id为0—7。A池取该种子randperm的前16张；源fit取独立generator(block_seed+1000)在779张fit中的前16张；query默认全部196张、固定原ID排序。每批内不重复，跨块可重复。所有臂共用这些ID。

B池固定全部271张，按ID排序分批前向；CE和梯度按图数加权，不能简单平均不同长度小批次的均值。D2只取block_id 0—3，避免运行后挑块。

## 5. 符号与更新

问题设定：源分布P_S提供有标签图，目标分布P_T提供无标签图，二者共享C个类别；测试时只做GNN前向。希望降低目标普通分类风险R_T(θ)=E_(G,Y)~P_T[CE(f_θ(G),Y)]。真实数据的P_T(Y|G)未知，不能从无标签输入自动证明源目标标签关系相同。

直觉是：在当前模型上，利用目标Jacobian定义“这批目标需要怎样的梯度查询”，再按源图的表示和响应相似性读取源残差。是否能迁移取决于签名保留的任务信息、覆盖和条件关系；D1—D8就是检验这些条件，而非假定它们已经成立。

| 符号 | 含义／形状 |
|---|---|
| G、Y、p | 整图、C维one-hot标签、C维预测概率；当前C=2 |
| θ、P | 当前参数快照、全部可训练参数个数 |
| q、Q_C | q=C−1；C×q的固定正交类别对比基 |
| J、J_tilde | 中心化logits的C×P导数；J_tilde=Q_CᵀJ，q×P |
| V、r | P×r的当前目标A批次梯度空间正交基；r为数值秩 |
| A(G) | J_tilde(G)V，q×r响应；注意与开发A池不是同一对象 |
| W、r_S、d | r×(b_S q)读取矩阵、源堆叠残差、r维系数d=W r_S |
| g_hat | 估计损失梯度−Vd；不是下降方向本身 |
| g_A、g_B | 当前θ上A批次／全B池的标签CE梯度；仅离线Oracle使用 |
| g_S | 当前θ上同一16张源fit图的CE梯度 |
| β、η | 反馈权重、一步学习率 |
| L_B、Δ_B | B池普通平均CE、某更新前后损失变化 |
| epsilon_g | 1e-12，FP64梯度近零判断；不是为零梯度伪造夹角的分母 |

源残差按图优先堆叠：r_S=col_i[Q_Cᵀ(Y_i−p_i)]，形状b_Sq；不额外除以b_S。目标平均已经放在B_T=col_j[A(G_j)]/b_T中，形状(b_Tq)×r。

为便于阅读D3/D5，统一定义：

- K_SS、K_ST、K_TT为标量核块；𝕂=K⊗I_q为对应的类别块扩展。
- H_ST=𝕂_ST B_T，H_TT=B_Tᵀ𝕂_TT B_T。
- E(W)=H_TT−W H_ST−H_STᵀWᵀ＋W𝕂_SS Wᵀ，形状r×r，是任务函数族的结构性查询误差矩阵。
- 原joint目标为tr(E)/r＋λ_max(E)＋λ_W||W||²_F/r；mean-only去掉λ_max(E)。
- Ω为半正定、迹为1的对偶方向权重；D=I_r＋rΩ。固定Ω时DW𝕂_SS＋λ_W W=DH_STᵀ，方向特征值δ_a对应有效正则λ_W/δ_a。

E(W)不读取目标标签，不能当成真实梯度误差或统计置信区间。r=0时跳过这些含1/r的公式，按零反馈边界处理。

当前正常更新：
θ_new = θ − η(g_S + β g_hat)。

每一诊断臂都从同一θ独立更新。每步仅一次普通SGD；不使用旧动量状态，不更改BN/dropout状态。V、W、签名和残差停止梯度，更新后不能沿用本块监督连续再走多步。

同批真实梯度满足：
g_A = −V [ (1/b_T) Σ_j A(G_j)ᵀ Q_Cᵀ(Y_j−p_j) ]。

此处的真实梯度是开发标签这一次有限实现下的经验CE梯度，不等于不可观察的条件期望梯度。D8另用已知条件概率消除标签噪声来检查。

单步诊断与数学的连接为L_B(θ−ηd)−L_B(θ)≈−η〈g_B,d〉；D1看估计方向，D2检验有限步是否符合这个预期。近似只在局部有意义，曲率与批次差异仍可能使实际结果相反。

## 6. 统一指标与统计

D1原始指标：

- 夹角余弦 c_A = <g_hat,g_A>/(||g_hat||₂ ||g_A||₂)，越大越好。
- 相对误差 e_A = ||g_hat−g_A||₂/||g_A||₂，越小越好。
- 方向／幅度增益 a_A = <g_hat,g_A>/||g_A||₂²；正数表示局部一阶下降有利，不保证有限步必降。
- 范数比 ||g_hat||₂/||g_A||₂，以及weighted_ratio = β||g_hat||₂/||g_S||₂。
- 对B梯度报告c_B、投影内参考VVᵀg_B与空间外能量，不能把B全梯度不在V内叫作“空间构造错误”。
- g_A或估计梯度范数≤epsilon_g时，夹角记NA并分类说明，不写成0或1；零反馈率、有效比较覆盖率必须同时报告。g_S近零时weighted_ratio记NA。

D2主要指标：
R_Q = [ L_B(θ−ηg_S) − L_B(θ−η(g_S+0.1g_hat)) ] / L_B(θ)。
正值表示在源SGD之外有额外帮助。主η固定0.0003；0.0001和0.001仅作预定敏感性分析，不按任务挑最优η替代主结果。

汇总：先在一个模型种子、任务内等权平均各快照和块，再汇总5个种子的均值±样本标准差与配对差。先平均3个打乱／随机重复，再进入模型种子统计。块、图、checkpoint、置乱都不是新的独立模型种子。各任务单独展示；跨任务平均仅辅助；原始、零梯度和异常不能隐去。

可附配对种子bootstrap区间，但5种子精度有限，区间不替代完整数据；不把设计门槛叫p值或显著性。所有阈值只用于后续工作决策，不是总体有效性的充分条件。

## 7. 保护解释边界

- 核Gram误差小不意味着真实梯度误差小；还依赖函数近似、跨域条件稳定性、监督支持及标签波动。
- W依赖源输入不自动构成泄漏；多轮θ依赖query标签使简单独立样本论证不成立。
- RaT也使用源样本残差；TQG的区别在目标梯度泛函读取及参数执行，不是“只有TQG用源残差”。
- 没有近端项不是已定位的主要故障；加近端项不会修复错误方向。
- 共同缩放A并重算同样的中位数尺度，通常不会改变核；D0用数值验收避免无效改动。
- 不自动按范数比放大小反馈；无支持反馈应保持零。源梯度近零时还要避免把有效目标反馈也强制清零。
- 普通CE与balanced accuracy目标不同，两者同时报告；不能只选自己获益的指标。
