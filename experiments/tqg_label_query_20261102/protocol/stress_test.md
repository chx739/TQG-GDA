# 研究压力检查与尚未解决的问题

[返回实验列表](README.md#experiment-list)

1. **是否只是RaT／KRR改名？** 当前平均项与岭回归有明确联系；D3先控制有效正则，D4检查响应签名。若复杂校准没有增量，应简化并重估贡献。RaT/TILT图改编仍需独立实现；不把本计划当新颖性证明。
2. **公式能推出迁移有效吗？** 不能。完整目标空间和执行等式只保证构造／执行一致；D1/2/8分别检验梯度、一步作用和已知条件规律。真实条件稳定性仍无一般保证。
3. **最简单替代解释是什么？** 标签额外访问、正则改变、范数变化、随机扰动、源CE主导。D1 null、D2 Oracle、D3匹配正则、D4等幅度及D9 FIT+QUERY-CE逐项处理。
4. **方法如何失败？** 同签名条件规律变化、信息丢失、无源支持、query噪声、自适应标签复用、源目标梯度冲突。D8保留条件翻转的不可识别例；门控不能宣称解决任意变化。
5. **最便宜的否定是什么？** 共同θ上的TRUE反馈不比等范数打乱／随机好，而Oracle一步有用。优先D1/2；不先启动360个适配。
6. **数据是否偏向方法？** 当前三任务是SEGA规模域，不是官方自然域；dev已被观察。D9增加PROTEINS仍只是另一规模域复核，若主张真实领域通用性须另建自然域协议。
7. **更多计算能替代贡献吗？** batch196已显示更低范数CV而无稳定分类收益。D9固定步数不等计算，效率主张另做600秒曲线，不把固定步结果当效率优势。
8. **最强的否定意见是什么？** “正确标签不稳定优于乱标签，复杂求解也没超过简单监督。” 本计划正面检验；若仍成立，结论是当前机制缺乏支持，不通过隐藏失败或堆模块回应。
9. **是否只有评测没有研究贡献？** 此阶段确实是诊断工作，不应单独包装成新方法论文。只有诊断支持一个明确干预，且跨数据集与简单解释对照通过，才进入方法贡献论证。
10. **为什么不立即加prox／归一化？** 未找到估计正确前，prox只是改执行；统一缩放A再重算同带宽可能完全等价。D0与D2先避免无效工程。

未解决：任意自适应query复用的有限样本理论、真实图签名的任务充分性、自然域广泛适用性、近期方法的完整可复现比较、未来一次性最终评价。它们不阻止有边界的D0—D2诊断，但阻止宣称投稿就绪或一般最优性。
