# D2：单步有效性、源目标冲突与Oracle对照

[返回实验列表](README.md#experiment-list) · [统一协议](method.md) · 输入：[D1](D1_gradient_quality.md) · 后续：[D6](D6_feedback_strength.md)

**优先级P0；待实现、待执行。** 临时参数步仅用于诊断，不进入正常UDA训练，也不保存为可部署模型。

白话：D1检查“建议方向像不像”，本项检查“真的迈一步，另一批目标图是否变好”。

## 1. 假设与共同设置

TQG在源SGD之外提供可测的B池CE改善。若Oracle在同样位置有帮助、实际反馈没帮助，应定位估计器；若单独目标Oracle好但混入源CE后效果消失，应检查混合更新。

固定D1所有45个快照，每快照取最前4个块，共180块。θ、源fit16、query196、A16与B271按统一规则锁定。η∈{0.0001,0.0003,0.001}；主结果只用0.0003。反馈β=0.1，只有单列的O-RAW使用未缩放g_A；后续β扫描单独放D6。

定义norm_match(v)=||g_hat_TRUE||₂·v/||v||₂；仅v非零时有效。该操作只为控制“同样大小但方向不同”，不提供可部署规则。

## 2. 一步对照臂与更新

每臂均执行θ_new=θ−ηd；F不更新。

| 臂 | d | 解释 |
|---|---|---|
| F | 0 | 冻结参考 |
| S | g_S | 匹配源SGD |
| Q | 0.1g_hat_TRUE | 单独当前反馈 |
| O-M | 0.1norm_match(g_A) | 与实际反馈同幅度的纯目标Oracle |
| O-RAW | g_A | 不缩放Oracle参考；与Q幅度不匹配，单列 |
| S+Q | g_S+0.1g_hat_TRUE | 当前联合更新 |
| S+O-M | g_S+0.1norm_match(g_A) | 估计器方向的受控替换 |
| S+P-1/2/3 | g_S+0.1norm_match(g_hat_PERM) | 等幅度乱标签对照 |
| S+R-1/2/3 | g_S+0.1g_hat_RAND | 等幅度同空间随机对照 |

12个非冻结臂×3η×180块＝6480个临时更新。另有F逻辑参考；同θ、同B时F的前向可缓存，不能为了省时合并不同更新后的评估。

若等范数参考为零：保存原始零结果并标注该受控比较缺失；不加epsilon把它伪装成等范数。不用目标标签挑方向以外的模型超参数。

## 3. 怎么评估

1. 先保存θ与buffer哈希、L_A/L_B、g_A/g_B/g_S、所有候选d。
2. 从θ分别clone，执行一次无动量SGD；检查更新等式。
3. 在A、B分别计算普通CE；BA、AUROC和类别召回仅辅助。B按全部271张加权。
4. 丢弃临时参数，验证原θ没变，再进入下一臂。
5. 记录有限步CE变化与一阶预测−η<g_B,d>；其差异用于识别步长／曲率问题。
6. 不通过临时更新结果选择下一块，也不迭代Oracle轨迹。

主要指标为统一协议中的R_Q：S+Q相对S的额外B池CE改善。另报S+Q相对S+P/S+R、S+O-M相对S、Q与O-M的差距，以及所有臂相对F的绝对变化。

## 4. 预设门槛与决策

主η=0.0003下，至少2/3任务满足：平均R_Q≥1e-4（即基准CE的0.01%）、至少3/5种子R_Q>0、且S+Q相对S+P均值及S+R均值的额外改善为正。可比较覆盖率≥80%。这只是进入训练的筛选门槛，不等于有实用分类收益。

| 观察 | 下一步 |
|---|---|
| O-M改善B、S+O-M优于S，而S+Q不行 | 优先D3/4，错误可能在估计方向 |
| O-M好，但S+O-M比单独O-M差或不优于S | 检查源目标冲突；不简单归罪于代码 |
| 小η有效、大η反向；一阶预期与真实变化不符 | 优先D6检查幅度／局部曲率 |
| A改善，B恶化 | 检查A批泛化、标签噪声与目标空间覆盖；D8补已知条件期望 |
| Oracle也不能改善B | 当前A→B Oracle诊断不充分；看批次噪声、步长及接近驻点，不宣称方法无解 |
| 各臂CE变化小到数值误差量级 | 标记不可判定；参考D0误差、函数尺度及更大预定η结果，不能挑最优η补过主门槛 |

D1和D2均支持，才让同一候选进入D9。失败时只允许有目的的定位分支，不直接扩大epoch。
