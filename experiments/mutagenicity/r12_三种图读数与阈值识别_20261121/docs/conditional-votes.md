# 在图大小模型的两个判决组内估计目标类别比例

2026-11-21。R10 五种子中即使在每张图上从 WL 和 B0 中选正确答案，PROTEINS 的 Accuracy 也仅为 64.68%，Size 为 65.60%。本先导允许在 B0 和 WL 都判错时选择另一类。旧 R12 在同源构造里检验过三读数的条件独立性和由同一份源表生成的分档对照。这次在自然形成的目标域检验一个更具体的假设：**给定真类和 Size 的硬判决，B0 与 WL 两张票的联合分布可以从源域移到目标域；每个 Size 组的正类比例可单独变化。** 这是稀疏联合漂移的一种固定分组。三个读数来自同一张图，拟合保留 B0/WL 的类内联合错误。区别于 R11，两个组能对同一种 B0/WL 投票作相反决定。[R12 原筛查](../report.md) · [稀疏联合漂移原文](https://arxiv.org/abs/2209.08436) · [R10 分歧与上界](../../r10_原生图适配基线与增量_20261121/docs/classifier-choice.md)

## 数据和唯一主规则

固定种子 3405，原三个开发设置各十二方向。复用 R10 的 B0、源验证选 C 的 WL 和 Size，在每图取 margin>0 的原始分类。记 x=2·B0+WL，z=Size。全源 V 只用于建立带标签的计数表。V 曾参与源 checkpoint 和 C 的选择，源拟合仅作校准。使用 R11 attempt-003-roc 已认证的同源三个等预算 A 子集及 H，保持 ID、顺序；R11 UNLABELED 阶段的 Size/GNN 核对基于无标签记录，WL 从冻结源模型前向。每个方向只用本域 A 拟合主规则。其他 A 用于交换对照。H 的每张图由既定八格表逐图分类。研究程序无需读取 A 类别。不训练 GNN、不跨源合并标签。先封存全部源计数、A 观测、所有规则、H 预测和角色，再用原授权 H 入口一次计分。

- 在 V 记整数计数 n(y,z,x)。每格加 1/2。源模板 g(y,z,x)=(n(y,z,x)+1/2)/(n(y,z)+2)，同层源比例 p₀(z)=(n(1,z)+2)/(n(z)+4)。静态后验用这两者作贝叶斯计算。没有源图的格对应等概率，等概率判 0。
- 对目标 A 内每个 z，用四格频数 a(x) 最大化 Σ a(x) log[(1−p)g(0,z,x)+p·g(1,z,x)] + p₀ log p + (1−p₀)log(1−p)。后一项相当于总权重一个源比例样本，保证内部唯一解。没有 A 图、源 V 在该层缺一类或两类模板完全相同时，直接沿用 p₀。以 p·g(1,z,x)>(1−p)·g(0,z,x) 判 1。所有判断平局归 0。用有理数计算每格临界 p* 处目标函数导数的符号作动作判据，可用另一数值根解核对比例。静态和回退动作直接用整数计数。保存实际源类数、目标层图数、模板总变差、估计比例、目标四格与拟合混合的总变差及改变动作数。
- 这是可被数据否证的工作假设。若两类模板都沿其差向量平移，同时反向调整目标正类比例，观测四格可逐格相同，真实最优动作可以不同。拟合残差很小本身不足以证明哪类正确。Size 常数时 A 仅提供一个活跃的层；在一层中出现的 H 图按该层既定动作分类。

## 竞争解释及判定

三个主要方法使用同一 V 和三张票。**Static** 沿用源八格后验。**Global** 用同一加半计数得到两个完整八格类模板，只拟合全 A 一个 p，使用同一目标函数和总权重一个的平滑，源比例为 (n₁+4)/(n+8)，缺类等回退同上。**Own** 按上述 z 分层拟合。再将 Own 的两份 p 都换成另一个等预算 A 的估计（两个异域分别评分后等权）。另固定 **OwnLock**，仅在 B0/WL 一致时强制用其共同动作；在分歧图上逐图复用 Own。对 Own−OwnLock 单列两者一致时的纠正、误改，以及按 Size 是否反对共同判决的计数。相应八格统计仅在评分后按方向聚合。原 B0、WL、Size、R16 源线性与二次融合 B/B₂、R11 同 A 的估计多数与直接按估计比例定阈均是固定强参照。核对历史 H 顺序与归档预测；既有带标签诊断臂不进入本研究。所有预测和源组按种子独立。

按十二个方向等权报告 Accuracy、Macro-F1、类别召回、常数块，以及主要比较的逐块净纠错和配对 Accuracy 区间，沿用 R11 图重抽样。仅在 PROTEINS 及至少一种 Mutagenicity 划分都达到下列标准时推进同一方法的四个备用种子：相对 Static、Global 及该设置上述固定强参照中的最高平均 Accuracy 均至少 +0.5 个百分点，超过两个异域臂的平均，且至少 7/12 方向胜过 Static。OwnLock 用于归因。若单一比例、静态融合或简单目标多数已能解释成绩，结束这项三票分组方法。两个 Mutagenicity 设置复用同一批分子。即使通过，新的图或外部基准仍需在固定协议下确认。
