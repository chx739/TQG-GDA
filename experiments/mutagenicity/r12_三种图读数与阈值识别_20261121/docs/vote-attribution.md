# 目标池的增量来自哪些图，比例与判决顺序各限制了多少

以下是种子 3405 正式评分后的描述性诊断。[原方案](conditional-votes.md)的各方法、强对照和补种子判定保持原定口径。复算只用已封存的 H 八格聚合计数、源模板和动作表。216 组逐图动作的 SHA-256 与评分前的[独立盲复算](vote-support.md)全部一致。[正式结果](conditional-votes-results.md)

## 允许推翻共识和使用目标信息分别带来多少改变

OwnLock 锁住两结构模型的共同决定。Own 对 OwnLock 估计的是允许推翻共识的总效果。Static 使用同一八格及源标签，在同一张图上允许相同类型的改判。Own 对 Static 才直接衡量用本域无标签 A 重估组内比例的增量。下表的数值均为各子集对**全部图**的 Accuracy 差贡献，按十二方向等权。每一列合计等于正式的 Own−Static。

| 哪些图上发生变化 | Mutagenicity 边数 | Mutagenicity 节点数 | PROTEINS 边数 |
| --- | ---: | ---: | ---: |
| B0、WL 分歧 | −0.173 pp | −1.715 pp | +2.081 pp |
| B0、WL 一致，Size 反对 | −0.129 pp | 0 | +0.465 pp |
| 三张票全部相同 | −1.849 pp | −7.182 pp | 0 |
| **Own−Static** | **−2.152 pp** | **−8.896 pp** | **+2.546 pp** |

PROTEINS 的共识改判，若与 OwnLock 比，纠正 167 次、误改 92 次；若与 Static 比，纠正 24 次、误改 20 次。后者仅在 Size 反对时发生。其余 29 次纠正、8 次误改来自 B0、WL 分歧的图。在两种 Mutagenicity 划分上，Own 胜过交换来的 A，却低于 Static；把本域与错误域相比有优势，仍不足以证明适配优于直接从源迁移。[逐设置配对计数与交换对照](../results/vote-attribution/source-and-foreign-differences.csv)

一个容易想到的修改是三张票全部一致时保留一致判决，其余逐图沿用 Own。从事后归因表移除这部分净改判即可精确计算，三个设置的 Accuracy 分别为 69.62%、71.32%、66.07%。仍低于相应的 71.49% 源二次融合、73.03% 源静态判决、66.95% 目标池多数基线。此次没有据此重新选规则。

## 如果知道每层有多少正例

沿用原来平滑后的源模板。给定 Size 层 z，一层四种 B0/WL 票型只能按源似然比 g₁(x)/g₀(x) 的次序依次跨过阈值。下表后三种上限允许看 H 标签，都属于同批开发图的事后上限。代入 H 观察比例一行也使用了监督信息。

| 层内决策依据 | Mutagenicity 边数 | Mutagenicity 节点数 | PROTEINS 边数 |
| --- | ---: | ---: | ---: |
| 部署 Own | 67.77% | 64.14% | 64.39% |
| 只在原可拟合层代入 H 实际正例比例，保留原回退 | 71.74% | 73.24% | 68.38% |
| 只在原可拟合层按 H 选最优工作点，保留原回退 | 74.37% | 74.07% | 69.29% |
| 所有层按 H 选最优工作点，仍遵守源模板的票型次序 | 74.37% | 74.07% | 73.41% |
| 每种票型单独选 H 多数类 | 74.94% | 74.57% | 74.56% |

在这批模型中，换成 H 的实际组内比例，就可恢复 3.97、9.11、3.99 个百分点。Mutagenicity 节点划分的损失主要能由此恢复。PROTEINS 还存在缺源支持的非空 H 层，放开原回退另有 4.12 个百分点的事后空间。任意允许非单调票型顺序相对全层最优工作点只多 0.57、0.50、1.16 个百分点。提升八格决策的复杂度因此并非首选。上限使用 H 选择规则会受有限样本影响，在新图上能恢复多少仍是另一项实验；两个 Mutagenicity 划分也共享分子。

两套独立核对分别枚举精确临界比例及间隙、按似然比降序整组合并同分票型，72 个层的整数正确数逐项相同。源模型在某层缺类或目标参考池为空时，第二、三行继续使用原协议的回退。[每层正确数与回退状态](../results/vote-attribution/prior-counterfactuals.csv) · [原始 H 八格计数](../results/attempt-002-conditional-votes/h-cells.csv)
