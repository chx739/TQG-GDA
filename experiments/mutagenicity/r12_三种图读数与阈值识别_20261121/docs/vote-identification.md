# 同样的三张票和真实组内比例，可以要求相反的纠错

以下为精确构造的二分类总体，用于解释[已登记先导](conditional-votes.md)依赖的假设。表中四列为 (B0, WL) 的 00、01、10、11。源域中 Size 的两个判决组各占一半，组内正例比例都为 1/2。两个 Size 组内的源类条件读数相同。

| 真类 | 00 | 01 | 10 | 11 |
| --- | ---: | ---: | ---: | ---: |
| 负 | .490 | .235 | .025 | .250 |
| 正 | .250 | .025 | .235 | .490 |

**目标一。** 两个 Size 组仍等大，其正例比例变为 0.3 和 0.7。表中的类条件读数保持。在每组中，目标四格频率是上述两行以真实比例混合的结果。两行不同，且每组都有观测，故在此假设下可唯一恢复比例。联合最优规则在 01、10 两种分歧上跟随 B0，在 00、11 两种共识上跟随 Size。源静态规则以及只校正一个全局比例的规则均跟随 B0，目标总体正例比例仍为一半。

**目标二。** 保留目标一的两张可观察频率表。在每个 Size 组内，将属于 00 的正例质量减去 0.03，加到 11；同时将 00 的负例质量加 0.03，从 11 的负例质量扣除 0.03。质量以该 Size 组的总量为分母。每个格的总频率和每组真实正例比例都与目标一完全相同，源监督观察也相同。新世界在 00、11 上的最优动作变为保留 B0 与 WL 的共识。

四格的可观察频率在两个世界均为 (.418, .172, .088, .322) 和 (.322, .088, .172, .418)。各项 Accuracy 直接对两个等权组及各格的真阳、真阴质量求和。这给出了一个分组规则相对纯源分类提高 2.80 个百分点的正例，也给出了它在相同无标签输入和相同真实比例下反而低 3.20 个百分点的反例。对于真实图，目标四格拟合误差小和比例估计准确仍不足以断定该推翻哪一个共识。需要在独立评分图上报告真实纠正与误改。

## 用两组无标签图学习排序，能否确定分类动作？

粒子物理的 CWoLa 从两个类别混合比例不同的样本组学习分类排序。若给定真类后的读数分布在两组相同，已知哪组更富集正类，则区分两组的似然比与真类似然比同序。普通 Accuracy 对应的阈值还要看类别比例或其他能识别两类分布的结构。[CWoLa 原文](https://doi.org/10.1007/JHEP10(17)174) · [混合分布的识别条件](https://jmlr.org/papers/v20/17-576.html)

一个二值读数 X 就能说明这个差别。两个世界的组 0、组 1 中 X=1 的概率都依次是 0.4、0.6，组 1 都更富集正类。第一世界中，两种真类出现 X=1 的概率是 0.35、0.95，两组阳性率为 1/12、5/12。第二世界对应概率是 0.05、0.65，阳性率为 7/12、11/12。在组 0 看到 X=1 后，真阳性后验分别约为 0.198、0.948。这两个普通 Accuracy 判决相反，无标签组频率完全一致。

回到种子 3405 的源验证表，以 Size 硬判为组别、两张票 (B0, WL) 为四值读数。两个 Mutagenicity 划分的八个源各自都在全部四格实际观察到两个真类，四格中均找不到某一类独占的票型。PROTEINS 的四个源里有三个在 V 只出现一个 Size 组。余下的源 2 在 S 的组 1 阳性率为 27/42，组 0 为 67/180；在 V 则分别为 3/13、21/43，富集方向发生反转。因此本项目没有把已有 Size 分组与双票直接扩展成新的无标签分类器。这是对这组源端观察量的核对；若要用新的分组，应另行说明富集方向、类内可比性和普通 Accuracy 的工作点如何辨认。[源票型计数](../results/attempt-002-conditional-votes/source-counts.json) · [各组正负数](../results/vote-support/source-support.csv)
