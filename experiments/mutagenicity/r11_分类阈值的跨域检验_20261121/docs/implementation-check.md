# R11 实现复核交接

实现复用 attempt-016/C 的原 B0 margin 和源 checkpoint，保持 3 个设置、4 个源域、每源 3 个独立目标、5 个种子。无标签预检已核对三个设置各一组的 V、A、H ID 和 margin 重建。正式流程先尝试认证完整 180 块，之后才解码 V 及 A。

阈值枚举同时包含唯一 margin、各自前驱与参考阈值。正确数采用 int64，距参考值用 float64 到有理数的精确转换处理，包括次正规数造成的距离差。V-only 读口只持封存的 V 文件，拟合函数只持 V 和 A 读口。A 从认证文件按授权 ID 对应的 offset 读取值，H 在本轮 OBS 后用独立读口开启。历史原始标签文件字节可用于完整性哈希，监督值的解码按角色和请求的图 ID 执行。

共同抽样下逐样本合成 OwnA−OtherMean，再取区间。H 的分域和共用阈值上限均仅在评价阶段计算，跨域等权目标用整数计数与有理数比较。全局门槛纳入 SourceV、OtherMean、B0 及方向覆盖要求。

合成回归覆盖等 margin、严格阈值、全同类、平局、uint8 计数、次正规数距离、分域和共用 H 上限、拟合角色与选择 ID、OBS 未建立时禁止开启 H，以及异域均值的共同重采样。
