# 固定分类排序后，目标域专属阈值有多少可重复的 Accuracy 空间？

2026-11-21 登记，尚未拟合本轮阈值或读取本轮结果。R9 的域内常数投票胜过逐图传递，但交换源、目标时源模型也换了。R11 单独检验一个必要前提：固定源模型后，知道目标身份和部分目标标签，能否在新图上选到比源阈值和异域阈值更好的工作点。这个试验使用目标标签作监督诊断。它本身不能作为无监督算法参加排名。[R9 报告](../../r9_目标近邻与源标签传递_20261121/report.md)

## 数据与对照

使用历史 R7 attempt-016/C，FINAL digest 为 `a97d6884ee74c456fce8b7c7e3ae9a5a5d6a72e22ac4b7b8835a06bf130a420c`。范围为 Mutagenicity 边数和节点数、PROTEINS 边数。每种划分包括四域间十二个方向，种子 3405–3409。按设置、源域、种子分成 60 组，每组三个目标共用一份 B0。核验 source.pt 身份、源验证图 V 的 ID 和分数、三个目标的 A/H ID、旧封存值。逐数据集检查 A 与 H 全局不交。源验证集 V 曾用于选源 checkpoint。不同方向间源和目标的角色会轮换，严禁把同一图的监督信息跨组传给估计器。NCI1 不在本轮范围。

每图唯一分数取 B0 的 float64 margin，即 logit[1] 减 logit[0]。每次都按 margin 严格大于阈值预测 1。模型、排序、H 和预测规则固定，变化因素只有估阈值用哪一池数据。

| 决策 | 阈值来源 | 用途 |
|---|---|---|
| B0 | 0 | 原始源分类器 |
| SourceV | 全部 V，最大化普通 Accuracy | 源域修正本身能带来多少 |
| OwnA | 本域 A 的带标签子集 | 同域阈值是否在 H 上重现 |
| OtherA ① / ② | 同一模型另外两个目标 A 各自的带标签子集 | 同等目标标签预算，换目标身份。两者的 Accuracy 取等权均值，保留单项 |
| H 最优阈值 | 全部部署动作封存并计分后在 H 枚举 | 测量该排序在这批图上移动单阈值所能达到的经验上限 |

三个 A 使用相同的标签数，取组三域 A 图数的最小值。以 UTF-8 文本 `r11-v1|<setting>|<decimal integer graph id>` 的 SHA-256 升序选图，哈希相同按图 ID 升序，同一阈值给所有对应的 H 使用。估计只读取授权子集，或在已封存历史角色的读口中按选中 ID 切出后交给拟合函数。所有阈值在对应拟合池上最大化分对图数。对每个唯一 margin 同时列入该值和其 float64 前驱（nextafter 朝负无穷），再列入参考阈值。平局选择距参考阈值最近者，再平局取较小阈值。SourceV 的参考为 0，A 臂的参考为 SourceV。H 上限只需要最大分对数。遇到不完整块逐项列原因并保留原分母。

## 输出与判断

先认证所有历史块、角色、模型和分数，登记实际输入与代码版本。先学 SourceV，再通过仅 A 的读口学所有目标阈值，逐图封存所有 H 决策；最后进入独立 H 评分。H 上限也只在评分阶段计算。留存块别阈值、拟合样本数、动作分歧、纠正/损害的整数计数、每类召回、逐方向五种子 Accuracy 均值与标准差、每个设置的方向等权结果。首要差值是 OwnA 减 SourceV 和 OwnA 减两组 OtherA 的平均，以百分点计。对 B0 的增量也完整报告。沿用 R7 配对图重采样，同一设置及目标内各源和种子共用 H 图权重。区间条件于已选阈值，不含重新采样 A 的不确定性。两个 Mutagenicity 设置源于同一数据集，分别报告。

- 如果 H 经验上限相对 SourceV 都很小，这批排序给单阈值策略留下的余地小。若 H 上限可观、OwnA 却无法胜 SourceV，说明在现有标签预算和划分下，即便监督拟合也难以把收益迁移到 H。
- 如果 OwnA 胜 SourceV 但换成 OtherA 仍能取得相同收益，先研究各域共享的源校准偏差。为了把域专属阈值列为下一轮优先项，预先要求至少两个设置的上述两个主差值均达到 +1.0 pp，且各有至少 7/12 个方向同时为正。另报第三个设置的方向和区间。这个投入门槛是本项目的约定。
- 如通过，只证明目标域有可重复的阈值差异。下一项实验须预先冻结一个只读源标签和无标签 A 的估计器，并与同一估计器交换 A 的结果比较。若未通过，停止围绕 R9 常数投票调参。结果只涉及这些冻结的 B0 排序；逐图改排序或改表示的方案有不同的验证条件。

### 计分前的反例核对

即使不同目标域共享一个最优阈值，有限 A 样本也可能在不同 margin 区域产生平局，导致选出的阈值在跨域时变差。为直接检查历史 H，对同一源模型的三个 H 再求一个共用阈值，最大化三个域 Accuracy 的等权均值；它与三个域各取最优时的等权均值之差给出这批 H 分开定阈值的最大额外收益。两者相等意味着存在一个阈值同时达到这三个 H 各自的最高 Accuracy。用整数计数和样本数判断相等。这两个上限仅在最后评分时计算。

若所有经调节的对照都比 B0 差，击败这些对照不足以支持继续开发。通过前述投入门槛的每个设置还须满足 OwnA 的平均 Accuracy 严格高于 B0。OwnA 的监督收益、目标身份是否有用以及未来估计器在无标签条件下是否有效分别作答。

评分区间沿用的按类图重采样固定了每域 H 的类别数、五个源模型和各池拟合的阈值。OwnA 减 OtherA 均值在每次共同抽样内先形成差值再取分位数。源 V、目标 A、最终 H 使用分开的读口，历史 C 已经计分不能替代本轮的权限分离。
