# 一条源端大小曲线能解释多少蛋白质迁移收益？

R11 的 Size 用节点和边的对数、常数截距及源验证选择的正则强度外推类别概率。P1→P3 的四个候选在 A 上都预测约 15%–17% 阳性，而已公布的 A 阳性率为 77.35%。如果用更简单的大小曲线就能判对多数类，后续方法必须说明它还分对了哪些与域内多数类不同的图。[R11 已有结果](roc-rate-transfer-results.md)

在 PROTEINS 边数四域，令 n 是单图节点总数，用源训练集 S 的原始二分类标签拟合单参数函数 b(n)=exp(−λn)。λ 非负，通过伯努利极大似然确定。它假设图越大，仓库中编码为 1 的标签概率越低。这个外推形状本身需要作为基线接受检验。这里的参数没有蛋白质活性位点的生物学含义。

**登记时已经知道什么。** 种子 3405 的四个源验证集上，这条曲线共分对 159/221 张，原 Size 共 153/221 张。我们也已在登记前看过这个种子的历史 H 聚合计数。用 b 在 A 的均值判断整个目标域的多数类，按十二方向等权的历史 Accuracy 约 70.03%，原池多数约 66.95%。十二方向只改了两方向，且各有一胜一负。这组探索性数字会经正式逐图评分核对。其他种子也是原开发图的复用，每个种子都单列。

## 哪两步可能贡献收益

复用 R11 原源训练图、各方向等预算 A、独立 H、冻结的 GNN 二分类 margin 及原标签映射，覆盖 3405–3409 的 12×5 块。每源域每种子拟合一次 λ。固定原类别方向与 0.5 判正阈值，等于阈值时判 0。记录两类样本数、节点数范围、λ 及数值收敛。单类源训练集的极限模型取该常数类。每张查询只使用自己的节点数、冻结分数和训练阶段已定的常量。需要目标参照的规则也可使用预先选定的 A。部署预测先封存，再读取 H 标签，A 类别不进入此次比较的拟合和决策。

| 分类规则 | 成对检验 |
|---|---|
| 单图预测 b(n)>0.5 | 与原 R10 的单图 Size 比较源端外推曲线，与下行池多数比较是否有必要给整域同一个动作。 |
| 本域 A 上 b 的平均值 p 超过 0.5 时全判 1 | 与原 Size 池多数比较时只换比例估计器。与同源的两个等预算异域 A 分别比较时只换参照池。另列源训练集多数类。 |
| 固定 B0 排序，按本域 A 的 p 设置判正分位数 | 完全复用 R11 DirectP 的平局、无穷端点及阈值迁移规则。与旧 DirectP 比较时只换 p；与上一行比较时固定同一 p。分别只换 p 的供体或只换定阈用的 A 分数分布，另一项保持本域；列出两个异域结果及等权均值。阈值从 A 转到 H，推断单张 H 图时无需其他 H 图。 |

同一份表列 B0、原 Size、原 Size 池多数、原 DirectP 及上述单图与整池规则。所有臂使用相同 H 和覆盖。输出逐块混淆矩阵、全判同类的块数、纠正与误改，算普通 Accuracy 与同一组硬预测的 Macro-F1。每方向先平均种子、每个设置方向等权，另列 3405 和 3406–3409、胜平负，以及去掉每一个目标域的结果。复用原 A、H 的实体身份，注明同一目标和不同种子的重复。

如果新曲线只提高整域猜多数的 Accuracy，结论限于域先验的外推。若想继续把该分位数规则发展为图级适配方法，预先要求它在 3406–3409 相对原 DirectP、单图大小曲线、使用同一 p 的池多数、原 Size 和 B0 中设置平均最高者至少高 0.5 个百分点；本域分别胜过两组交换参照的均值，且至少七个方向胜过该最强参照。0.5 个百分点及方向数是本项目的投入门槛。若主要提升来自一个目标域或伴随 Macro-F1 下降，报告具体影响。达到门槛再讨论新图或新域上的确认；这个蛋白质试验单独不能验证分子设置上的优势。[TU 图分类指标和可比性](../../../../docs/guides/research-retrospective.md#真实图怎样判断稳定性)
