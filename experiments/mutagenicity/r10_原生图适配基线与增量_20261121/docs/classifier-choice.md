# 同一个源模型迁往三个目标时，是否值得按目标改选分类器？

后续[同最强源参照比较的逐图上界](vote-bounds.md)给出新的限制。即使逐图知道答案，B0 与 WL 二选一在 PROTEINS 上也只有 64.68% Accuracy，低于 Size 的 65.60%。

2026-11-21。R10 attempt-003 的 FINAL 已生成。策略会话在读取其分类结果之前写下以下判读，属于对既有开发结果的二次分析。只读 FINAL 认证的逐块配对计数与配对区间，不重新读取目标标签、预测或图，不改变原基线的成败判定。[原始方案](structural-reference.md)

固定两名候选：源验证选 C 的 WL 和原图网络 B0。对设置内的每个源 s、目标 t，在五种子及同一批图上求 Accuracy 差 d(s,t)=WL−B0，先逐块用（纠正−损害）除以图数，再对种子等权。区分下列三种使用事后答案的能力。

- 每个源只选一个分类器去三个目标，在 B0 之上最多增加 max(0, 三个 d 的平均)。若每个目标都能提前知道胜者，可增加三个 max(0,d) 的平均。两者之差叫作**按目标选整套分类器的额外空间**。同一源三项同号时严格为零。两项都是看过开发结果的参照，在实际无标签协议中无法获得。
- 逐图知道谁正确，尚可比该方向最好的固定分类器多分对一部分图。逐方向先对五个（WL 独对比例、B0 独对比例）取均值，再取二者较小值；两者之和为分歧图比例。两个量的差别区分按目标选择与按图纠错的可能空间。作为数值复核，把第一项额外空间按每个已训练源种子分别计算，再平均。
- 分歧大小本身无法识别哪一方正确。在同源三个方向里另报是否出现符号相反且各自原配对 95% 区间均不含零的两个方向。这一条件仅描述已拟合模型对这批 H 的结果，三个方向不能视作独立复现。

不估计事后胜率，不使用这项分析训练选择器。若整域切换在 PROTEINS 或两种 Mutagenicity 均连 0.5 pp 的五种子等权额外空间都没有，就不投入以这两名分类器逐域硬切换为唯一机制的方法。若空间存在，下一项投入仍需一个可用无标签量预测胜方的独立理由；必须比较逐图源监督门控及静态集成。若分歧图较多，最多说明两者的错误互补。这一上界不约束改变表示或逐图改变分类决策的其他算法。

两种 Mutagenicity 的整域硬切换空间均低于 0.5 pp，这条路线结束。方向赢家在 PROTEINS 有实质差异，其中只有源 2 同时出现两边区间均排除零的反转。WL−B0 到目标 0 为 +7.63 [2.47, 12.78] pp，到目标 1 为 +7.61 [1.13, 14.08] pp，到目标 3 为 −7.47 [−14.70, −0.72] pp。这组差异说明目标域有影响，部署时如何预测赢家仍是开放问题。当前没有证据把最后一列的上界当作可实现的增益。
