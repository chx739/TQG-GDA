# PROTEINS 的原始节点属性能多分对哪些图？

## 这次决定什么

R5 的图输入使用三类离散节点类型，原始 TU 文件还含有一个数值属性。此前在 110 张有角色记录的源图中，同一张图内类型和度数相同的节点也可取不同数值。该观察只说明端点可区分。这次仅检验一个假设：在大小偏移下，各节点类型的属性中位数是否含有超出 WL 与图大小的类别信息。若通过，获得一项今后比较 GDA 时须纳入的同输入强基线。本次不训练适配器。[原始字段核验](size-support.md) · [已封存的单模型与联合基线](../../r9_目标近邻与源标签传递_20261121/docs/reference-geometry-results.md)

## 固定比较

1. 范围为 R9 种子 3405、PROTEINS 边数划分、四个历史源域内部的小→大和大→小，共八个方向。逐方向沿用原图号与 D/C/E，D 标签拟合、C 标签选正则。U 完全不用。八方向全部预测封存后才按本方向 E 角色评分。复用的 E 仅作开发评价，不接触真实四域迁移的适配池或测试池。[既有角色](../../r9_目标近邻与源标签传递_20261121/results/attempt-002-weighted-residuals/roles.json)
2. 保留 WL、Size、Base 三臂。Base 将原半径 0/1/2 带类型 WL 向量与源 D 标准化的两列 log1p 大小拼接。新臂只给 Base 添加三个数，每个离散节点类型一个属性中位数，偶数个值取中间两个的算术平均。保留原始有限值（含负值）；新增输入逐图按 TU 文件的行归属确定，核验 R5 登记的原始文件哈希和离散类型对应关系。对每个新增坐标，用有该类型的 D 图中位数特征的均值、总体标准差作标准化。图内类型缺失时该坐标取标准化后的 0；D 中全缺失或标准差为 0 时该坐标对所有图固定为 0。图上的节点顺序不影响结果。同图同类型内重排数值应逐图给出完全相同的特征，本次度量的是属性分布摘要。
3. 两个输入模型用同一种带自由截距的 L2 logistic，各自用相同预算在 C=0.1、1、10、100 中选值（先比较校准集普通 Accuracy，再比低 NLL，仍平则取较小 C），margin>0 判正。单类别 D 沿用 R9 的平滑常数。原三臂可直接复用已验证的 R9 同图封存预测，需检查原臂的 D/C/E、参数和图号完全匹配。不得用 E 标签选特征、阈值、缺失处理或尺度。[R9 算法和核验条件](../../r9_目标近邻与源标签传递_20261121/docs/reference-geometry.md)

## 判读

同一批预测计算普通 Accuracy、Macro-F1 和 NLL，与三项参照逐方向报告分歧、纠正和误改。每个方向先算百分点差，再对八方向等权；每个源组取组内两方向等权。若新臂对 Base 平均至少 +0.5 个百分点、严格超过独立 WL 和 Size 的八方向均值、且相对 Base 在至少三个源组为正，则将这套同输入分类器带入后续比较。否则停止这项固定摘要，不在同一 E 上试均值、极值或新的特征组合。这里的门槛用于决定研究投入。即便通过，结论也只涉及源监督学习。

要另作“目标池帮助纠错”的主张，后续须先说明该池提供的哪个观测会改变同输入强源模型的哪些判决，再固定查询图、可见属性和源监督预算，比较本域未标记池、等预算错池及无池源模型。若三者判决相同，这一目标池在这些图上的 Accuracy 增量必为零。
