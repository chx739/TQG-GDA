# 同一图大小在几个域内实际出现？

对 R10 大小参照作输入核对。每个设置分别将该域作为源，以 R7 C attempt-016、种子 3405 所认证的 S、V 角色逐图读取其结构；S 和 V 合起来恰为该源域。读取器逐张核对 R5 的输入哈希与角色。跨源组只汇总大小频数，未读取目标图类别或将其他源组的图用于拟合。节点数为原图节点行数，边数为去掉自环、合并两个方向后的唯一无向边数，与 R10 相同。[R5 四域索引约定](../../r5_原始方法与请求价值_20261114/docs/r5-protocol.md) · [角色与哈希核验代码](../../r9_目标近邻与源标签传递_20261121/src/local_vocabulary/audit.py)

最后两列衡量域编号的可辨别性。对每个已观测大小 c 计不同域中有该大小的图数；只在恰有一个域时计入倒数第二列，取各域中最大计数再求和得到末列。这里没有使用整图分类标签。每个设置的相邻域只共享切点这一个整数，非相邻域的实测大小集合完全不交。若用源池估计目标图在“同一大小下”的结构分数均值，除切点外必然涉及外推。直接用单图大小预测标签仍是合法的源基线，其效果应和目标队列提供的额外信息分开度量。[源基线实测](structural-reference-results.md)

Mutagenicity 的实际节点数跨度还涉及孤立节点。4337 张原图有 121 张含无非自环邻居的节点，共 2401 个，五张图的这类节点超过自身节点的一半。零基 ID 2143 有 417 个节点、100 条唯一无向非自环边，其中一个分量有 99 个节点，另有 318 个孤立节点。最大边数来自另一张图，ID 1525 有 172 个节点、112 条边。PROTEINS 对应为 1113 张中 5 张、共 5 个孤立节点。一份独立核对直接读取原始 TU 压缩包中的图归属文件和边表，与解压件逐字节、与 R5 登记的文件哈希相符。两种 Mutagenicity 设置的全部 4337 张图都与 R5 归档的节点数和边数逐图相符。孤立节点的化学来源或对标签的作用需要独立证据；不能把它们统一解释成填充，或据此删图后与原始四域表直接比较。[TU 文件定义](https://chrsmrrs.github.io/datasets/docs/format/) · [TU 数据集说明](https://chrsmrrs.github.io/datasets/docs/datasets/)

进一步按 TU 原始图内顺序（从 1 开始）检查端点。38 张节点超过 99 的图在两个划分中都属 M0；36 张的最大有边位置恰为 99，另两张均为 103。这 38 张图共集中了 2274/2401 个孤立节点；其余 4299 张图的最后一位都有边。该规律能在原始边表重现，上游成因未核实。用两种划分的 120 个 R7 C 认证 manifest 只核对 H 的 ID，各自恰有同样 8 张这样的图，均位于 M0。固定其它图的分类动作，只在这类图上纠错，即使 8 张全部从错变对，十二方向等权 Accuracy 最多增加 **0.619 pp**（边数）或 **0.623 pp**（节点数）。重新训练后影响其他图的方案不受这个直接改判的上界约束。[R7 数据角色](../../r7_共同解释与共享更新验证_20261119/docs/r7-protocol.md)
