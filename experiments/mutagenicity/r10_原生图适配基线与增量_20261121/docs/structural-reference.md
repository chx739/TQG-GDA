# 在所有开发方向上建立只用源标签的结构基线

2026-11-21。登记于 R13 评分之后、R14 的实现和 R9 无标签词汇覆盖审计期间。R10 原生 GRADE 与同架构源模型只有 Mutagenicity 边数两个方向，R8 的源融合也限于相同两方向，R9 的 WL 分类器只在源内构造过伪迁移。只胜过 B0 或 SourceCal 还不足以证明方法超过一个有竞争力的图结构预测器。本项要回答同一个源域分类器在不同目标上能达到多少普通 Accuracy，以及是否只用图的大小就能解释。无需训练 GNN。未读取本项的真实目标预测或评价结果。[R8 源融合](../../r8_图结构观察量与类别约束_20261121/report.md) · [R9 的 WL 设定](../../r9_目标近邻与源标签传递_20261121/docs/source-bridge.md) · [原生 GRADE](../report.md)

## 固定参照

沿用 R7 C attempt-016 的 S/V、目标 H 角色和 R11 的 B0、SourceCal。Mutagenicity 边数、节点数以及 PROTEINS 边数各十二个方向，种子 3405–3409，共 180 个方向与种子组合。每个设置、源域和种子训练一次，三个目标复用同一个预测器，共 60 个训练组。两种 Mutagenicity 划分与各源组之间单独拟合。模型在所有训练与选模中只见该组的 S/V，无需任何目标 A 数据、图标签先验或 H 特征。对该组三个 H 逐图用原有 ID 推断；所有配置、选择和预测封存后才开放 H 标签。NCI1 保持封存。

- **WL 固定参照**。复用 R9 的半径 0/1/2、节点/边类型编码、每层整图频数 L2 归一化、三层等权及仅 S 建词表，保留未知颜色在该层归一分母中的贡献。Mutagenicity 用原节点和键类型；PROTEINS 三种节点类型、所有边同一类型。源模型为 R9 的稀疏二项 logistic，截距自由，原有正则 C=1，不加类别权重。特征核属于 WL 子树核家族，此处明确使用本仓库的归一化、边类型和 logistic 读出。[Shervashidze 等原文](https://www.jmlr.org/papers/v12/shervashidze11a.html)
- **WL 源选模参照**。同一特征、词表、训练目标和普通 argmax，用 C∈{0.1,1,10,100} 在 S 独立拟合；C=1 直接复用固定参照。V 上先选普通 Accuracy 最高的候选，平局取总体 NLL 低者，再平局取较小 C。保留全部 V 候选值，固定所选模型后推断三个域。这个对照代表从已获准的源验证标签中选择正则强度的能力；不以测试成绩选择基线。
- **大小参照**。每张图仅用 log(1+节点数)、log(1+去自环唯一无向边数) 两项。按 S 的均值、总体标准差标准化，常数坐标的 scale 取一，再用相同的二元 logistic、同一组 C 和相同 V 判据。各分类器以 margin 严格大于 0 时预测 1。每个预测器的标签空间、类别语义、训练图 ID 都来自源组。

必须保存普通 Accuracy、纠正和损害计数、BA、两类召回、AUROC、NLL；每个设置报告各方向五种子的均值与 SD，再对十二方向等权。主要配对比较为 WL 源选模减 B0、SourceCal、大小参照，另报固定 WL 减 B0 及选模 WL 减固定 WL。区间沿用 R11 的 H 图配对重抽样；各方法、源组和种子在同一目标域共用图权重，说明区间条件于这批已拟合模型。全部 180 块均纳入。只在相同图、种子及角色可核验时引入已发表的其他逐向对照，报告其覆盖数。单种子 R13/R14 的机制价值应与该相同种子下的 WL 比，不能和五种子的平均横比。

若 WL 在多个域超过 B0，则把它作为后续图级适配的源监督参照并判断目标 A 带来的额外收益。若两者优势随方向互换，保留两者的完整成绩，不按目标标签挑选逐域赢家。即使一个只用源图的参照表现稳定，也只证明表示或读出有源监督价值，无法归因于利用无标签目标图。
