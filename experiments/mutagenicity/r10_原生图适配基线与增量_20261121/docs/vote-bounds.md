# 只在 GNN 与 WL 分歧时改判，能否超过最强源参照

这是对 R10 冻结预测的事后分析。各设置均含十二个迁移方向、五个种子。对每块，假如提前知道答案，在 B0 和 WL 中逐图选模型，正确数恰等于 B0 正确数加 WL 相对 B0 的纠正数。两者一致时它们犯的错都会保留。表内为各块等权平均的 Accuracy。

| 设置 | B0 | WL | Size | B0/WL 逐图知答案选择 | 两模型上界减 Size |
| --- | ---: | ---: | ---: | ---: | ---: |
| Mutagenicity 边数 | 69.04% | 71.49% | 58.25% | 79.53% | +21.28 pp |
| Mutagenicity 节点数 | 70.87% | 70.99% | 58.56% | 79.60% | +21.04 pp |
| PROTEINS 边数 | 55.46% | 53.29% | 65.60% | 64.68% | −0.92 pp |

对于这批 PROTEINS 预测，只在两者分歧时二选一的任何方法，连 Size 的五种子平均准确率都达不到。各方向的差别很大。P3→P0 和 P3→P1 的上界分别低于 Size 59.59、44.23 pp。换到 P0→P2，上界反而高出 29.66 pp。五个种子各自十二方向的差为 −1.06、−2.07、+4.02、−5.66、+0.19 pp。这些上界使用已知答案；它们约束的是当前冻结模型和当前图。[原始正确数及召回](../results/attempt-003-structural/endpoints.csv) · [原始配对计数](../results/attempt-003-structural/paired-blocks.csv)

## 图大小模型在哪些图上确有不同的信息

只看 B0 和 WL 意见一致、Size 作相反判决的图。比较两条规则，均在其他图给出相同判决，一条在这些图上保留两者共识，另一条听从 Size。下表把纠正和误改都折算到**全部图**，允许与已发表混淆统计相容的所有格内标签数；区间为计数约束界。

| 设置 | 此类图占比 | 听 Size 可纠正 | 听 Size 会误改 | 净 Accuracy 变化范围 |
| --- | ---: | ---: | ---: | ---: |
| Mutagenicity 边数 | 32.17% | 6.70%–12.49% | 19.68%–25.47% | −18.77 至 −7.19 pp |
| Mutagenicity 节点数 | 32.78% | 7.12%–12.46% | 20.32%–25.66% | −18.55 至 −7.86 pp |
| PROTEINS 边数 | 39.07% | 22.48%–25.52% | 13.55%–16.59% | +5.88 至 +11.96 pp |

在两种分子划分上，无条件听从 Size 会造成净损失；在 PROTEINS 的开发方向等权平均则确定有净收益。同一设置的不同源和目标仍可能给出相反结果。这说明一个候选需要既能推翻两名结构模型的共同错误，又能识别何时保留它们的共识。按数据集名称事后决定信谁会用到这些开发结果。[逐块输入与界](../results/vote-bounds/blocks.csv) · [设置汇总](../results/vote-bounds/settings.csv) · [R12 先导设计](../../r12_三种图读数与阈值识别_20261121/docs/conditional-votes.md)

## 如何复算

从原 R10 OBS 的三个无标签动作统计每块八种票型的数量 nₓ，位序是 B0、WL、Size。从 FINAL 认证的源方法端点取 H 正例总数 P 和三个真阳性数 TPⱼ。对每种票型设一个未知整数 kₓ，表示其中有多少正例。约束为 0≤kₓ≤nₓ、Σkₓ=P、Σₓxⱼkₓ=TPⱼ。无需知道任何图的真实标签。若 Size 是反对两张相同票的唯一成员，改判的纠正数为 k₀₀₁+n₁₁₀−k₁₁₀，误改数为 n₀₀₁+n₁₁₀ 减纠正数。对所有可行整数解分别取两端即可。这些界对每块是精确的；对重复使用相同图的不同块未强制共享标签，逐块界等权后仍为有效界。

同样，允许按块看答案为八种票型分别挑一个类别，最佳正确数为 Σₓ max(kₓ,nₓ−kₓ)。其逐块可行极值等权后，三设置的 Accuracy 分别在 [73.21%, 83.47%]、[73.28%, 82.17%]、[74.42%, 78.38%] 范围内。一个同样能看答案、只在 B0、WL、Size、全正和全负之间逐块挑一个的对照已分别达到 72.95%、72.99%、74.31%。因此分格表相对这个对照的可能增量为 [0.27, 10.53]、[0.29, 9.17]、[0.11, 4.06] pp。八格表有表达空间，PROTEINS 的结果也容许只比选对整域规则多分对很少几张图。无标签数据能否决定这些动作，需要单独验证。

复算校验 R10 FINAL、OBS、两份汇总表和 180 个预测成员的哈希，读取硬投票后即按八格聚合，不打开 A 或 H 的标签文件。两种精确整数算法对 180 块的全部极值给出相同结果。一种固定 B0/WL 双正票中正例数，枚举组内 Size 正票的可能分配；另一种枚举四个自由格，再用四个独立计数方程确定其余四格。另用混合整数规划交叉核对。PROTEINS P2→P1 的种子 3406 上，数值求解器少报一个可达到的正确数；该块仅七种可行整数表，全枚举核定最佳正确数范围为 55–61。其他块的数值极值与整数枚举相同。保留了每块聚合输入和极值供重算。[原始 FINAL](../results/attempt-003-structural/FINAL.json)
