# 源分类误差怎样经过参考图影响新判决

这一推导对应[源内大小迁移筛查](reference-geometry.md)。它说明主臂在哪种情形下可以多分对图，也给出同样观测下必然存在的歧义。

设 C₀ 为联合基线在源校准集选定的 logistic 正则参数，a 为协议给定的尺度，p(d) 为**当前重拟合模型**对源训练图 d 的正类概率。额外特征为 a·p_R(d)/√2。对其权重写出 L2 正则化一阶条件后，这一块在新图 x 上贡献的 margin 恰为

$$
\frac{C_0 a^2}{2}\sum_{d\in D}\big(y_d-p(d)\big)\,
\mathrm{Cov}_{r\in R}\big(K(d,r),K(x,r)\big).
$$

推导只用 logistic 残差与特征的乘积，正则目标与源模型相同。它和早期梯度 TQG 都用带标签源残差确定方向。这里参考池影响的是残差传往另一张图的权重；所有源模型参数联合重拟合。固定参考池后，额外特征仍是原 WL 词频的线性函数。可能的贡献来自正则化使用了本域结构之间的关联，以及源训练图未见、但可经参照图与源词相连的词。若原有判别方向已足够好，重新加权也可以损害分类。[TQG 与 TSBA 的出发点](../../../../docs/method/design-zh.md) · [源 logistic 的实际目标](../../r8_图结构观察量与类别约束_20261121/src/composition.py)

**一个可精确重放的四词例子。** 用四个正交单位向量表达四种结构词，源训练正、负样本分别只有第一词和第二词。两张无标签参考图分别含第一与第三词、第二与第四词，每图 L2 归一化。两张查询图分别只有第三词、第四词。大小量为常数，取 C₀=1。按登记的方差匹配，a=2。用相同源标签拟合，完整本域参照给两查询的 margin 约为 +0.200529 和 −0.200529；原 WL、源参照及对角方差臂都给两个零分。这个对称例的最优截距为零，零分按固定规则归为类 0。

若两个查询的真实类别为 1、0，完整本域参照分对 2/2；若为 0、1，它分对 0/2；三个对照在两个世界均为 1/2。两个世界的全部训练观测、无标签参照和预测完全相同。数值是线性特征夹具的复算，不代表真实图结果。该例也说明只在源已见词表内计算查询与参照的内积，会消去一条待检验的信息通路。
