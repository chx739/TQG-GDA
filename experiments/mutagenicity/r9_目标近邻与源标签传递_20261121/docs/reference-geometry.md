# 目标参考图之间的结构共变能否改善源监督分类？

2026-11-21。R7 的本域更新能够纠正原 GNN，但在 PROTEINS 的 154 次净纠正中，有 153 次已经由源监督 Size 作出了相同改判。R9 配平源残差能缩小 WL 均值距离，但没有改善分类。本次直接用有标签的源图学习判决。无标签目标图仅决定哪些结构差异在预测器的正则化中获得更大权重。假设是两种结构如果在目标图中一起增减，源图上学到的判别信息有时可沿这种关系转移。若结构同现主要反映大小或背景，等预算源参照、仅利用各词方差的对照或原分类器就能达到同等效果。[R7 强源对照](../../r7_共同解释与共享更新验证_20261119/docs/transfer-of-flips-results.md) · [R9 加权残差](weighted-source-residuals-results.md)

把样本表示成它对一组参照的相似度已有理论和实证工作，域适配中用无标签数据估计特征子空间也有先例。这里检验的是在当前大小迁移任务中，相似度的共变是否提供超出同预算强基线的分类价值。这个筛查本身不构成方法创新证明。[Balcan 与 Blum，ICML 2006](https://doi.org/10.1145/1143844.1143854) · [Fernando 等，ICCV 2013](https://www.cv-foundation.org/openaccess/content_iccv_2013/papers/Fernando_Unsupervised_Visual_Domain_2013_ICCV_paper.pdf)

## 数据和算法

- 完全复用 R9 attempt-002 的种子 3405、三个设置、每个设置四个历史源内的两个大小段方向及原图 ID。D 为有标签拟合，C 为有标签源校准，U 为无标签伪目标参考，E 为另一批伪目标评价图。每个方向独立拟合。两方向的角色有复用，统计单位保留历史源组。不使用真实迁移的 A/H、U 标签或外部数据。全部 24 方向预测封存后才按本方向 E 角色评分。[角色与权限](weighted-source-residuals.md)
- R9 带类型 WL 的半径 0/1/2 归一化向量记为 F(x)，包括所有词对归一化分母的贡献；K(x,r)=F(x)·F(r)。Z(x) 为两项 log1p 大小，用 D 的均值、总体标准差标准化，常数除以 1。分别在 D 拟合 WL、Size 和联合基线 Base=(F,Z) 的二元 logistic，截距自由；三者各按 R10 的四个 C 值在本方向源校准集选普通 Accuracy，平局看 NLL 再取较小正则参数 C。所有新臂共用 Base 所选 C，决策为 margin>0。单类 D 时所有臂用 R9 已定的平滑常数。
- 两个等预算参照池各取 m=min(|C|,|U|) 张。按 SHA-256 对 UTF-8 串 `r9-geometry-v1|{setting}|{source}|{graph_id}` 排序后取前 m，图号作最终平局键，十进制无前导零。C 参照仅用特征；源校准标签的用途和预算各臂相同。对 R 中每张参照 r 定义 p_R(x)_r=(K(x,r)−mean_{j∈R}K(x,j))/√m。同一图中使用的均值只依赖该图与冻结 R。两图 p 内积恰等于它们对 R 的相似度的总体协方差，即 F(x)ᵀ Cov_R(F) F(x′)。
- 对额外特征块 v，用 D 图的总方差 T(v)=mean_D ||v−mean_D(v)||² 固定尺度。设 a=√(T(F)/T(v))。新输入为 (F/√2, a·v/√2, Z)，使结构块在 D 的总方差与 Base 相同。原始 WL 块只需 D 中出现的坐标；计算 T(F) 用完整 D 特征。相似度允许查询和参照共同出现的词，即使该词在 D 不曾出现。T(F) 或 T(v) ≤1e−14 时该臂直接返回已拟合的 Base。C、U、E 不参与 D 尺度的估计；参照池的身份定义 v。
- 唯一主臂 **TargetFull** 使用 v=p_U，其中 U 指选出的 m 张。**SourceFull** 只将参照改为 C 的 m 张图。**TargetDiag** 保留同一 U 并令 v_j=F_j(x)·sd_U(F_j)，使用总体标准差；此时只保留协方差矩阵的对角。各臂依同一方差规则归一，并报告缩放因子。对角线对照同时改变了非对角项和用于总方差匹配的标量，所以比较解释为固定结构总方差下的整体收益。源图只见 D 标签，不为参照图或 E 生成伪标签。另给出沿 Base 排序、与 TargetFull 在 E 上阳性数完全一致的对照，平局按图 ID 升序；它只用于解释重排。

## 核验与投入判断

在人工小矩阵中核对相似度协方差恒等式和对角形式、调换参照顺序不改变最终 margin、常数参考准确退回 Base、额外块为 F 自身时与 Base 的正则问题等价。另用一组源中没有但与源词在参考图上共同变化的词，核对完整特征与错误地只用 D 词表算相似度的差异。目标中也可把这种新词与类别的关系反过来，保持全部源标签与目标边际不变；类别可迁移性仍须计分。

每设置八方向等权，主指标普通 Accuracy，同表列 Macro-F1、逐方向与逐源组的纠正／误改、方法间分歧；另报 NLL 和与 Base 同阳性数的配对差。必须保留两个单模型参照。若 PROTEINS 及至少一个 Mutagenicity 划分都满足 TargetFull 对 Base ≥0.5 个百分点、严格胜过 SourceFull 和 TargetDiag、且严格高于该设置 WL 和 Size 二者，并在至少三个历史源组上较 Base 净增益为正（组内两方向等权），才进入真实四域开发试验。用整数计数的有理数判断门槛。若只提高于 Base 而不胜 SourceFull，归因于额外的结构表示仍是可行解释；若真实共变不胜 TargetDiag，则目标词方差已能解释这项结果。若条件未满足，结束这个固定表示的跨设置推进，不在同一 E 上扫描参照数、混合权重或正则强度。旧 E 已参与其他方法的研究，这一步是源内开发筛查。
