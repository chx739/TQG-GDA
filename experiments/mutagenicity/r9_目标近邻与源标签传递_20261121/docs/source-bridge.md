# 第一阶段：仅在来源内检验两跳结构邻居

2026-11-21，登记于 R8 固定均值诊断之后。该诊断有分类改善，但 M1 使用另一个目标域的权重取得更高 Accuracy。R9 改问局部问题：对某一张图 h，结构相似的适配图 a 是否能把投票权转给更可靠的带标签源图 s？若目标图与源的局部片段有重叠、途经不同片段的两段相似性都保留类别信息，h→a→s 或可纠错。一个反例是两张图有相同骨架而标签取决于很小的不同取代基，中转可能增加系统性误配。该实验只决定是否值得投资真实跨域验证。

WL 子树指纹、相似图上的标签传播及图级 GDA 的标签传播均为既有方法。先把“增加一个描述图的特征”“增加平滑程度”“中间图改变哪些源图得到投票权”区分开，再讨论贡献。[WL graph kernels](https://www.jmlr.org/papers/v12/shervashidze11a.html) · [Zhu 等的谐函数方法](https://mlg.eng.cam.ac.uk/zoubin/papers/icml03zgl-subm.pdf) · [LP-TGNN](https://proceedings.mlr.press/v280/wen25a.html)

## 数据与可见信息

- 仅使用 R8 首次 OBS 认证的 M0、seed 3405 的 `source_fit_ids` 和对应 R5 源训练角色标签。用图 ID 核对拓扑缓存，计算只涉及名单内的图。M1、M3、其他真实目标域和外部 NCI1 均不进入本阶段。M0 已用于既有研发，所以这里属于来源内筛查。
- 按无向边数的不同取值切为上下两组，取使两边图数差最小的切点；并列取较小切点，相同边数不跨组。两个方向分别以整组为带标签 S，对面为伪目标。每方向重新拟合源模型，旧 GIN、SourceCal、R8 的标签分数都不可复用。
- 为避免同一种指纹行跨 A/H，以三个深度的原始计数直方图（保留计数）的完整组合分组。用固定 SHA-256 排序群组后，在相邻群组边界选择图数最接近一半的前缀作 H，另一半作中间图候选池 U，平局取较短前缀。H 在五次扰动中固定。对 U 的群组分别以 3405–3409 作哈希种子排序，取图数最接近 U 的 80% 的前缀作无标签 A。排序采用无标签、跨进程确定的规范字节，记录算法和每组图 ID。若任一伪方向无法形成非空的 S、A、H，记录不可评价。所有臂逐张推断 H，不连 H–H 边。
- 标签仅用于拟合本方向 S 的源模型和端点投票。两方向各自封存 S/A/H、参数、权重检查、H 分数和分类动作，两个方向都完成后，再对 H 计分。反向实验所用 S 标签在另一方向是伪目标标签，两方向的预测过程须独立，不能交换拟合参数和监督诊断。可从 R5 的同一源标签文件按已登记角色索引。允许完整性检查读取原始字节，记录每次算法实际取得的标签 ID。不得按伪目标标签平衡切分或调整参数。

## 固定算法和竞争解释

每张分子图使用带节点与边类型的 WL 半径 0、1、2。半径 0 取离散节点类型；后续用上一层中心类型与排序的（边类型，邻居类型）多重集生成规范标识。每层节点标识计数做 L2 归一，再把三层拼接并除以 √3。核 K 为其内积。源外新标识在不同图中共享相同规则，避免公共 unknown 桶制造假相似。训练源模型的参数仅覆盖 S 的特征列，核对目标图新特征仍使用完整图的归一化分母。推断时可逐图计算，不用测试集做特征选择。

基础模型 B 是在 S 上拟合的二元 logistic，C=1，截距不惩罚，斜率 L2，无类重加权，保存收敛检查。所有传播臂共用概率 (B(h)+Σ w_s y_s)/2，权重各行和为 1；普通决策为 p>0.5。核正值按相似度降序截取前 8 个，平局取原图 ID 小者，权重正比于所选核值。候选少于 8 个则全部保留。若某行无正相似候选，用候选集上的均匀分布并报告次数。核、路径长度、混合比例和 k 在本阶段固定。

| 臂 | h 如何取得源标签 |
|---|---|
| B，源监督结构模型 | 直接使用 B(h) |
| Direct，直接邻居 | h→S 的单跳源权重 |
| TargetBridge，主臂 | h→A 与 A→S 两个行归一矩阵相乘 |
| MatchedWeights，同权重对照 | 保留主臂在此 h 上的全部源权重值，按降序逐一赋给 h→S 直接核相似度从高到低的源图（平局按 ID）。本臂也使用 A。两臂每图权重和、非零数、熵、有效邻居数一致，只有获得各权重的源图身份可变 |
| SourceBridge，源中转 | 用相同个数的源图替换 A，按种子和源图 ID 做确定性哈希抽样，核及路径长度相同。源中转图到 S 时排除自身及其完整指纹计数组。若源图数小于 A，两个中转池均缩到源图数，目标池按既定无标签顺序选取。若排除后没有源候选，标记块不可评价 |

对主臂与每个对照记录 H 逐图分数、动作，及两跳权重是否集中在相同源图。验证含三层结构的手算例、节点重编号不变、同权重对照逐图权重多重集相同、重复源图排除、无操作和同种子可重放。在合成反例中令中间图同时与不同类别的局部片段相似，确认方法容许有害路径。

## 投入标准

### 预评分复核补充（原登记 dc722f0）

独立审查在本轮尚无评分产物时发现，逐层原始计数可不同而 L2 归一化指纹完全相同。角色分组和 SourceBridge 排除同组端点统一使用每层整数计数除以本层所有正计数的最大公约数所得的规范字典，三层都相同才属同组。这精确对应模型的完整输入相同。边数切分依旧由原始图决定。另记录 H 与 S 是否有归一化指纹完全相同的图，分开描述这部分覆盖。工程例应包括一份图及其两个不连通副本。

增加一个只作归因的 PooledBridge。对于每张 h，用 A→S 的各行简单平均作为源权重，仍与 B(h) 做等比例混合。它恰好等于在同一 A 内将两段路径的中间身份均匀随机重配后的**期望权重**，保留该 A 整体偏爱的源端点。它的 Accuracy 并非多次打乱所得 Accuracy 的期望，因为阈值为非线性。主臂若对它没有可重复的净纠错，研究解释只限于 A 整体影响了投票，逐张选择中间图的价值仍待验证。四个原门槛、阈值与前置分歧判定按最初登记。标签隔离和双向统一封存分别验证；互为反向的实验中，未打开本方向 H 评分不等同整项试验从未取得这些 M0 标签。

以普通 Accuracy 为主。所有臂共用 H，报告每方向、每次 A 扰动的纠正和损害数、差值、两方向等权均值；按域和类别重采样图 2,000 次（随机种子 20261121），每次共享各臂及 A 扰动的图抽样，另报 BA、每类召回、NLL。五次扰动共享源模型和 H，不计作五次独立训练。因单向 H 分母固定，严格正负用有理数判断。解释图结构的诊断与门槛分别报告。

投入门槛是预先选择的 1 个百分点，作为下一次计算预算的标准。每图两臂动作一致的部分不可能贡献准确率差；若 TargetBridge 对下列任一关键对照（B、Direct、MatchedWeights、SourceBridge）的两方向等权平均动作分歧率 <1%，则已有上界，封存后可终止而不打开 H 评分。否则一次性计分。仅当主臂相对四个对照的方向等权 Accuracy 差都 ≥1 pp、任一方向相对任一对照均无平均净损失、且相对 MatchedWeights 在两个方向均有严格正的平均净纠错时，才登记一个真实开发比较。任何缺块、触发无候选的不可评价条件或任一项未达标均不晋级。若失败，明确是哪一个对照解释了差异；这一阶段结束后不在该伪目标上调 k、深度、混合系数或划分。若通过，真实方向、原生图基线与独立确认另行冻结。
