Spearman 用并列中秩，先逐方向计算再等权。概率变化为二分类 sigmoid 正类概率差的绝对值，先在同一 Q 平均。每个设置均有六个缩小方向、六个放大方向，零个等尺度方向。缩小方向是 M1→M0、M2→M0/M1、M3→M0/M1/M2，反向均放大。各设置本域比例范围依次为 0.341–2.933、0.349–2.867、0.149–6.895。PROTEINS M3→M0 的 Q 上，最大绝对 margin 从 143.31 降到 21.33，逐图规则为 10.39。

- **正比例输出** `t·z(1)` 保留全部原 B0 动作。直接放大读出输入 `P` 仍改变原 B0 的 391 次动作。
- **公共截距对照** 与 Own 相差 13 次，仅用每方向相同的截距和正比例即可复现绝大部分动作。
- **冻结 ReLU 原激活外推** 与 Own 在 10,311 次中动作完全一致。本域缩放仍在 670 次图前向中造成 710 个严格激活边界穿越，当前这些穿越没有改变外推的类别结论。

**在这些 Q 图上，读出幅值显著改变了输出概率，分类决策主要表现为沿原排序移动工作点。** 当前诊断在此收束。这里的上界和排序证据条件于本批 Q，类别正确性需要另有监督证据。
