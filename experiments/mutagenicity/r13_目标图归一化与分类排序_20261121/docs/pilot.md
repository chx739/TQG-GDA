# 无标签目标统计能否让冻结分类器在同域新图上多分对几张

2026-11-21，在 R12 源内分布筛查后、执行新编码或查看本轮预测前登记。R11 的固定阈值研究显示工作点和类条件错误率都会变，R12 实测图读数之间的依赖会破坏阈值识别。从这里直接跳到“目标分布能指定正确标签”缺少依据。这里改问，域间的某部分变化能否通过已有编码器中可直接测量的节点激活均值、方差校正。该问题用已有 checkpoint 做前向即可回答。AdaBN 已经提出替换域统计量；本轮测量图级任务中每图等权相对每节点等权的增量。GraphNorm 学习单图内部的归一化，本轮在一批适配图上估一套共同统计并应用到新图。[R11 先验结果](../../r11_分类阈值的跨域检验_20261121/docs/prior-control-results.md) · [R12](../../r12_三种图读数与阈值识别_20261121/README.md) · [AdaBN 原文](https://arxiv.org/abs/1603.04779) · [GraphNorm 原文](https://proceedings.mlr.press/v139/cai21e.html)

**假设。** 常规 BN 把大图中的节点计得更多。若类别以整张图为单位，且域改变的主要是与类别无关的激活位置和尺度，让每张适配图贡献相同总权重，有可能改善不同目标图之间的分数排序。反例包括同域图大小几乎一致、激活与图规模无关、大小本身携带标签信息，以及类别比例变化恰好改变激活分布。即便实验成功，也仅能说明这种统计替换在相应设置有用。

## 冻结的比较

沿用 [R11 数据角色](../../r11_分类阈值的跨域检验_20261121/docs/threshold-transfer.md) 指向的 R7 C attempt-016。Mutagenicity 边数、节点数以及 PROTEINS 边数各 12 个方向，第一阶段固定种子 3405，共 36 块。每组固定一个源模型 S 和三个目标 A，三个 H 分开推断。在原 R5 的 B0 checkpoint 上只改 BN 的 running_mean 和 running_var，保持模型权重、BN 仿射参数、epsilon、输入、sum pooling、head、eval 状态不变。严格沿用源 checkpoint 的输入、推断精度与选模规则；先用原 buffers 对齐历史 B0 的逐图类别、logits 数值精度和 ID，报告实际最大差。无需梯度、伪标签或目标阈值拟合。

为使本域、异域及同算法的源统计有相同图数，在每个源模型内取 K=min(|S|, |A1|, |A2|, |A3|)。从各图池按 UTF-8 串 `r13-v1|<setting>|<十进制图ID>` 的 SHA-256 升序取前 K，遇哈希平局按图 ID。S 为实际源 fit 集，V 不进入统计，估计器对 S 和 A 均只读图。四套统计都各自从同一个原 B0 独立开始，逐 H 同时列下述结果。

| 对照 | 统计来自哪里 | 要回答的问题 |
|---|---|---|
| B0、已封存 SourceCal | 原源 checkpoint 及源验证校准 | 能否超过原模型和简单的源端决策校准 |
| S-node、S-graph | 相同 K 张源图 | 精确重算统计本身或改变统计权重的作用 |
| A-node、A-graph | 相同 K 张本域无标签图 | 已有 AdaBN 方法，以及每图等权的额外作用 |
| Other-node、Other-graph | 同源模型的另外两个目标 A | 对每个 H 分别列两套异域输出，等权平均两份 Accuracy，检验目标身份 |

同一批图内，node 使所有节点等权，graph 给每张图相同总权重，再给该图的每个节点均分权重。两者均使用加权总体均值和总体方差，方差包含图间均值差异。按实际前向顺序依次替换每个 BN 的输入统计，GIN/GINE 各层依次是内部 MLP 的 BN 和该层外部 BN。每确定一层的统计后固定该层，再测下一个 BN 的输入。float64 累积矩并以模型的 buffer dtype 使用，保持 epsilon。按图分批的求和应给相同预测；记录每处 BN 的矩和所用图数与节点数。等节点数的合成图上，两种权重应给相同结果。H 图只在冻结后的 eval 前向中出现，不进入统计。各目标 A 本域和异域互换，共用图 H 和模型的设计也能检验是否某个 A 普遍更好。

## 评分与解释

先封存全部 H logits、类别、图 ID 和统计来源，再读既有 H 标签评分。主指标为普通图级 Accuracy。固定模型和图 ID，按方向报各臂准确率、纠正图数、损害图数、净变化百分点，设置内对方向等权。使用历史同图证据能覆盖的块额外列出已封存的较强源模型/图域适配模型及配对差，注明覆盖数。次要报告 BA、两类召回、AUROC、NLL、预测正类比例。若有区间，沿用 R11 目标域×类共享图重采样，说明条件于该种子及固定域。

对每个 H 单独做事后等阳性数比较。对 A-graph 预测为正的 k 张数，取冻结 B0 margin 前 k 张为正，margin 相同以十进制图 ID 数值升序取前。它可以直接解释仅改变整体阳性数量的收益；从 H 的分数取得 k 和排名使它只适合这次诊断。统计附加的净纠错、AUROC 变化和是否有分类决策改变。即使排序变好，仍可由图规模改变造成，暂不宣称学到了分子机制。

预先区分三种结果。若 A-node 胜过原 B0 及 S-node，而图等权没有额外收益，记作经典基线结果。若 A-graph 和 S-graph 相对各自 node 的提升相当，则缺少归因于本域图等权的证据。若普通 Accuracy 改善完全可由 B0 等阳性数解释，这一轮只支持工作点变化。

对图等权路线，先看每个设置的 A-graph 相对 B0、SourceCal、S-graph、Other-graph 均为正，相对 A-node 和 B0 等阳性数控制也均为正，且逐方向至少 7/12 同时超过 B0 和 A-node。要求至少 2/3 设置满足，才在原三个设置全部补齐预留的 3406–3409 种子。报告 (A-graph−A-node)−(S-graph−S-node)，两项均为普通 Accuracy 配对差，有助于辨别图等权的作用是否依赖于目标。若图等权未满足但普通 A-node 在至少两个设置高于 B0、SourceCal、S-node 和 Other-node 且各至少 7/12 方向胜 B0，则只给这一公开基线补种子。其他情况结束本轮，保留负结果。该门槛仅决定计算投入。开发图及既往模型被复用，一种子不能判断跨种子稳定性；正式优势还需独立任务及同权限强图分类方法。NCI1 保持封存。
