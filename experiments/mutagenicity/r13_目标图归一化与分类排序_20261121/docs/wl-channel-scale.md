# WL 各邻域半径的贡献随域改变尺度，会影响分类吗？

2026-11-21。复用 R9 的静态 WL 岭分类器及源内双向大小迁移，检验一个具体假设。若目标域改变局部结构出现的幅度，同时保留各半径对类别的作用方向，那么用无标签图估计三种幅度变化，可能纠正同一批图中的相对排序。R13 之前考察总读出尺度，R9 用目标词频重新拟合源岭系数，本次直接固定全部源系数。按域对齐二阶统计已有 CORAL 等工作；这里检验的具体选择是按 WL 半径分组、保留目标平均分。若观测到的方差变化源自不同类别的混合比例，缩放可能恰好削弱真正的类别证据。[CORAL 原文](https://arxiv.org/abs/1511.05547) · [域对齐的反例](https://proceedings.mlr.press/v97/zhao19a.html) · [R9 静态分类器](../../r9_目标近邻与源标签传递_20261121/docs/feature-dropout-transfer-check-results.md)

**数据与权限。** 用种子 3405、Mutagenicity 边数和节点数、PROTEINS 边数，每项四个来源、每来源两个大小方向。D 已用于有标签拟合，C 已用于选岭惩罚。U 为无标签参照，E 为评价。复用 R9 冻结词表、权重、截距和各方向实际的等预算 U/C 参照。另从 D 按字符串 `channel-v1|方向键|图ID` 的 SHA-256 字节序取前 m 张，碰撞按图号排序，m 等于该方向 U 参照张数。D 里的尺度是训练内估计；用 C 替换 U 的对照也使用同一 D。E 已用于其他方法的设计，两个分子划分图实体有重叠，单种子属于来源内开发。

**唯一改变。** 对图 g 按半径 j=0,1,2 汇总原权重乘以对应 WL 特征，得到 h_j(g)，原分数 f(g)=b+Σh_j(g)。用上述 D、U 参照分别求总体标准差 s_Dj、s_Uj，取 ρ_j=s_Dj/s_Uj；任一标准差小于或等于 1e−12 时取 1。主臂分数为 f(g)+Σ(ρ_j−1)(h_j(g)−mean_U h_j)。原截距和 U 参照上的平均分均保留，硬判使用分数严格大于零。若两张目标图各半径贡献分别为 (2,−3) 和 (−2,3)，其源读数为 (2,−1) 和 (−2,1)，缩放第二项可让两图交换排序。将两张目标图的真实类别互换，任何无标签统计仍完全相同，纠错方向却反转。下面的分类检验衡量真实数据支持哪一种解释。

| 对照 | 能回答的问题 |
|---|---|
| 原静态岭 f；以等预算 C 替换 U，其余计算原样 | 变化有无净纠错，收益是否依赖目标参照 |
| 单一尺度，对总分使用相同标准差比和数值保护，在 U 的原平均分处缩放 | 单一幅度和阈值可以解释多少 |
| 在本方向 E 上沿 f 原排序取主臂相同阳性数，同分按图 ID 升序 | 排除改变阳性数后，还纠正了哪些图。此项为排序诊断 |
| R17 已封存的源选 WL、Size、联合 Base、固定 C=1 WL；另在 PROTEINS 对照 R9 D 拟合的节点数曲线和同一 U 参照的曲线多数 | 这套方法相对已有简单分类器的绝对竞争力 |

**计分与取舍。** 先独立重建、对齐各对照的 E 身份并封存全部预测，再开放该方向 E 标签。按八方向等权报告普通 Accuracy 与同一硬判的 Macro-F1，逐方向报告纠正／误改、胜平负、逐源及去一源后的 Accuracy 差。单设置进入另一批图的固定规则复核，须同时满足以下条件：相对原岭及表末全部可部署基线中设置均值最高者达到 +0.5 个百分点，严格胜过 C 替换、单一尺度和同阳性数，四源至少三源相对原岭有净收益，去掉任一源后等权差仍为正。若仅一设置成立，仅在该设置复核；跨分子和蛋白质的结论要求 PROTEINS 及至少一种分子划分分别通过并复现。若都未通过，结束这条冻结三尺度修正，不按 E 的标签选半径、系数或裁剪范围。
