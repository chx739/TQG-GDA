# R8 运行前复核交接

预检覆盖登记的两方向、五种子及原始 R5 图缓存。已核对 4,337 个图记录、266,894 行有向边、133,447 条无向边，原始节点类型为 0–13、边类型为 0–2。原始边无自环和同向重复，反向边类型全部一致。预检只读四个拓扑文件、认证元数据和固定 ID，从未反序列化源或目标标签。

生成测试覆盖无向计数、未知类别与无边图、带宽下的逐值零更新、两分数解析解、同信息先验区间、KKT、边界与不可行区分，以及先验相同但条件关系反转时的 NLL 恶化。两个解析测试的容差及数值配置见代码。

复核重点是四行不等式的类 0 符号与常数项、零带宽 LP 与有限 logit 的区别、源 fit 词表与标准化、两臂共用同一四行多面体，以及 A/H 标签访问顺序。词表外节点和边各归入一个桶，源 fit 的常量列标准差置一。范围、带宽、比较标准沿用登记协议。

### 解封前的数值反例与修复

在两张图上取 v 为 0 和 1，两个源类均值分别为 0.5−0.2×10⁻⁸ 和 0.5+0.8×10⁻⁸。零带宽条件蕴含平均正类概率约为 0.2。旧实现会把 0.8 判为可行，还可能在重复相同图后误报空集。修复后，在线性规划和对偶中使用等价的先验等式与中心化交叉矩，并以原始条件矩和线性规划先验区间复核部署概率。对类均值严格相等的情况单独处理。另一组样例取源 logit 为 −25、25，精确约束只允许 q 为 0 和 1。求解器现先判定有限 logit 内点，再判断能否返回原模型。主臂的统计带宽和各项精度门槛沿用登记值。

回归覆盖两分数的解析后验、同一样本重复、相等类均值以及极端源概率。有限数值求解未达到证书时单独标记 numerical_failure。历史封存链核验会读取含标签文件的原始字节计算哈希，预检不解码标签值。目标标签值在 OBS 后用于诊断和评分。[审查回归](../../../../tests/tsba/test_r8_projection_review.py)
