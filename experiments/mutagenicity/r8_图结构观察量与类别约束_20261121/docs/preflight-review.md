# R8 运行前复核交接

预检覆盖登记的两方向、五种子及原始 R5 图缓存。已核对 4,337 个图记录、266,894 行有向边、133,447 条无向边，原始节点类型为 0–13、边类型为 0–2。原始边无自环和同向重复，反向边类型全部一致。预检只读四个拓扑文件、认证元数据和固定 ID，从未反序列化源或目标标签。

生成测试覆盖无向计数、未知类别与无边图、带宽下的逐值零更新、两分数解析解、同信息先验区间、KKT、边界与不可行区分，以及先验相同但条件关系反转时的 NLL 恶化。两个解析测试的容差及数值配置见代码。

复核重点是四行不等式的类 0 符号与常数项、零带宽 LP 与有限 logit 的区别、源 fit 词表与标准化、两臂共用同一四行多面体，以及 A/H 标签访问顺序。词表外节点和边各归入一个桶，源 fit 的常量列标准差置一。范围、带宽、比较标准沿用登记协议。
