# 仅源监督的图组成基线在同样大小的图中能否选对需要翻转的样本

2026-11-21，在 R13 实现期间、计算本项分解之前登记。R8 的源监督融合 SourceFusion 在两个方向都胜过源校准 SourceCal，等权平均多 0.654 个百分点。融合所用的节点和带类型端点频率与图大小可能相关。R1 的规模探针回答两种计数能否单独预测类别，未回答两种已部署分类规则之间的增量能否由规模解释。[R8 报告](../report.md) · [R1 探针](../../r1_图表示与边界支持_20261111/report.md)

使用 R8 attempt-001 已经计分的 Mutagenicity 边数 M0→M1、M0→M3，各五种子。比较固定 SourceFusion 与 SourceCal，不重新运行模型或拟合标签。每张 H 图记录源校准判决 b、源融合判决 f 及图规模，图规模固定为节点数与去自环唯一无向边数。H 的已发布预测和原角色解封的标签只用于历史归因。分组键为（节点数，边数，b），分别在每个方向与种子内操作。保留每组样本数 n、原判错误张数 e、融合翻转张数 k，随机打乱哪些图收到这 k 次翻转。源校准的正确数为 n−e，随机翻转后期望正确数是 n−e + k(2e/n−1)。实际融合正确数减去这个期望，表示固定图规模、源校准判决和翻转预算后，正确分配翻转带来的净贡献。用精确计数求期望，报告每块的图数、翻转数、期望增量、额外净贡献和实际增量，单位为百分点。

同时报告满足 0<e<n 且 0<k<n 的组覆盖多少图、多少次翻转；其余组对额外净贡献恒为零。用原数据验证两部分之和等于归档 Accuracy 差。报告全部十块和两方向均值。正数仅说明融合在这批相同大小、相同原判的图之间能更好地分配翻转，信息可能来自节点类型、组成或源分类器置信度。很多精确大小只出现一张图或同组类别都相同时，剩余覆盖小，不能凭零差异断言结构无用。这是既往开发数据的事后归因，不改变 R13 门槛。
