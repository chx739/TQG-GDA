# 环闭合背景能否从另一批未标记图复测？

复用 R9 的八个 Mutagenicity 边数来源内方向，只读原始无向邻接、图 ID、节点类型和图角色。枚举长度为 4、5 条边的无重复节点路径；一条路径及其反向只计一次。首尾之间有边即记为闭合，允许图中有弦。按长度和两端节点类型是否相同得到四组，每图每组的机会数为 O、闭合数为 C。每组背景率用所选参照里 C/n 的和除以 O/n 的和，n 为单图节点数。

U 按整图分两半交叉评价；每折用其中一半的子集与等图数的源 C 作参照，实际每臂 95–122 张图。在另一半图上，对每条有机会的路径计闭合事件 Brier，先每图平均，再对方向内可评图平均，最后八方向等权。路径之间有重叠。无路径的 31 张图属于 M3 大→小；可评图数为 3,437/3,468。

| 如何估计闭合率 | Brier，越低越好 |
|---|---:|
| 本域图，分长度与端点类型是否相同 | 0.04337189 |
| 等预算源图，同样四组 | 0.04383599 |
| 本域图，只分长度 | 0.04749769 |
| 等预算源图，只分长度 | 0.04763433 |

换用本域参照，Brier 平均降低 0.00046410，7/8 个方向改善，约 92.5% 的净改善来自 M0 与 M3。对同样的本域参照，区分端点类型使 Brier 降低 0.00412579。数字支持测一次分类增量。类别构成、大小或度分布的变化均可能导致闭合率变化。截至此预检未计算该方法的分类分数。

## 一个能区分两种解释的六点例子

令所有节点同型、所有边同型。三棱柱和完全二部图 K₃,₃ 各有 6 个节点、9 条边，所有节点度均为 3；标准 1-WL 的各轮颜色直方图相同。按本轮定义枚举路径，长 4 时三棱柱有 42 个机会、30 个闭合，K₃,₃ 有 36 个机会、0 个闭合；长 5 时分别为 30／18 和 36／36。因此这些计数提供了单凭上述 WL 与大小无法恢复的图信息。

进一步令两种图各自对应一个固定类别。两类各占一半时，长 4、长 5 的背景率分别为 5/13 和 9/11；若目标池中三棱柱占四分之三，两项就变成 5/9 和 5/7。每一类的图完全相同，仅更换类别比例便能产生显著的背景率变化。分类实验因此要同时比较能直接使用环信息的强源模型，以及仅改变类别比例就能解释的那部分变化。[分类对照](source-screen.md)
