# 把同一目标修正直接用于原 WL，是否能保留额外纠错？

原筛查的三个准确率分别为 WL 77.077%、加源背景修正 74.148%、再换本域背景 74.426%。相同拟合下，替换背景净多纠正 2 张；完整修正比原 WL 净少纠正 22 张。原完整方案已结束。这里检验一个单独的问题：若已有 WL 已经学到了源域的环关联，只在部署时改变与目标参照有关的部分，能否直接纠正强模型？[原协议](source-screen.md)

**比较图与已知信息。** 仍是 Mutagenicity 边数、四个源内大小双向和 3405。取 R9 固定模型补充评价池（原 U 去掉 R9 词频参照），再剔除 R19 原本域 U 参照。八方向剩 1,961 张，各方向与自身 D、C、E 及两个 U 参照均互斥。按原图 ID 升序，覆盖全部合资格图。R9 曾在这些图上评价不同方法，反方向也使用过它们的源标签。此次对照属于来源内开发验证。在查看此次配对分类成绩前，用冻结的无标签动作测得主臂与原 WL、等阳性数对照及平均截距的分歧为 57、22、23 张；八方向等权的差值绝对上界为 2.755、1.093、1.139 pp。等阳性数分歧覆盖 6/8 方向和全部四源。它们是能改变的判决数，纠正与误改需另行评分。

**唯一待检验的部署改动。** 不重训、不选参数。在任一图 g 上，让 δ(g) 等于原目标背景连续分数减原源背景连续分数，即同一组 w、源 C 缩放和机会数 o 下仅替换 pS 为 pU 的效果。主臂按 f_WL(g)+δ(g)>0 判正，系数固定为 1。静态 f 直接复用 R9 封存的原始连续分数，原 R19 模型和参照 ID 沿用正式 OBS。不依据已有原 E 的标签选择符号、强度或图子集。

| 对照 | 固定的操作 |
|---|---|
| 原 WL | 沿用原阈值。 |
| 统一截距 | 使用 f_WL 加原 R19 本域 U 参照上 δ 的图等权均值；可逐图部署。 |
| 等阳性数 | 在本方向补充评价图上，沿 WL 分数降序给出与主臂一样多的阳性；同分按 ID 升序。用于诊断排序。 |
| 混合变化与反号 | 分别给 f_WL 加原混合背景相对源背景的连续变化，或减 δ。四组背景、同一 w 和拟合的混合比例均已封存。 |
| 原源背景、原完整目标背景、仅源原始环特征 | 在同一批补充图重放原轮的固定读出，以检查原筛查中源修正损失能否重现。 |

冻结角色、配对预测和原模型摘要后再按该方向补充池授权计分。独立核对先前已盲算的四种动作，逐行核对 1,961 个 ID，初次盲算清单 SHA-256 为 `60cef366ef642756c7c16bcec39aeaa15fc5b249459e874476848a70237ba91b`。报告绝对 Accuracy 与 Macro-F1、纠正／误改、八方向胜平负、逐源与去一源结果。只有主臂相对原 WL 和统一截距中设置平均较高者至少 +0.5 pp、严格胜过等阳性数及混合变化/反号，并且至少三源相对 WL 为正、去掉任一来源相对 WL 仍为正，才投入下一项真实域试验。原完整方法和源表示的绝对分数一起呈现。若没有越过这些对照，结束这组冻结环修正的分类试验，不在这些图上扫描步长。
