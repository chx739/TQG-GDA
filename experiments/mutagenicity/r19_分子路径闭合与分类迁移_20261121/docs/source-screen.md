# 只更换环闭合的背景率后，哪些分子会改判？

环表示可以补充普通 WL 表示遗漏的结构。分子图上若给定路径类型后的额外闭合有类别意义，且图大小分段改变该类型路径通常闭合的机会，使用未标记目标图估计背景率可能改善分类。有两项直接竞争解释：仅靠环数就能改善源模型，或闭合率变化来自域内类别比例。实验在目标分类评分前固定。[环表示的原始研究](https://proceedings.neurips.cc/paper_files/paper/2021/hash/157792e4abb490f99dbd738483e0d2d4-Abstract.html) · [大小迁移中的局部结构](https://proceedings.mlr.press/v139/yehudai21a.html) · [无标签结构预检](structure-results.md)

**数据和基线。** 复用 R9 种子 3405 的 Mutagenicity 边数四源、双向的 D/C/U/E，E 含 869 张既有开发图。D 训练、C 源验证、U 无标签参照、E 计分；正反向模型分开。强源起点 f 为 R9 结构词 dropout 的静态 WL 岭回归的连续分数，沿用原 D 词表、C 选定的正则及自由截距。核对原 E 冻结分数与判决。源和目标参照各取 m=min(|C|,|D|,|U|) 张，从 D、U 分别按字符串 `ring-r19|{原方向key}|{D或U}|{十进制图ID}` 的 UTF-8 SHA-256 升序取前 m 张。源 C 与原 f 选模共用；只将其用来拟合修正，不用 C 的拟合成绩判断价值。全程不调用真实目标域 A/H。

**闭合特征。** 沿用预检的四组计数，按长度 4、5，再按端点类型不同、相同排序。图特征 c=C/n、o=O/n。源、目标参照分别估计 pS、pU，逐组取同一参照中 c 的和除以 o 的和。若某组源参照无机会，用全部 D 的率，全 D 仍无机会取零；U 无机会的组沿用 pS。记录覆盖。部署对每个查询图独立计算其 c、o。

**拟合。** 固定原 WL 分数。用 C 的标签和原分数形成响应 r=(2y−1)−f。以四列 v=c−pS⊙o 拟合无截距的岭修正 w；每列除以在 C 上的均方根再除以 2，零均方根的列固定为零。最小化平方残差和加 w 的平方和，不选新的超参。查询时保留同一套缩放及 w。主方法把 v 中的 pS 换成本域 pU，最终分数为 f 加该修正，严格大于零判正。两种背景都无路径的查询保持原 f 的判决并进入分母。

| 对照 | 它回答的问题 |
|---|---|
| 原 WL；另给原 WL 加上 C 的平均残差 | 只靠冻结源模型或一次源端截距校准能达到多少？ |
| 源背景 | 完全相同的 w 和特征，仅使用 pS 时，和本域 pU 相差多少？ |
| 源监督的原始闭合与机会数 | 同一 C 响应、无截距岭回归，把输入换成 c、o 的八列，各自按 C 的均方根与 √8 缩放。只增加表达能力能否解释收益？ |
| 只允许类别比例改变的背景 | 在 D 的每类分别算 c 和 o 的均值。对比例 π 用两类均值分别混合，分子除以分母得四个混合率 h(π)。从 pS 加上 h(π)−h(源 D 阳性率)，裁到 [0,1]。在 π=0,0.001,…,1 中选择对 pU 的机会加权平方误差最小者，权重为所选 U 的 o 各组之和，平局取较小 π。对无机会的 D 混合组用全 D 率，D 缺类时沿用 pS。将该背景代入相同 w。只用 D 标签和 U 结构，不输入 U 类别。该约束仅检验固定源类条件结构的混合解释。 |
| 相同阳性数 | 在整批 E 沿“源背景”连续分数取出与主方法同样多张阳性，平分按图 ID 升序。衡量改动在调整判正数量之外能否纠正排序。 |

冻结全部 D/C 拟合、参照 ID、p、各系数、E 的连续分数及动作；先核对交换 p 恒等和无路径的手算例，再按原 E 角色评分。报告各方向的 Accuracy、Macro-F1、与每个对照的同图纠正和误改及去一源结果，方向等权。若主方法对原 WL、截距校准、源背景及原始闭合与机会数中设置平均最高者至少 +0.5 个百分点，且严格胜类别混合和同阳性数对照，四个源组至少三个相对源背景为正，才值得扩大。若仅原始环特征有益，就把结果归给源表示。若本域背景不能产生额外分类收益，结束这次固定修正。Brier 的变化不进入分类晋级。这个单数据集筛查通过后仍需在独立图和真实迁移任务上确认。[原 R9 角色与初测](../../r9_目标近邻与源标签传递_20261121/docs/feature-dropout-screen.md)
