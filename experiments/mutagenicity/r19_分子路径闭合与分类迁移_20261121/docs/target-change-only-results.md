# R19 补充｜只把背景变化加到原 WL，能否纠正分类？

**不能达到晋级门槛。** 将单位目标变化直接加到原静态 WL，Accuracy 从 **77.57%** 降到 **77.04%**，差 **−0.533 个百分点**，纠正 23 张、误改 34 张。从原完整修正里去掉源背景修正，能追回 0.986 个百分点。保留下来的目标变化仍使原 WL 退化。[协议](target-change-only.md) · [原主试验](../report.md)

## 封存与限制

- 冻结阶段没有读取标签。先独立核对 1,961 个图 ID 与主臂、原 WL、等阳性数、统一截距的 7,844 个动作，全部一致。三个对照与主臂的分歧分别为 57、22、23 张。静态分数完全相同，目标变化的独立计算最大差约 3.12×10⁻¹³。
