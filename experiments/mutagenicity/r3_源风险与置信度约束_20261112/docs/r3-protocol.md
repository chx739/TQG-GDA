# Mutagenicity R3 源风险与置信度干预

[R3机器计划](../configs/r3-plan.json) 固定两项迁移 0→1、0→3，种子3405–3409，四组主实验360条和M11敏感性160条。每条30次尝试，第30次是主终点。NLL是主要概率指标，BA和准确率与类别指标同步报告。统计以五个种子为单位。

源角色直接调用仓库 SEGA 的 `split_source_roles`，传入同一种子和0.4、0.4比例。合并ref与fit后按原始图ID排序，得到868张训练图，cal得到216张验证图。源验证仅用于100 epoch源训练的CE选模及事后计分。完整域1和3只向训练过程提供图输入及冻结坐标。R3_OBS封存包括输入、配置、全轨迹、待评价预测和重载检查。评价入口核验封存后才解析两个完整目标域的类别值，涵盖旧实验的保留样本。结果是全目标域开发证据。R2档案仍使用其原有角色。

冻结坐标基于868张源训练图，适配使用float64。每个score从头训练，固定同一目标池上的独立验证噪声，保存精确900、1800、3600、7200步。恢复点每50 epoch，端点诊断使用初始分类头对首轮128张目标批次投影得到的同一批锚点。适配使用精确7200步。几何尺度来自当前 `bandwidth` 规则，密度带宽加倍不影响投影或移动尺度。

M00使用生产求解与回溯。M10/M11去掉源CE的线性推动项，保留源GGN，并在完整训练集上线性化logits后约束两类CE。M01/M11在全部源训练图及对应完整目标池上限制线性化margin。约束以共同起点为参照，风险增量固定0.05。SLSQP使用解析梯度和Cholesky预条件，置信度约束逐步加入违反上限的行，候选发布前核验全部行，求解或残差失败按拒绝记录。真实前向使用15次生产步长序列，逐项核验Armijo、源风险、置信度和执行上限。新增两类预算的浮点核验容差为1e-9。M00的零请求强制求解源CE，保护组的零请求为驻点。

第1、30次尝试从各条轨迹的更新前状态求正常、零、反向候选。共用步长从1/16开始减半，使用本组真实目标和预算验收。零密度轨迹的旁路使用主带宽7200步学习score。共同候选不可用时保留状态。几何重定位沿旧法向扫描±4σ0的65点，对检测到的符号变化和转折做二分。保留无根、多根和近切触。扫描交点是有限线段上的结果，位移取旧法向坐标。KDE审计保存生成图权重、ESS、最大权重以及去掉生成图后的请求。保护组敏感性零控制逐格验证初始驻点，配对表复用M11主网格零请求结果。

源预训练用独立工作目录发布完整checkpoint，若中断保留原工作目录并重新执行该源模型。score恢复最近完整恢复点。每轮适配原子发布一个状态文件，恢复读取最后已发布状态。每个阶段的日志、错误和角色哈希存入新实验目录。
