# 跨大小域复制一个源图的判决，最多能帮到多少目标图？

在三个现有四域设置中，跨域保节点类型的全图同构对均为零。对每个目标取完整源域作候选，这个覆盖已经是只允许源训练图时的上界。全程只使用原图归属、无向邻接、节点类型及域索引，核对十八项输入哈希。忽略键型、去除自环、合并重边，保留孤立点；要求相同键型会进一步收窄匹配。[逐域输入](../results/cross-domain-structure/inputs.json) · [逐域图数](../results/cross-domain-structure/domains.csv)

| 各设置十二个有向迁移 | 分子边数 | 分子节点数 | 蛋白边数 |
|---|---:|---:|---:|
| 所有目标图次 | 13,011 | 13,011 | 3,339 |
| 划域所用大小在源域也出现的目标图次 | 348 | 361 | 32 |
| 跨域全图同构对，忽略节点类型 | 47 | 30 | 0 |

| 只改一种局部结构可匹配的目标图次 | 27 | 28 | 0 |
| 取非空 2-core 后可保类型同构的目标图次 | 5,693 | 5,866 | 0 |

限定的三种改变是添删一片叶及其唯一连边、添删一条边、或改一个节点的类型。先按必要条件分桶，再逐一判定同构。即使有这三种例证的所有图都由原错变对，以目标图次汇总的 Accuracy 增益也至多为 0.208、0.215、0 个百分点。这个界针对只有匹配图可以改判的规则。深度有限的 WL 签名容许非同构图重合；例如分子两种域划分各有一对命中三轮保类型签名，精确同构均不成立。[精确同构](../results/cross-domain-structure/exact.csv) · [逐域近重复覆盖](../results/cross-domain-structure/edit.csv) · [各深度的观测等价](../results/cross-domain-structure/wl-equivalence.csv)

去除全部度小于二的节点并迭代至稳定后，分子有 43.76% 和 45.08% 的目标图次找到同核源图，蛋白仍为 0。分子边数 M0 与 M3 之间只共享十八类非空核心，其中一类在 M3 已有 359 张图。很多分子共享一个骨架，这个结果只确定可匹配规模，分类还依赖骨架外的结构。R17 早先从自然存在的诱导包含关系直接核过部分整图标签，已见结构匹配而标签相反的实例。若改用共同核心，应在有标签源图独立检验同核异外围的类别残差是否好于现有单图模型。[各尺度覆盖](../results/cross-domain-structure/partial-graphs.csv) · [当时执行的核验脚本](../results/cross-domain-structure/original-checks.zip) · [既有自然包含监督结果](natural-containment-results.md)

## 目标池只用来识别环境，有多少额外信息？

把同大小的图全部标为其中最常见的域，已知全域划分的事后查表在三设置分别正确区分 4,233/4,337、4,225/4,337、1,105/1,113 个**域号**，准确率为 97.60%、97.42%、99.28%。四域的熵接近 2 bit，已知单图大小后的剩余域熵分别为 0.065、0.070、0.022 bit。R9 的 24 个源内大小伪任务按已登记切点划分，D 与 U 的切分大小交集均为空；已知切点后，单图大小可精确判别伪域。这些数值仅衡量身份识别，查表利用了完整基准的域索引。一个实际部署的源模型若只有一个源，未必知道新域切点。即使域号已知，有限源图学到的类规则在新域也仍可错。若训练一个看目标批次的适配器，应与同时可看查询图大小的强单图模型比较，并直接检验替换参考池后是否能多纠正整图类别。[全域查表与条件熵](../results/cross-domain-structure/size-id-summary.csv) · [跨域并列切点](../results/cross-domain-structure/size-id-shared-sizes.csv) · [24 个伪任务的逐项核对](../results/cross-domain-structure/size-id-pseudo-tasks.csv)
