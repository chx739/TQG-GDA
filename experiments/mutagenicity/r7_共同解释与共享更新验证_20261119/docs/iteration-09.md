# R7 第九轮迭代：用角向特征拟合共同解释

[第八轮](iteration-08.md)表明约束目标类别比例可以缓解 M3 的退化，但两个真实迁移方向的 NLL 仍上升。冻结图编码器逐层使用 sum pooling。封存后的特征诊断显示，按五个源模型取平均，M1、M3 的目标 A 嵌入范数中位数分别是源 fit 的 0.73 倍和 0.45 倍，且分别有 29.4%、75.1% 的 A 落在源 fit 范数的第 5 百分位以下。这里的范数使用固定的源坐标尺度。边密度域之间的图规模差异可能改变嵌入幅度，类模板拟合可能把这种变化解释成类别变化。读出包含非线性层，嵌入方向是否保留可迁移的类信息要靠实验判断。

对真实图解释模型，用原点为零的方差标准化嵌入 `h/s` 做逐行 L2 归一化，分母下限取既有坐标下限。源图和目标 A 使用相同映射。在归一化后的嵌入上，按原规则由源 fit 确定二维投影和类条件 GMM，再按第八轮程序拟合共享仿射、类别先验及 B0 类别比例代价。原始 B0 logit、更新特征、候选后验矩、风险和所有对照程序沿用第八轮。归一化只作用在解释模型使用的表示，目标图的分类更新仍在原始完整特征空间中。

[冻结配置](../configs/r7-iteration09-angular-mixture-mass.json)在 S 使用新种子 45–49，二维合成分支沿用原观测模型以保留解析真值对照。另以构造的高维正比例缩放图嵌入检查角向实现，并复核 B0 类别比例及后验矩。S 主门槛验证原机制回归，高维夹具验证变换和接线。真实 P 使用第八轮相同方向、种子、源模型、目标 A/H 图 ID、宽度和晋级条件。预测及审计封存后才按协议读取目标标签。

在主门槛外，用两轮均完成封存的 P 做配对诊断。对照包括同一 B0、原第八轮 J、固定温度 C05/C075，以及以无标签 A 上二分类 margin 更新的 RMS 为标准缩放的第八轮 J。用 A 拟合截距和 B0 margin 对更新量的线性投影，再把冻结的残差方向应用到 H，观察其单独对 BA、净纠错和 NLL 的贡献。用源验证图检查角向化是否损害源模板的类信息。

如果角向版本保留 M1 分类收益，同时使 M3 优于第八轮和 RMS 匹配对照，支持幅度变化干扰解释拟合的假设。如果仅 NLL 降低且排序与分类基本相同，收益主要来自校准。如果源模板劣化或 M3 在更新强度匹配后仍退化，当前角向方案缺少进一步扫描归一化强度的证据。这是相同开发图上的新方法比较，跨划分和跨数据集证据以原 C/D 协议为准。

已有图规模泛化研究发现，局部结构分布也会随图规模改变，并使训练良好的 GNN 在不同规模上迁移失败。这里检验的是现有冻结表示中径向幅度的作用。即使归一化有效，本实验也无法排除局部结构差异。[Yehudai 等，ICML 2021](https://proceedings.mlr.press/v139/yehudai21a.html)

两轮 P 均封存后，在仓库根目录运行配对诊断。输出保存到封存目录之外的新路径。[诊断脚本](../scripts/audit_angular_update.py)

```bash
python -m experiments.mutagenicity.r7_共同解释与共享更新验证_20261119.scripts.audit_angular_update \
  --reference /path/to/attempt-010/P --angular /path/to/attempt-011/P \
  --output /path/to/attempt-011/diagnostics/angular-update.json
```

## 封存结果

S 已通过。正确设定和角度偏移各有 5/5 种子满足主门槛，平均期望 NLL 差为 −0.01229 和 −0.00990，无偏移为 +0.00016。18 项相关工程回归通过，其中 16 维夹具检查角向实现。二维 S 的结果用于确认已有机制可复现。真实 P 按原门槛继续。[S 门槛](../results/iteration-09/S/gate.json) · [工程回归](../results/iteration-09/S/engineering-regression.txt)

真实 P 未通过。十组主比较与独立局部分离审计均有效，搜索未发现有害可行解释。下表是留出集主宽度的 J−B0，括号为条件于拟合模型的配对 95% 区间。

| 方向 | ΔNLL | ΔBA（百分点） | NLL 改善种子 | 净纠错为正的种子 |
| --- | ---: | ---: | ---: | ---: |
| M0→M1 | +0.01436 [−0.00765, 0.03823] | +0.094 [−1.079, 1.260] | 1/5 | 4/5 |
| M0→M3 | +0.05504 [0.03382, 0.07789] | −0.079 [−0.943, 0.762] | 0/5 | 2/5 |

相较第八轮，角向模型使 M3 的留出 BA 提高 0.99 个百分点。相对在 A 上匹配修正 RMS 的第八轮 J 提高 1.02 个百分点 [0.04, 1.99]，因此改善并不能仅用修正幅度解释。同时 M3 仍低于 B0，NLL 与匹配对照接近。去掉截距和置信度分量后的角向残差在 M1 带来 +0.90 个百分点 BA，在 M3 为 −0.81 个百分点，两个区间均跨零。M3 的 J 相比逐图对照 P 的 NLL 高 0.01776，BA 低 0.62 个百分点 [−1.23, −0.08]。这次真实试点不支持扩大共同约束迭代的范围。[P 门槛](../results/iteration-09/P/gate.json) · [配对结果](../results/iteration-09/P/paired.csv) · [更新强度匹配诊断](../results/iteration-09/diagnostics/angular-update.json)

角向化降低了参考解在目标 H 上的最大坐标 CDF 距离。源验证集上，模板相对 B0 的 NLL 代价从 +0.06399 增至 +0.07602，BA 从 −0.40 降至 −0.57 个百分点。边缘匹配改善与类信息受损可以同时发生。结合真实 P，后续优先检验在图编码器读出阶段处理尺度能否保留类信息，不继续扫描同一角向归一化的强度。[模板与边缘诊断](../results/iteration-09/P/coverage.csv)
