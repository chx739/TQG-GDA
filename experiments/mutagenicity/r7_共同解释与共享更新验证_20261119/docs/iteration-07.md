# R7 第七轮迭代：防止目标类别质量坍缩

[第六轮实测](iteration-06.md)的源后验恒等重放通过。M0→M3 的无标签适配仍给出接近 0 或 1 的目标先验和后验类别偏差，和 B0 在 A 上约 0.48–0.57 的平均类别 1 概率相差很远。该现象发生在多个源模型上。新假设是，目标边缘中不足以识别类比例的部分需要由弱类别质量信息约束。

## 固定改变

使用 \(m_0=|A|^{-1}\sum_i p_{0,i}\) 作为无标签锚点，用同一候选解释给出的 A 后验均值 \(m_\theta\) 约束实际进入 shared update 的类别质量。对二类概率使用 \(\tilde m=10^{-8}+(1-2\cdot10^{-8})m\)。拟合参考、计算相容性与搜索时使用同一观测目标

\[
\ell_c(\theta)=\ell_{\rm obs}(\theta)+\frac{|A|}{|S_{\rm fit}|+|A|}\,\mathrm{KL}(\tilde m_0\;\|\;\tilde m_\theta).
\]

权重用一张 A 图对应一个软类别观测的单位固定为 1。风险目标、完整 W、正则、目标类别标签启封顺序和比较方法均保留。原始边缘拟合损失、类质量代价和合成真后验风险分别报告。阈值此时约束带类别质量代价的观测目标，原始真参数似然仍作为单独诊断。这个约束依赖 B0 的目标类别质量有参考性。它可能阻碍真实类先验变化，M1 正是需要检查的情形。

## 验证

[冻结配置](../configs/r7-iteration07-mass.json)使用未打开过的种子 35–39 和原三宽度，主宽度 0.005。通过原 S 门槛后，复用相同两图方向 P 作为开发评价。除主指标外，核对 A/H 的类别质量、源验证损失和实测方向风险。若抑制极端类别质量后仍没有可重复的 BA/净纠错改进，则类别质量失真无法解释全部失效，后续应更换迁移假设。C/D 只按原门槛触发。
