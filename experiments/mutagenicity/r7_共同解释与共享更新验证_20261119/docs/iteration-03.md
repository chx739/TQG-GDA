# R7 第三轮迭代：让解释模型只拟合源任务相关的坐标

## 依据与假设

[第二轮 P](iteration-02.md#真实图-p-实测)的独立搜索没有发现当前解释族内的有害方向。A 标签却显示相反的风险变化。单参考解释 E 同样有害，宽度 0.005–0.02 的结论一致。误差最大的 M0→M3 上，J 把平均类 1 预测概率降到 0.288，真实留出图比例为 0.524。源验证 NLL 也明显上升。推断是 16 维的对角类条件模型能通过边缘拟合得到不可信的类后验。O 的留出 NLL 改善说明同一线性修正空间有任务信号。O 的 BA 区间仍横跨零。

本轮只改变共同解释的估计坐标。待验证假设是，优先拟合与源分类相关的两个坐标，可以减少高度相关或偏离高斯假设的余下维度对类后验的影响。估计空间减维后，真实任务信号也可能被丢掉，或两个保留坐标本身仍强烈偏离模型。

## 固定改动

1. 对原始整图 embedding 做相同的源训练逐维标准化。第一轴取冻结源分类头的二分类 logit 差法向；第二轴取源训练标签的正则化 Fisher 法向在第一轴正交补的分量。若残差退化，取正交补上方差最大的源方向。仅用源训练图归一化两个坐标。二维合成特征已在维数上限内，保持整个原空间。
2. 只用这两个坐标估计 J 的同族解释、参考和相容阈值。每个解释仍一次性给所有 A 图提供后验，后验与完整的原特征坐标组成监督矩。W、原始正则坐标、分类头宽度、同空间 O 与 B0 保持一致。对比低维和原始版 E、J、P、P_mass、J_cal、J_bias。H 的后验用冻结源投影和同一解释参数重算。
3. 主宽度仍为 0.005，敏感性宽度为 0.01、0.02。维数与投影规则事先固定。用户目标域标签不参与投影、候选估计、选模或更新约束。

## 验证与失败条件

先用未使用的 15–19 新种子验证原四个二维世界。该环节检查投影入口保留既有机制，二维恒等条件本身不能检验高维修复。通过后按同一原始图 ID 配对再跑两方向 P。两个真实方向的旧版结果已用于定位原因，这次 P 属于开发验证。推进 C 仍要求原门槛，最终外部 D 保持独立。

除主要 H 分类与 NLL 外，比较 J 的源验证 NLL、A/H 预测类边际、真实监督矩与有限候选的距离，以及实际方向风险和已找到风险之间的差。目标是同时纠正方向风险和改善分类；若只减小更新、只改善 NLL 或仍远离真实任务方向，保持失败判断。投影后的 CDF 距离只描述两个坐标的边缘拟合，和原 16 维最大距离的数值不直接对等。
