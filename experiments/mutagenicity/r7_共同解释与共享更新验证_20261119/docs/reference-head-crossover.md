# R7 第十二轮的分类收益是否依赖本域适配图？

2026-11-21。第十二轮沿用普通 argmax。两个 Mutagenicity 设置上，相对原 GNN，单解释更新 E 的五种子平均 Accuracy 提高约 0.69、0.76 个百分点。共同解释更新 J 相对 E 为 +0.09、−0.18 个百分点，配对区间都跨零。即使一个更新头来自无标签目标图，它也可能在不同目标上都带来近似的源分类器校准。本轮用同一源模型已学到的三个头做交叉推断，检验其收益中有多少来自参考域与评价域的匹配。[原报告](iteration-12.md) · [原封存配对](../results/iteration-12/repair/C/paired.csv) · [图级 GRADE 的两域交叉对照](../../r10_原生图适配基线与增量_20261121/docs/reference-crossover-results.md)

## 冻结输入与动作

只使用 R7 第十二轮数值修复版的 C 阶段，原 R7_FINAL digest 为 `a97d6884ee74c456fce8b7c7e3ae9a5a5d6a72e22ac4b7b8835a06bf130a420c`。三个既有设置，每设置四个源、五个种子 3405–3409，宽度 0.005。保持源 GNN、β、每个历史参考池的全部图及原更新不变。交叉头仅在相同设置、源域与种子内使用。对每个目标留出池 H，比较本域 A 产生的头以及另外两个目标域各自 A 产生的头。异域头是归因对照，实际部署只需本域 A。保存不同 A 的图数，参考池不同包含图的内容和实际池大小。

- 主分析 E，另报 J 以及二者的配对差。逐源种子核对三个块的源训练 ID、冻结 GNN 检查点身份和源标准化参数。在原源坐标中，用 H 的冻结 B0 两类 logits 加标准化 H 特征（含截距）与对应头权重的线性修正。普通 argmax 平局取 0。每个有效对角的动作须逐图复现原封存预测并核对 logits 或其 margin。B0 为共同起点。
- 对每个交叉头另建一个只移动 B0 判决阈值的诊断。把同一 H 的 B0 margin 降序排列，同分按原始图 ID 升序，取与该交叉头**精确相同**的阳性图数。记录边界平局次数。这一对照使用整个 H 的无标签分数，只用于解释排序和阳性数的贡献。
- 每个设置的主格只纳入 E 和 J 各自三个参考头均有效的共同源种子，保留完整三乘三交叉矩阵。另对全部原定方向报告明确的实施规则：某个参考头原拟合失败时沿用 B0。分别列出缺失和回退数；发布的原 C 成败按原门槛。检查同一设置下 A 与 H 的图 ID 无交叉污染。全部方法、参考域、留出域的动作先封存，再用各块原 H 图 ID 的授权标签评分，复用同目标同一批图的标签。无新增训练、A 标签、外部数据或 NCI1。

## 对照与判读

每个源、种子、H，分别算本域 Accuracy、异域两个 Accuracy 的平均、B0 Accuracy 和上述 B0 同阳性数动作的 Accuracy。主差值为**本域减异域平均**，另外报告本域减 B0。为区分改判数量和改判对象，将主差分解为同阳性数 B0 的本异域差，以及两者之差；后者衡量换参考域时，重排对 Accuracy 的额外贡献。逐项报告 Macro-F1、图上纠正／误改及动作分歧，原有同图强源基线从已发布的 R10/R11 端点精确配对到同一方向与种子后列出（SourceV、源选模 WL、Size），保留绝对数。

先在每个迁移方向内对有效种子等权，再对十二方向等权。完整案例在 PROTEINS 有三个方向各缺一个种子。区间沿用已拟合模型、目标域内按类配对图重抽样 2,000 次，同一图在所有方法、参考域、源与种子下共享权重，不将 60 个块当作独立数据集。分歧率也给出无标签可达 Accuracy 差的绝对上界。三个目标中某个头在所有 H 都普遍更好，其共同优势在完整的交叉比较中抵消。原第十二轮选择 β 时已见的分子边数 M0→M1、M0→M3 单列，移除这两个方向的敏感性结果单列，不用于重选头。

本轮的投入判断事先固定。E 的本域优势若在 PROTEINS 和至少一个分子设置均达到 +0.5 个百分点、配对区间下端高于零且本域超过 B0，才继续将 E 作为跨设置的目标匹配机制。若只有单一设置达到，在该设置定位具体条件。若本域优势很小而本域优于 B0，先将源侧或通用校准视为竞争解释。若同阳性数对照解释了主要差异，下一步应验证阈值价值；若有可重复的重排贡献，则优先分析哪些图的相对次序获得纠正。J 与 E 同时在同批图比较，不能用事后选择表现较好的头宣布主方法过线。真实数据已经参与过研究开发，这轮仅作配对机制归因。
