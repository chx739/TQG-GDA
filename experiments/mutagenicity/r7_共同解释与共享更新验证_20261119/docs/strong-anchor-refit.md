# 在强源分类器上重新求解 R7 的更新

## 要检验的差别

原 R7 单解释头 E 以 GNN 的 logits 为起点。在 R7 的强基线对照中，只有 E 翻转了 GNN 的硬判决才可能修改 WL 或 Size。这样会丢失两类信息：强模型很确定时，原 GNN 的改判可能幅度很小；强模型处于边界时，原 GNN 的概率可能移动很多却仍留在同一侧。本试验保留 E 的目标监督矩、源 GNN 的特征和正则化，只更换求解时使用的初始 logits。问题是原目标解释能否直接纠正强源模型仍犯的错。[硬改判实测](transfer-of-flips-results.md) · [原 E 求解与数值记录](iteration-12.md)

## 来源、一次先导和算法

沿用 R7 C attempt-016，种子 3405，三个设置各十二个既有方向。冻结宽度 0.005、原始解释、源标准化更新向量 u（含常数列）、完整原 A 和独立于 A 的历史开发 H。两种强源起点 C 为 R10 同源同种子选定的 WL 和 Size。两者都运行，开发数据事先指定的主要比较仍为两种 Mutagenicity 用 WL、PROTEINS 用 Size。复用已拟合的源模型，仅读取 A、H 的无标签结构及预测完成推断。H 的图号须与既有角色逐图相同；不得在拟合、选模、定步长或选方法时打开 A/H 标签。其他域的 A 只用于已登记的同源交叉对照。36 个方向的两种起点全部预测冻结后，按原 H 角色统一评分。这些 H 已用于研发；筛查通过也只触发进一步验证。[R10 强源模型](../../r10_原生图适配基线与增量_20261121/docs/structural-reference.md) · [R7 交叉权限](reference-head-crossover.md)

在参考 A 中调用原 R7 单候选 master，用 C 的 logits 替换原 GNN logits。记 C 的二类 margin 为 c，参考解释的正类监督矩为 s=mean(qᵢuᵢ)，取原 OBS 中与 ref_theta 唯一相等的 theta 所对应的 stats。若用二类差分 d 表示更新，目标是 mean[softplus(cᵢ+uᵢᵀd)−softplus(cᵢ)]−sᵀd＋λ‖d‖²/4，λ 直接取该轮 R7 的 regularization。新图按 c(x)+u(x)ᵀd>0 判正。可用等价的严格凸二类求解器，以原坐标一阶残差核验解并与独立计算对读。强源模型的 A logits 从 R10 已封存模型按原无标签图重建；在 H 须复现 R10 的原 margin、顺序和判决。每个设置、源、参考及强源起点各拟合一次；该方向不得使用另外两个参考池改善本域解。

| 臂 | 固定或改变的部分 | 要排除的解释 |
| --- | --- | --- |
| 强源 C | 零更新 | 能否比同一强模型多分对图 |
| Full，本域重新求解 | 在强源 logits 上拟合原目标矩，使用完整 u | 主方法 |
| B0Teacher | 同一强源起点、同一 A、同一 u、同一正则，把 q 换成原源 GNN 在 A 的概率 | 仅把另一个源分类器蒸馏到 C 已经足够 |
| ScoreOnly | 原目标矩、强源起点和正则不变，更新仅允许位于截距和原 GNN margin 两项张成的权重子空间 | 简单移动阈值或融合两个已有源分数已经足够 |
| 原 E 软修正 | 给 c 直接加原 E margin 减原 B0 margin，单位系数 | 只需保留连续更新，重新求解没有增量 |
| 异域 Full | 同源另两个等设置下训练好的 Full 各在相同 H 推断，然后等权 | 相同求解过程和源信息是否已解释收益 |

ScoreOnly 以正交列 Q 表示上述子空间，输入 UQ、监督矩 SQ，在原正则下求解，再还原 Qd。Q 由常数坐标和原 v0 两类系数之差去掉常数坐标后归一化构成；非截距法向为零时只留截距。该臂容许目标信息选择 GNN 的系数与截距，仍不能使用与这两项正交的更新方向。对 Full 另给沿 C 在 H 的原排序、阳性数与 Full 相同的硬判决，仅作事后排序归因；并列按原图号打破。归档两类单模型、两个比较方法产生的原 logits 或解、KKT 残差、各池大小和失败范围。若数值核验不通过，先查明原因，禁止根据标签选择可用方向。

一个可核验的恒等式是在同一起点，Full 和 B0Teacher 的初始梯度差等于 mean[(p_B0−q)u]，与 c 无关。更换起点会改变两者的共同误差项、曲率与各新图离分类边界的距离。若拟合后 Full 仍仅在原 GNN 犯错而强基线早已分对的图上移动，重新求解不会提供稳定分类增益。用合成矩阵核验零修正、原 B0 重放、子空间目标/正则等价以及换池后的源坐标一致性；在真实块复核原 B0 起点的 E 动作。

## 评价与停止条件

以普通 Accuracy 为主，给绝对值、同图纠正/误改、逐方向正平负、Macro-F1、NLL，以及同阳性数后额外的 Accuracy。每设置十二方向等权。预先要求 PROTEINS 和至少一个 Mutagenicity 设置同时满足：Full 比指定强源起点至少 +0.5 个百分点，在至少 7/12 个方向胜过该起点，且设置平均严格胜过 B0Teacher、ScoreOnly、两个异域 Full 的等权平均和两个独立强模型 WL、Size。通过才投入其余四个既有种子。若 Full 只胜教师而仍落后于 C，结束该固定的重新求解规则；若收益被 ScoreOnly 或等阳性数干预复现，分别保留源分数融合或阈值变化这一较窄的解释。原 E 软修正对比给出重新求解的实际增量，等阳性数对照不参与调参。完整报告两种起点的全部设置，保留此前两种分子划分复用实体的限制。
