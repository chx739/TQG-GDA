# R7 共同解释集合能否支持有用的共享分类更新

登记日期为 2026-11-19，状态为计划中。本次执行前补充了简化对照、配对区间及外部确认。数值预算、门槛和角色定义见[计划配置](../configs/r7-plan.json)。[R5](../../r5_原始方法与请求价值_20261114/report.md)给出原始 TSBA 的全方向效果，[R6](../../r6_源梯度与密度请求分解_20261114/README.md#结果摘要)分离了持续源驱动与密度请求。本轮验证[共同解释驱动的共享更新](../../../../docs/method/shared-update.md)，沿用已选定的源模型和表示，将研究变量收窄到固定 logit 修正的监督信息及共同约束。

## 1 研究问题与证伪条件

| 问题 | 对照 | 证据含义 |
|---|---|---|
| 同一修正头有没有可利用的任务空间 | 同空间监督诊断 O 对源模型 B0 | O 在目标留出图也改善，说明在当前表示和正则下有可利用空间 |
| 无标签共同解释能否提供有用的监督统计 | 共同解释 J 对 B0、单解释 E 和固定概率缩放 | NLL 降低表明概率质量改善。BA、Accuracy 和净纠错另外判断分类价值 |
| 图之间的共同约束是否有价值 | J 对使用同批已发现解释的逐图区间 P | 仅改变后验在图之间能否独立组合。优势在扩充候选后保持才支持这一归因 |
| 收益能否由类别比例或简单阈值移动解释 | J 对只保留类别比例约束的 P_mass，以及限制更新空间的 J_bias、J_cal | J−P_mass 检查超出全域类别比例的特征关联。J−J_cal 检查超出全局 logit 缩放和截距的收益 |
| 集合能否既覆盖任务信息又支持非零修正 | 真实监督矩或观测标签矩、源预测矩与候选凸包的关系 | 合成已知后验识别覆盖。真实图用经验矩和方向风险识别可疑缺口 |
| 冻结方法能否迁移到外部数据集 | D 中 J 对同口径 B0，在 NCI1 留出图上比较 | 测试方法和配置在新数据集上能否复用，源模型按 NCI1 的源域重新训练 |

分别回答**效果、收益来源、外部复现**。J 即使与简化对照相当，也可能在留出图上改善分类，此时根据对应消融收窄贡献解释。若同空间 O 有收益而 J 退回近零，先查集合是否也容纳源预测矩。若 J 给出非零修正却损害真实风险，先查候选统计的方向覆盖与局部搜索遗漏。O 在留出池无稳定改善时，该监督诊断尚未证明修正空间的可达收益。它受 A 样本量和正则影响，作为诊断而不是方法效果的硬门槛。

## 3 方法、控制和设置

从 R5 的 `frozen.pt["h"]` 取原始整图表示，使用 `source.pt` 中的源线性权重与偏置在 float64 重建固定 $z_0$。逐图重放 R5 B0，softmax 相对容差 $10^{-10}$、绝对容差 $10^{-12}$，预测类别要求一致。J、E、P、O 共用源训练表示估计的逐维标准化、16 维表示和常数特征，形成 $z_0+Wu$。新方法采用分类头原始 $W$ 坐标上的 $\lambda=0.1$。R5 缓存的全局 RMS 坐标只供原始 TSBA 同口径对照使用。

| 组 | 求解方式 | 所用标签 |
|---|---|---|
| B0 | $W=0$，固定源分类器 | R5 已完成的源训练与源选模 |
| E 单解释 | 同一冻结参考解释的 $S$，用一个约束求主问题 | 当前源训练标签 |
| J 共同解释 | 当前生产实现，在固定似然阈值内局部寻找更不利的联合解释 | 当前源训练标签 |
| P 逐图区间 | 与 J 同批解释，逐图独立在同批概率中取最坏值 | 当前源训练标签 |
| P_mass 逐图区间加类别比例 | 在 P 的同批逐图区间上，加上同批解释给出的全域平均类别概率范围 | 当前源训练标签 |
| J_bias 截距修正 | 同一 J 候选、同一主问题和 L2，只允许 $W$ 的常数列非零 | 当前源训练标签 |
| J_cal 全局缩放加截距 | 同一 J 候选和 L2，把 $W$ 限制为对源 logits 做共同非负缩放加类别偏置 | 当前源训练标签 |
| O 同空间监督诊断 | 冻结后在 A 上用 one-hot 真实标签构造单个 $S_Y$，沿用同一主问题 | 仅冻结后读取 A 标签 |
| C05、C075 | 固定 B0 logit 倍率 0.5、0.75，两组均报告 | 已有源模型 |

P 在给定 $W$ 时，对每张 A 图取同批解释中最小的 $q_i^\top Wu_i$，再在整个 A 上平均。可用精确逐图分离的约束生成法求解这个凸目标。P 的分离在这批已保存概率上是精确的，预算为 100 次，容差与 J 一致。输出前按完整逐图乘积精确重算最坏风险，且最终违背量须不超过分离容差，主问题也须通过零修正比较。预算耗尽后仍有显著违背时，记录求解未核验，主比较记缺失。J–P 的比较范围是 J **实际保留的候选**，包括按联合统计去重的影响。扩充审计子对照保留全部不同解释参数，即使其联合统计相同，以便 P 获得其逐图差异。E 采用观测拟合参考解。

P_mass 用同一候选池给出各图 $q_{i,1}$ 的区间和全域平均值的区间。二分类可做精确分离。从不考虑平均值约束的逐图最优点出发，若总质量越界，按目标线性系数排序，在各图仍可调整的区间内以最低代价补足或撤回质量，平局按图 ID 排序。实际目标类比例不参与这一组。其求解预算与 P 相同。相同 $W$ 上的最坏风险应按 J、P_mass、P 非递减。

设 $V_0u$ 为按类中心化的固定源 logits，$e$ 为常数列的单位向量。J_cal 限制 $W=(a-1)V_0+be^\top$，其中 $a\ge0$、$b$ 按类均值为零，得到与 $az_0+b$ 相同的预测。保留原坐标 $W$ 上的 L2，类共同偏移不会额外抬高对照的惩罚。J_bias 取 $a=1$。三个新增对照均用主宽度，扩充审计另报同候选并集的 J 与 P_mass。

主宽度 $\tau=0.01$，辅助为 0.005、0.02，单位为每图平均联合 NLL。S 与 P 全报三个宽度，C 只用主宽度。每块共享一个参考拟合解及 $\ell_{\mathrm{ref}}$，主门槛只用 0.01。参考类条件对角高斯、共享正对角仿射、均值/方差范围及先验边界沿用当前实现。J 主预算为 10 次分离，每次 5 起点、150 次迭代，主问题 200 次迭代。种子用当前任务 seed。数值阈值保留计划配置的原值。

**预算与遗漏审计。** P 小规模阶段的主宽度运行中，冻结 $W_J,W_P$ 后，保持参考阈值与参数范围不动，用 seed+7001 的独立初始化，对这两个固定更新各做一次额外分离。另选 A 中 J 的二分类改变量绝对差最大的两张图，以图 ID 打破平局，对每图类别 1 概率的最小与最大各查询一次。每个查询 10 起点、300 次迭代。所有相容新解释与原集合取并集，供额外的冻结集合重求解 $J^+,P^+$。保存互相独立的主结果和扩充审计。若找到更低似然，记录与参考的差并维持既定阈值。若发现相容解释使已冻结修正的相对 NLL 大于 $10^{-6}$，本轮的近似风险判断出现反例，即使修正能改善实际标签指标也保留该反例。

## 5 P 与 C 的指标、门槛和数据口径

**主终点**为固定主宽度 J 在 H 上的最终预测。J−B0 的 NLL 是概率质量终点，BA 是分类终点。主机制比较为 J−P，补充 J−E、J−P_mass、J−J_bias、J−J_cal。辅助分类指标为 Accuracy、逐类 recall、Macro-F1 及相对 B0 的错→对、对→错、净纠错。附报源训练/验证和 A 的评价仅供定位。NLL 从 log-softmax 计算，Acc/BA 差值用百分点。记录目标类别边际和相对 B0 的类别中心化 logit 修正 RMS。

每块保存 $d(S_0,\mathrm{conv}\{S_k\})$、$d(S_Y,\mathrm{conv}\{S_k\})$ 和沿 $W$ 的实测与候选最坏风险差。范数采用统计矩原坐标 Frobenius 范数，凸包距离求解须报告单纯形残差，失败记 NA。H 上用**冻结的解释参数在 H 特征上重算全部 $S_k$**再构造用于评价的凸包。经验 one-hot 矩反映有限标签样本。另报告在 A 拟合的参考解释与 H 观测特征之间的逐坐标最大 CDF 距离及其中位数，作为边缘拟合诊断，模型选择与相容阈值维持原值。

**配对不确定性。** 对预定的 H 上各方法差与经验方向风险差，报告逐方向、逐设置的图级 paired bootstrap 95% 百分位区间，指标包括 ΔNLL、ΔBA、ΔAccuracy。每次按目标域和类别有放回抽取原数量的图，同一图 ID 的所有方法、seed 和共享目标域的源方向随该图一起重采样。共 2000 次，RNG seed 为 20261119，固定已拟合模型与解释。每类少于 10 张图时，主指标点估计仍按可用情况报告，相应区间记 NA，完整设置的区间须包含所有指定方向。区间反映固定模型、固定域的留出图变动，模型 seed 波动另外报告，各设置的区间不合并。0.5 pp、4/5 seed 等值是事前的实用与投入阈值。

**从 P 进入 C 的门槛。** 以下为事前的投资决策阈值，按两方向分别计算，每方向 5 seed，所有主比较配对完整。相等判据为 NLL 容差 $10^{-8}$。

- J 在 H 的每方向平均 NLL 相对 B0 下降至少 0.005，且至少 4/5 seed 方向一致。每方向至少 4/5 seed 有效非零更新。预定独立搜索审计完成，J 上无相容解释反例和未解释的数值回退。
- J 相对 B0 两方向平均 BA 均不下降，其中至少一方向平均 BA 提高 0.5 pp 且至少 4/5 seed 净纠错为正。如果 NLL 有益但分类条件未达到，当前证据限定在概率质量，暂不扩展分类主张。

若 B0 或 J 的指定评价池出现缺失或评价失败，保留全部分母和原因，所需门槛记未通过。O 的收益和 J 的 oracle 收益比例作为诊断。J 对 P 或 P_mass 的独立机制证据分别要求至少一方向的平均 NLL 下降 0.002，另一方向的增加不超过 0.002，并在扩充候选审计后保持。不满足或缺失时仅收窄机制结论。J−J_cal 用于判断特征相关修正是否超过全局缩放与截距，E 与 J 收益相近时共同解释相对点估计的额外价值尚未建立。所有比较均附配对区间。若区间跨过零，报告为不确定并保留点估计，停止扩展不自动解释为机制被否定。任何由 P 结果引起的模型范围、$\tau$、正则、预处理或阈值变动都登记为新版本，并明确该结果是进一步开发。

**C 全方向。** 按同一参数、划分和方法执行其余 170 个任务×种子块，每个 seed 内等权平均 12 方向，再分别报告三个设置的五个 seed、均值、区间、样本 SD、胜平负和逐方向差。新增块另报，不把 P 贡献计成独立确认。跨数据集开发收益的点估计门槛为三个设置的平均 NLL 均降低、BA 均不下降，且 **PROTEINS 与至少一个 Mutagenicity 划分**各提高 BA 至少 0.5 pp。只有两个不同数据集各有完整且方向有利的 ΔNLL、ΔBA 配对区间时，才报告这两个开发数据集上的明确复现。机制另列五项主宽度消融，PROTEINS M0→M3 的 5 seed 重复 P 阶段独立扩充审计。保留每设置分母，BA 缺任一类时记 NA。

**同口径 TSBA 对照。** C 阶段另运行原始 M00 的零请求 B1 和学习 score A0，锁定同一源 checkpoint、同一 A/H 和 R5 主配置。A0 只在 A 重估带宽并训练 score 至第 7200 次实际更新，包含最后不足 128 的 batch，达到精确更新数就停止。固定原 R5 的 seed+101/+102/+103 随机流与 seed+201 批次流，epoch 数由 A 池大小决定。A0 与 B1 共用重新抽取的合法源/目标批次和 A 带宽，两组各 30 次尝试。H 只做最后状态评价。原始 TSBA 使用冻结 R5 全局 RMS 坐标，J 保持新方法固定逐维坐标。此对照比较完整方法，机制归因依赖同空间对照。每个设置分别对 A0、B1 报 ΔNLL、BA、Accuracy 与净纠错。跨数据集优于 A0 的分类主张也应用上段的点估计和区间标准，并将比较基准换成 A0。历史 R5 端点用于背景解释。

## 6 D 外部数据集确认

**预指定 NCI1 边数划分。** [官方 TUDataset](https://chrsmrrs.github.io/datasets/docs/datasets/)登记 4110 张二分类图，提供节点类别特征。仓库 `data/idx_NCI1_0.npy` 至 `data/idx_NCI1_3.npy` 已核对覆盖 TU 零基 ID 0–4109，四域图数为 1027/1027/1027/1029。按 R7 同一哈希规则得到计划 A/H 分母 718/309、715/312、704/323、739/290。当前检查没有找到本地原始文件和源 checkpoint。`configs/r7-plan.json` 记录索引哈希。计划使用 [官方 NCI1 ZIP](https://www.chrsmrrs.com/graphkerneldatasets/NCI1.zip)，将原始文件置于本地 `data/NCI1/raw/`。启动前登记 ZIP 与原始文件哈希，核对图编号及边数域对应关系。若数据缺失或对应关系不成立，记 D 未执行。

**固定方法和标签角色。** C 达到跨数据集开发收益的点估计门槛、主配对完整后，先封存 D 协议、代码、J 超参数和报告脚本，再准备 D 的原始输入。D 只训练 **M0** 源域的五个 GIN，目标是 M0→M1/M2/M3，共 15 个块。源模型沿用 R5 的 3 层、hidden 64、embedding 16、dropout 0、Adam 0.001、batch 128、100 epoch，按 M0 源验证 CE 最小选模。沿用 R5 的逐类源角色分配。节点类别采用 M0 源训练池的有序词表 one-hot，加一个未知槽，边属性为空。目标域的任何图都不作为 D 的源标签数据，三个方向的全部无监督结果封存后才读各自 A 标签用于 O，O 封存后统一读取 H 标签。

**确认标准。** D 采用相同的 B0、E、J、P、P_mass、J_bias、J_cal、O 和固定缩放对照，只用主宽度。J 对 B0 在每 seed 等权平均三个方向，再平均五 seed，要求留出 NLL 下降至少 0.005、BA 提高至少 0.5 pp，且两项的配对 95% 区间都在有利一侧。至少两个方向平均 BA 为正，单方向 BA 下降不能超过 1 pp，单方向 NLL 增加不能超过 0.005。必须保留全部 15 组配对分母。主指标未确认时按概率质量、分类增益不足、反向或不确定分别报告。对简化基线的比较单列，机制未建立仍可报告 J 对 B0 的确认。该阶段结论限定在固定方法、NCI1 边数划分与 M0 源设定。跨设置原始 TSBA 优势仍由 C 的匹配对照决定。

## 7 实现、封存与交付

| 实现边界 | 计划工作 |
|---|---|
| 核心模块 | 复用已审查的 `ExplanationSet`、`solve_shared_update`、`solve_master` 和冻结 logit 公式 |
| 本轮 `src/` 与 `scripts/` | R5 封存读取和按任务限域导出、S 合成生成器、固定划分、各消融与独立搜索审计、匹配 B1/A0、D 原始输入及源训练、汇总与恢复 |
| 核验 | 先在合成小夹具检查角色隔离、概率与 logits 重载、同期 B0 等价、P 与 P_mass 的精确分离、限制修正空间、统计配对和封存拒读。单候选时 E/J/P 应等价，同一 $W$ 上已找到风险须满足 J ≤ P_mass ≤ P |

R5 的目标 score、带宽、完整目标批次、候选轨迹和目标标签缓存不作为本轮适配输入。匹配 TSBA 预算上限为 180 个 score、360 条轨迹、10800 次适配尝试。J 的计划求解规模为 S 的 20 块×3 宽度、P 的 10 块×3 宽度、C 新增的 170 块×1 宽度，以及有条件的 D 15 块×1 宽度。P 初试复用 5 个源 checkpoint，无额外 GNN 或 score 训练。D 新训练 5 个源 checkpoint。所有统计求解 CPU float64，单 worker 的 BLAS/OMP/torch 线程为 1，最多 4 worker。不预估未测量耗时。

运行入口在实现后登记，此处的 JSON 是计划。按阶段保存 `R7_INPUT`、`R7_OBS`、`R7_ORACLE`、`R7_FINAL` 和相应版本、输入、ID、命令、配置、环境哈希。自定义封存还需验证预期产物成员及分组、方向、seed 的完整性。观察包包括行序可重载的 $z_0,u,W$、解释参数和 $S$、阈值与候选日志、预测、P 精确分离误差、KKT 残差及审计反例。运行结束归档实际配置、原始证据索引、`endpoints.csv`、`paired.csv`、`moments.csv`、`separation.csv`、`coverage.csv` 和报告。

正常判定的零修正保留为 B0 预测并计入分母。工程失败、搜索未核验、数值回退和缺失分别记录。输入哈希、标签隔离或预测重载不符时停止对应阶段。禁止替换失败种子、使用目标反馈调参或覆盖旧 attempt。阶段门槛、主要比较和实际偏离在报告中逐项核对。
