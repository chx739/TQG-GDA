# 只保留原目标解释超出分数校准的更新

本项在看到强起点先导的主结果后登记。Full 相对指定强源模型的 Accuracy 在三个开发设置分别为 −1.038、−0.355、−4.429 pp；相对 CalTeacher 则为 +0.351、+0.228、+0.877 pp。这项对照改变了投入判断：即使两种教师间有分类差异，要求强源模型逼近整个教师分布可能保留了双方共有的误改。要检验这一解释，只将已经封存的两个更新相减，再作用于原强源分数。前一项的相对收益并不保证在新的判决边界上仍然成立。[两种教师的构造](strong-anchor-score-teacher.md) · [主要对照与原数据角色](strong-anchor-refit.md)

## 规则与对照

复用单种子 3405 的全部 36 个方向、两起点、原 H 角色及强起点 OBS `cadd75220d2b7a57cc644c4f57f9907b354881e27da15bbeb1b33d757b042665`。C 为 WL 或 Size，c(x) 为其原二类 margin。每个参考池 A、每个强源起点已有两个唯一凸解 dFull 和 dCal。定义 δ=dFull−dCal，查询图的结果为 c(x)+u(x)ᵀδ，严格大于 0 判正。固定单位系数，不重新拟合分类器或教师。每个任务仅使用本域 A 的两个解即可部署。若原教师的监督矩可由校准 GNN 完全解释，强凸性保证 δ=0，原分类器逐图保持原判。

两种目标函数只相差线性项。沿 dCal 到 dFull 的线段积分 Hessian，得到 H̄δ=sFull−sCal，H̄ 的最小特征值至少为 λ/2。因此这个修正运输的是两个解释间的矩差，曲率由强源起点、A 和已拟合的两个解共同决定。矩差已经匹配正类质量与源 GNN margin 的一阶矩；经过曲率变换和判决阈值后，输出的阳性数仍可能改变。

固定比较原 C、原 Full、原 CalTeacher、两个异域参考得到的同式 δ（分别在同一 H 上推断并等权）、反号 c−uᵀδ，以及沿 C 原 H 排序且与本域新臂阳性数相同的动作。后者平局按原图号，仅作归因。另列原选模 WL、Size 的绝对指标。对原两个教师使用强起点 OBS 中的权重与图号。为避开先减两个巨大 logits 的舍入，在权重上先相减再乘 H 的 u。所有 36 方向与两起点的动作一并封存后，才由 H 评分入口计分；不使用 A 标签、真实新域或新的种子。

## 结果如何改变决定

主要比较沿用两种 Mutagenicity 的 WL 和 PROTEINS 的 Size。每个设置十二方向等权，报告普通 Accuracy、Macro-F1、NLL、各方向与原 C 的纠正/误改。PROTEINS 及至少一个 Mutagenicity 设置均需满足：相对指定 C 至少 +0.5 pp、至少 7/12 方向为正、设置平均严格胜过 WL、Size、反号以及异域平均。进一步要求在两个过线设置均严格胜过等阳性数对照，才把增量归于跨图排序。通过后才值得补其他种子；若未过线，在这些 H 上结束本轮固定的两教师矩差规则，不通过改变系数或截取有利方向重试。该测试是同一批开发图上的事后提出、事前固定动作的机制检查。
