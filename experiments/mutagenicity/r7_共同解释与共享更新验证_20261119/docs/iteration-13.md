# R7 第十三轮迭代：给均衡分类独立的预测决策

[全方向 C](iteration-12.md#全方向-c-的封存结果)在 Mutagenicity 边数划分得到 NLL 和 BA 收益。在 PROTEINS 的 M1→M0，预测类别均值更接近实际类别比例，少数类召回却降到零。这个方向表明，校准后的概率可以改善多数类主导的 NLL，同时在 0.5 的普通二分类边界下损失少数类识别。

对角向解释、β=0.375 的候选后验和共享更新沿用第十二轮的概率模型。在无标签适配池 A 计算预测类别均值 $\widehat\pi_c=|A|^{-1}\sum_{i\in A}p_J(c\mid x_i)$，在留出图上用 $\arg\max_c [\log p_J(c\mid x)-\log\widehat\pi_c]$ 分类。二分类先将 $\widehat\pi_1$ 截断到 $[10^{-8},1-10^{-8}]$。如果概率与类别比例都准确，这个决策对应类别均衡的错误率。NLL 和候选风险直接使用原概率。BA、Accuracy、召回和净纠错使用冻结的分类动作，动作和概率分别存档。A 的阈值不含真实标签。

定义三项同口径对照。J_argmax 使用相同的 J 概率和普通 argmax。B0_balanced、C05_balanced 分别从自身无标签 A 输出估计类别均值，再使用同一均衡规则。它们检验共享更新是否提供超出阈值调整的类别信息。主门槛的原 B0、原始 TSBA A0、原效应大小和稳健性条件保留。

在第十二轮封存的 C 上进行固定规则开发回放时，持原概率、用自身 A 类别均值的 J，相对原始 B0 的 BA 差为边数 +0.910、节点数 +0.694、PROTEINS +4.097 个百分点。最后一个数来自 59 个有效块。PROTEINS 的 B0_balanced 在其 60 个有效块上为 +2.894 个百分点。此回放用同一批已评价开发图形成后续假设。全方向的正式主比较仍需补齐缺失块并按冻结新方案计分，NCI1 才是外部确认。

另修复一个第十二轮 C 的单候选数值失败。归档 A 侧显示 PROTEINS M3→M0、seed 3407 的缩放 epigraph 求解走完 200 次预算，驻点与可行性均未通过。去掉 epigraph 后在原权重坐标求同一光滑目标，独立回放通过 KKT。正式重跑把这个数学等价的补充求解纳入原验收流程。其余块的比较仍由冻结预测验证。

新的 S 种子为 65–69。P 和 C 仍从固定图开始执行原适配与风险审计。C 只有在核验原 A/H ID、冻住的源模型、原 TSBA 优化预算和代码身份一致后，才复制第十二轮已经封存的 A0/B1 证据，并在新阶段重新核验四个池的预测。J 和监督诊断重新拟合，所有主指标重新计分。

## 首次 S 的封存结果与固定扩展

五种子方案的四个合成世界均完成运行，工程和数值审计通过。正对照 `well_specified` 通过 3/5（66、67、69），平均期望 ΔNLL 为 −0.012929 nats，最差为 +0.001929 nats，解析监督上界 O_analytic 通过 5/5。另一个正对照 `angle_shift` 通过 5/5，平均 −0.012581 nats。无偏移世界的均值为 +0.000091 nats，最大为 +0.000344 nats，符合原保护门槛。首次 S 因 `well_specified` 联合信号不足停止，未启动真实 P。见[首次封存门槛](../results/iteration-13/S/gate.json)。

使用相同的冻结输入，以第十二轮代码重放失败的 65、68。共享更新 w_J、候选参数与统计量，以及 A/H 概率 logits 逐值一致。这排除了本轮预测决策或求解补充分支改变这两个概率失败的解释。两例失败仍计入后续扩展。

一次性固定扩展将种子锁为 65–79，共 15 个。保留全部五个原种子以及两个失败，在每个正对照保持 80% 的通过比例，即至少 12/15 个联合通过。按已观察到的前五个结果，`well_specified` 至少需要新增十个种子中的九个通过。概率模型、均衡决策、真风险阈值、无偏移保护与真实阶段门槛沿用原设定。若固定扩展失利，将保留该结果并以新的机制假设开展下一轮迭代。
