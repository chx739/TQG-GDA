# R7 第十二轮迭代：再降低一次候选后验置信度

[第十一轮](iteration-11.md)把候选后验强度从 β=1 降到 β=0.5。在相同真实开发图上，两个方向的 NLL 都比第九轮更低，BA 都变为高于 B0。M1 满足该方向门槛，M3 的 NLL 平均差为 +0.00191，只有 3/5 个种子改善。现在检验 M3 残留的 NLL 代价是否还受候选后验过度自信影响，以及进一步调节是否会损害已经出现的分类收益。

唯一改变的模型参数是 β=3/8。图编码、角向解释、原边缘似然、B0、更新目标、类别比例锚和风险审计均沿用第十一轮。M3 从 β=1 到 β=0.5 的开发效应只用于确定这一项后续试验，β=3/8 的效应和分类结果仍要实际测量。下一组 S 种子固定为 60–64，并沿用二维原机制回归与独立高维工程夹具。

真实 P 继续用同一批固定 A/H 图和源模型。报告与 β=0.5、原 B0、固定温度及逐图对照的差别。在两方向同时检查原 NLL、BA、净纠错和独立分离门槛。若通过，固定该方案进入 C 的三设置全方向验证，分类收益的外部复现仍以 D 为准。若进一步降低置信度不能补齐 M3 或 M1 的分类损失，这两个值的开发证据用于判断是否需要新的任务约束。
