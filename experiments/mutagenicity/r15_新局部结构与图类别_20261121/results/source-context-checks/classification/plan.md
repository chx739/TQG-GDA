# 登记：源内图类别与远处结构的对应

本次是 R9 的 24 个历史源内方向、种子 3405 的事后机制检查。只在每个方向的 D 上拟合，在同段独立 C 上评价两个固定分类器。先生成全部预测并保存 SHA-256，再按登记顺序读取 C 类别。每方向的标签读取限于自己的 D 或 C。各方向有角色复用，不跨方向传递标签、模型或统计量。整个分析在 /tmp 内，不改仓库。两臂都不使用 U 或真实目标域。结果衡量来源内标签可预测性。

节点词、词典、图内词对、归一和平滑沿用 /tmp/r19-mechanism-screen/replay.py。按 D 中含该词的图数排序，取 16 个最常见的一跳带类型邻域，其余合并为一列。对每张图取所有半径一邻域互不重叠的有序中心对（包括不同分量的中心），其词对计数矩阵除以图内有效对数得 F_g。无有效对时 F_g 为零。

每个源类 y∈{0,1} 各自用属于 y 的 D 图累加 M_y=Σ_g F_g。令 k 为词典宽度。条件表 C_y(i,j)=(M_y(i,j)+1/k)/(Σ_j M_y(i,j)+1)。单词频率 B_y(j)=(Σ_i M_y(i,j)+1/k)/(Σ_i,j M_y(i,j)+1)。这两个概率公式在整个类没有有效对时均给出均匀分布。类先验由全部 D 标签得到，π=(D 正数+0.5)/(|D|+1)。每张 C 图得到两个且仅两个分数：

- 终点边际 m_B=logit(π)+Σ_i,j F_g(i,j) log(B_1(j)/B_0(j))。
- 条件表 m_C=logit(π)+Σ_i,j F_g(i,j) log(C_1(i,j)/C_0(i,j))。

两者的平均 log 比系数固定为一。F_g 为零时都返回源先验。普通分类按 m>0 为正，平局判零。逐图二元负对数似然为 logaddexp(0,m)−y·m。按原 C 全图等权计算 Accuracy 与 NLL，按设置内八个方向等权汇总。另报告图数、覆盖、正例数、动作分歧及条件表相对边际的纠正/误改。两个类别内的第二词共现预测相对边际的好坏只通过这两个固定分类分数与真实 C 标签评价。没有额外的等先验、温度、阈值或超参候选。

角色取 R9 reference-geometry-001 的 OBS 认证清单。拟合时按对应方向的精确 D 身份、评分类别时按对应方向的精确 C 身份逐条读取 R5 注册原始类别行的偏移，并校验类别映射、图号与所需记录。任务无 E/H/U 的图类别读取。源 C 标签与先前的目标 E/H 分开。跨方向复用意味着同一图可能在另一方向对应别的角色，这里以当前方向的授权为单位。源数据上改善也仍不能证明目标适配或目标域净纠错。
