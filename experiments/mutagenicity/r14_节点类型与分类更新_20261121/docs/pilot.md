# 用图中可观察的节点类型检验一次整图分类更新

在 R13 的 36 块评分及独立重放后、实现本轮方法前登记。R13 将本域 BN 统计代入源模型，三个设置的 Accuracy 和 AUROC 平均都下降，固定阳性数后也没有得到正的平均净纠错。相同预算的源图重算 BN 在该种子的三个设置都比原 checkpoint 高。R14 改为从目标图本身提出一个有已知答案的问题：遮住一个节点，从其上下文恢复原来的类型。**待验证的假设**是，模型需要改进目标节点类型与局部结构对应关系的方向，也能改善其他目标图的整图类别预测。相反的解释是，模型可以更好地预测节点类型，同时削弱源分类任务所用信息。图属性掩码、用自监督任务进行测试时训练以及图级测试时训练各有先例。这次重点是扣除同一张图的类型组成后，检验剩余方向对跨图分类的增量价值。[R13 结果](../../r13_目标图归一化与分类排序_20261121/report.md) · [Hu 等的图预训练](https://openreview.net/forum?id=HJlWWJSFDH) · [Sun 等的 TTT](https://proceedings.mlr.press/v119/sun20b.html) · [GT3 原文](https://arxiv.org/abs/2210.08813)

## 共同起点与数据角色

沿用 [R13](../../r13_目标图归一化与分类排序_20261121/docs/pilot.md) 和 R7 C 的源角色 S/V、目标 A/H、checkpoint、三设置与四域。源训练集 S 的全部无标签结构用于 R13 的 node 等权、逐层精确重估 BN。此处用整个 S，使每个源模型的起点完全独立于三个目标。所有更新臂共享这个源起点 Base，保留原 B0、SourceCal、R13 已有的 S-node/S-graph 以及能对齐的 SourceFusion/GRADE 作参照。主试种子 3405，共 36 块。H 在全部拟合与更新方向冻结之后仅作推断，先封存预测，再解码 H 标签。各组之间不传播源标签；适配过程无需 A 或 H 的图类别。NCI1 维持封存。

对每张图，在原封存节点行序下，按 UTF-8 字符串 `r14-node-v1|<TU数据集名>|<十进制图ID>|<十进制节点序号>` 的 SHA-256 升序（平局按序号）选最多四个不同的节点。对每个位置单独复制原图，仅把该行 one-hot 节点类型改为全零，保留邻接、边属性和其他节点。每份副本只遮一处。记录从图中取出的原类型，用它做自监督目标。S、V、各 A 遵循同一规则。每张图的总权重相等，图内各位置分摊。推断图类别时使用原始未遮图。

在全部 S 的上述样本上，取最后一层卷积外部 BN 后、ReLU 后、池化前的被遮节点表示。固定 Base，在这些表示上拟合带截距的多项 logistic 类型头，不看整图标签或目标统计。float64，多类交叉熵按图等权平均，L2 惩罚为所有权重平方和除以 2|S|，截距不罚，等价 C=1。类型集合沿用数据的固定输入宽度。若某类型在 S 的遮点中没有出现，在拟合中仅用已出现类型，生成梯度时把未知类型映射为同样已知类上的均匀软目标，并报告各池实际占比；S 只出现一个类型时所有该模型更新记零。所有臂共享同一个类型头与规范化方式，拟合完成后冻结。源域 V 的类型预测准确率与只猜 S 遮点多数类型的对照用于诊断。若读数无法在 V 上恢复类型，直接注明该数据的辅助任务缺乏证据。

## 哪个更新携带与位置有关的信息

共享可更新参数 θ 只取最后一层**外部** BN 的 γ 和 β，其他权重、全部 BN 统计、图分类头和类型头冻结。每源组在 V 和三个 A 各取 K=min(|V|,|A1|,|A2|,|A3|) 张，使用 `r14-pool-v1|<setting>|<十进制图ID>` 的 SHA-256 升序，平局按数值 ID，保证相同图预算。V 未参加新类型头拟合，曾参与原 B0 的 checkpoint 选择。池之间独立产生一次更新。从共同起点计算两个按图等权的损失梯度：

- g_true 用每个遮点自己的原类型作为预测目标。
- g_hist 给同一张图的每个遮点相同软目标，取该图所选位置真实类型目标的均值。对交叉熵，此梯度恰好是图内随机置换标签后的**未归一化梯度期望**。同一图的输入、遮点位置和总类型计数都相同。若四个位置全为同类，该图在 g_true−g_hist 的贡献为零。

主方法 Binding 使用 g_true−g_hist。它衡量该位置的真实类型相对同图可互换类型的增量。按 `−g/||g||₂` 给方向，一次固定移动 `0.05 ||θ_Base||₂`。记录原始范数与每图贡献，避免把已归一化的弱信号误解为强信号。若池中少于两类、或 ||g||₂≤10⁻¹²，该臂沿用 Base，保留该块分母。在同一 H 比较本域 Binding、True（g_true）、Hist（g_hist）、V-Binding、同源另外两个 A 的 Other-Binding（两份结果逐项列出，再等权）和零动作 Base。全部主动臂在同一个起点、同一参数空间取相同移动长度。

## 分类评价与机制读数

正式评价采用单次更新后的普通 Accuracy。逐方向和设置内等权报告准确率、纠正/损害、BA、两类召回、NLL、AUROC、预测阳性数。用 Base 的原始 margin 取相同数量的最高分图判正作诊断，数值 ID 打破平局。H 图与同一冻结更新方向的关系也可以在不使用 H 类别的情况下计算：设 z 为原二分类 margin，v 为沿已登记单位方向的右方向导数。封存 z、v 后以 mean[(y−sigmoid(z))v] 计分，正数表示该小步局部降低 H NLL。分档或精确求导时对 ReLU 在零处取右方向导数 max(0, 输入速度)，与正向差分核对；禁止以 H 选择步长或符号。另报将 v 对 [1,z] 作无标签最小二乘投影后的残差读数，衡量超出平移和温度变化的部分。退回 Base 的方向速度为零。该导数与有限步 Accuracy 分开报告。

先用合成图验证全零掩码仍保留其他行、每图采样和损失权重、图内置换平均梯度等于解析软标签梯度、单一类型图的 Binding 为零、未遮图 margin 方向导数与数值差分一致。核验从 Base 起步只动指定两组仿射参数。每池报告有至少两种真实遮点类型的图数、遮点总数、未知类型占比、方向范数，以及适配前后本域/异域在同一 H 上的分类预测。报告历史覆盖不足的比较；门槛以全部 36 块及已登记的主要对照为准。

**计算投入标准。** 在一个设置内要求 Binding 相对 Base 至少 +0.5 个百分点，同时平均超过 B0、SourceCal、True、Hist、V-Binding、Other-Binding 及等阳性数 Base，并在至少 7/12 个方向胜 Base。要求 PROTEINS 和至少一个 Mutagenicity 划分通过，才按原配置在三设置全部补种子 3406–3409。若辅助任务可学但梯度与分类风险倾向相反，则否决当前遮点信号与参数组合。若局部梯度有利但有限步准确率未达到标准，记录两种评价的差异并结束这条固定更新分支。这个单种子屏检只解决是否值得补种子；独立任务上的稳定性须另行建立。
